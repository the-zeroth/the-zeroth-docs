This section collects public release notes for The One Desktop.

- [0.5.0](./0-5-0): One main assistant per Space, matters on boards worked by working groups, triggers, Needs you and the morning report, the action log with undo, and the removal of three third-party sign-ins.
- [0.4.x](./0-4-x): Plugins and the Plugin catalog, Spaces that reference Plugins instead of copying them, and the announced removal of three third-party sign-ins.
- [0.3.0](./0-3-0): Self-managed context (Meditation), per-Space memory, runtime capabilities, live sub-Graphs, the Atlas canvas, the self-evolution lab, a managed Default space, and visible reasoning.
- [0.2.0](./0-2-0): Provider integration, Definition Spaces, sharing platform, and Graph terminology.
- [0.1.0](./0-1-0): The first desktop release with the repository, editor, runtime, and observation loop.
