在 The One 中，Agent 之间有好几种传递工作和信息的方式，各自适合不同的交流。

## 在一个工作组里

1. **移交**：Agent 调用 `handoff_work`，把工作、文件或请求交给与它连了边的 Agent。发出方随即睡下，接收方醒来，只拿到交给它的内容，看不到发出方的其他上下文。
2. **并行叫醒**：Agent 用 `activate_node` 叫醒同一个工作组里的另一个 Agent，带上要它做的事，自己接着做，不必等它。出厂团队的检查员就是这样在开工时和负责人并行启动的。
3. **共享文件**：同一个工作组的 Agent 在同一个文件夹里干活，读得到彼此写下的东西。
4. **TaskBoard**：Agent 把任务分层排好，每个任务配一个 worker 和一个 reviewer（reviewer 从发起它的 Agent 克隆而来），同一层的任务并行，整层做完后结果交回给它。
5. **子 Graph**：Agent 把另一个模板拉起为子 Graph，并充当它的人类：子 Graph 的提问来找它，它用 `reply_to_subgraph` 回答。

## 在工作组之间

6. **事项看板**：同一事项上的每个工作组都读写它的卡片——别人需要知道的事实、决定、清单、链接和文件。读看板不会叫醒任何人。
7. **工作组之间的消息**：工作组用 `message_working_group` 给同一事项、或它上面、下面和旁边的事项上的另一个工作组留言：问一下、请它做、回复，或者指出对方的回复还差什么（返工）。请求要等对方歇下来才送到，做不做、怎么做由对方判断。
8. **子事项**：工作组可以把一部分活开成一个子事项，它有自己的看板和工作组。

## 和你

9. **主助手**：它用你的原话给工作组布置任务，转达你后续的话，回答工作组的提问，或者把该你定的问题留给你。
10. **你**：Agent 需要你时会问你，问题出现在对话上方的**等你**里和事项的看板上。你也可以直接和任何一个工作组对话。

## 读和改别人的上下文

每个 Agent 都能管理自己的上下文：展开、折叠自己的技能和文件，或者冥想。有的 Agent 还带着上下文编辑工具（`context_editor`），可以按 id 读取、修改任何一个 Agent 的上下文，帮它纠正认知，让它工作得更好。在官方空间里，主助手、通用 `chat` 工作组的助手和夜间复盘员带着它：宿主先从记录里找出反复出现的摩擦，复盘员再用它读出事前后别的 Agent 的历史，弄清摩擦是怎么来的。任何角色都可以在编辑页里加上它。
