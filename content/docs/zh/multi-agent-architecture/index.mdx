这一部分讲 The One 为什么这样设计。用 The One 不需要先读它；想知道主助手、工作组和进化背后的道理时，再来看。

## 按这个顺序读

1. [单一 Agent](./single-agent)：一个 Agent 由模型、工具和上下文决定。
   - [上下文与冥想](./single-agent/context)：它看到什么，上下文快满时怎么办。
   - [ReAct 与回合](./single-agent/react)：它怎么一步步做事，一轮什么时候结束。
   - [一直活着的 Agent](./single-agent/life)：睡着、出错、应用重启之后，它都还在。
2. [从单一 Agent 到 Multi-Agent](./evolution)：什么时候值得多一个 Agent，什么时候不值得。
3. [A-Genetic Engineering（Agent 基因工程）](./a-genetic-engineering)：一支团队怎样被完整写下来，可以复用、传给别人。
4. [Prolifera Engineering（增殖式工程）](./prolifera-engineering)：团队怎样在干活时长出来。
5. [协作：组内、组间和你](./collaboration)：Agent 之间、工作组之间、它们和你之间怎样传递工作。
6. [Self-Evolution（自我进化）](./self-evolution)：空间怎样依据证据把自己的活做得更好。
7. [没有审批这一步](./record-and-undo)：Agent 自主行动，安全靠记录、撤回和急停。

在应用里怎么用这些，从[快速入门](../start/quick-start)和[主助手](../the-one-app/main-assistant)开始。
