---
title: Multi-Agent 的更多可能
description: Multi-Agent 相比单一 Agent 多出的独特能力边界。
---

Multi-Agent 还有更多独有的特性和可能性，是单一 Agent 所完全不具备的。

- [通讯方式](./communication)：Agent 之间怎么传递工作和信息——工作组内部、工作组之间借事项的看板，以及和你之间。
- [上下文编辑](./context-editing)：一个 Agent 编辑另一个 Agent 的上下文。
- [Dynamic Graph](./dynamic-graph)：Agent 在运行时创建、克隆、激活、休眠其他 Agent，让工作组边做边长。
- [Meditation](./meditation)：Agent 在上下文窗口用完之前，原地压缩自己的历史。
- [Self-Evolution（自我进化）](./self-evolution)：空间如何依据证据改进自己——进化事项和夜间复盘。
