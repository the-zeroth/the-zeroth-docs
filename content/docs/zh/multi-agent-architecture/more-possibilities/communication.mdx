---
title: 通讯方式
description: Agent 之间怎么传递工作和信息：移交、共享文件、TaskBoard、子 Graph、事项看板、工作组之间的消息，以及你。
---

在 The One 中，Agent 之间有好几种传递工作和信息的方式，各自适合不同的交流。前四种在一个工作组内部：

1. **移交**：Agent 调用 `handoff_work`，把工作、文件或请求交给与它连了边的 Agent。发出方随即睡下，接收方醒来，只拿到交给它的内容，看不到发出方的其他上下文。

2. **共享文件**：同一个工作组的 Agent 在同一个文件夹里干活，读得到彼此写下的东西。

3. **TaskBoard**：Agent 把任务分层排好，每个任务配一个 worker 和一个 reviewer，同一层的任务并行，整层做完后结果交回给它。

4. **子 Graph**：Agent 把另一个模板拉起为子 Graph，并充当它的人类：子 Graph 的提问来找它，它用 `reply_to_subgraph` 回答。

其余几种连接不同的工作组，以及你：

5. **事项看板**：同一事项上的每个工作组都读写它的卡片——别人需要知道的事实、决定、清单、链接和文件。读看板不会叫醒任何人。

6. **工作组之间的消息**：工作组用 `message_working_group` 给同一事项、或它上面、下面和旁边的事项上的另一个工作组留言：问一下、请它做、回复，或者指出对方的回复还差什么（返工）。请求要等对方歇下来才送到，做不做、怎么做由对方判断。

7. **主助手**：它用你的原话给工作组布置任务，转达你后续的话，回答工作组的提问，或把问题留给你。

8. **你**：Agent 需要你时会问你，问题出现在**需要你**和事项的看板上。你也可以直接和任何一个工作组对话。
