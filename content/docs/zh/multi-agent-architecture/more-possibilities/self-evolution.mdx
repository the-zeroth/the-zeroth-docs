**自我进化**是一个空间依据证据把自己的活做得更好的方式：Agent 找出工作反复出错的地方，改动导致问题的最小一层，只有读数表明有用才留下这处改动。The One 用两条回路来做：由你开启的**进化事项**，和自己运行的**夜间复盘**。

## 两条回路

| | 进化事项 | 夜间复盘 |
| --- | --- | --- |
| 什么时候开始 | 你请主助手让空间把自己的活做得更好时；之后每周一 10:00 普查一次，没有新情况的那周跳过 | 每天夜里 03:30，只在出现新摩擦或有以前的改动要复查时 |
| 谁来做 | 实验室工作组：总监、改动员、验证员 | 一个 Agent：复盘员 |
| 读什么 | 真实工作在哪里出了错、夜间复盘的改动效果如何，以及实验室自己的记分卡 | 真实使用中的摩擦：反复失败的工具调用、原地打转、绕路、问你的问题、返工、工作组之间的返工、卡在出错里的 Agent |
| 改什么 | 出问题的最小一层：记忆、技能、角色、模板或代码 | 记忆里的一条教训或一个技能；要改提示词、模板或平台时，改为写一份提案 |
| 怎么判定一处改动 | 上线之前：先回放出事的那一步，再在目标题上和现行版本同批对比，然后看没调过的题，最后用封存的题确认；只有过了第一次读数前写好的门槛才上线 | 生效之后：每处改动按它针对的摩擦对比前后；变差了、或到期没见效的，由复盘员撤回或改进 |
| 在哪里看 | 进化事项的页面：读数、本轮在试的改动、试过的改动 | 晨报里的**昨夜复盘**和**上周复盘** |

## 靠什么保持诚实

- **先看证据**：两条回路都从这个空间真实工作中出过的错出发，只处理反复出现、机制说得清的问题。
- **先写下，再读数**：一处改动该修好什么、不能弄坏什么、多久见效，都在第一次读数之前记下，结果出来以后不能再挑。
- **小步、可撤回**：一次只改一处，只改最小的一层。实验室把旧版冻结成副本；夜间复盘的改动走**行动记录**，你可以在晨报里撤回其中任何一处。复盘员的规程要求它不再做你撤回过的改动。
- **没有审批关**：循环内部由总监拍板，不由你审批。实验室的指令要求它遇到高风险的外部副作用时停在提案上，不自己去做；这是 Agent 自己守的规矩，不是宿主设的闸。和 The One 里的其他地方一样，没有什么会拦下一次工具调用：安全靠记录和撤回。
- **只改你自己的空间**：官方空间是只读的：在那里两条回路都改不了任何东西，实验室会把找到的改进留作提议，直到你复制一份空间。

## 用 A-Genetic Engineering 的话说

自我进化就是作用在基因上的定向进化：看表现型在哪里失败，在最小的一层修改基因型，验证，只留下有用的。基因见 [A-Genetic Engineering（Agent 基因工程）](../a-genetic-engineering)；在应用里怎么开始、怎么跟进这两条回路，见[进化：实验室和夜间复盘](../../the-one-app/evolution)。
