The One 中的所有 Agent 都按 ReAct 运行：醒着的 Agent 不停地“推理、调用工具、拿到结果、接着推理”，直到它自己决定这一轮到此为止。

## 一轮怎么结束

一轮只在 Agent 调用一个结束回合的工具时结束：

- `sleep_node`：歇下，等新的输入。
- `handoff_work`：沿着边把工作交给下一个 Agent。
- `talk_with_human`：回答你或问你。带上 `keep_working=true` 时只把话发给你，这一轮接着做；你的回复以后作为新消息送到。
- `report_task_completion`：TaskBoard 里的审核者用它交回一个任务的结论。
- `restart_desktop_application`：重启 The One 本身，比如改了它自己的代码之后。

工作流结束、上下文重启也会结束这一轮。`ask_choice` 和 `ask_confirmation` 不结束回合：它们最多等你五分钟，没等到就接着做，你的回答以后作为新消息送到。

纯文本永远不会结束一轮，也不会送到任何人手里——那是 Agent 的内心独白。每个 Agent 手上总有一种结束回合的办法，宿主从不在工具之外替它结束。

## 行动链

ReAct 让 Agent 朝着目标一步步走。可是对复杂的任务，只盯着最终目标，模型往往会在一条死路上反复撞墙。所以 The One 给需要的角色配了计划工具 `update_action_sequence_plan`：Agent 把一个大任务拆成一串小的行动目标——我们叫它**行动链**——写进自己上下文里的计划，边做边改。

不是每个 Agent 都需要它：一次就能做完的活不用拆。哪些角色带着它，在角色的工具里设置。

## 宿主提醒，Agent 决定

除了你和别的 Agent，宿主——The One 的运行时——也会在 Agent 的历史末尾追加提示，但从不替它做决定：

- 这段工作花得多、同一个失败反复出现、同一个调用反复执行，或者连续几轮没有产出时，提示它停下来想一想；继续、换路还是找人，由它决定。
- 上下文越过几档大小时，告诉它有多大，见[上下文与冥想](./context)。
- 它写东西的磁盘快满时，告诉它还剩多少、大头在哪里；删不删由它或你决定。

提示只追加，不改写前文，不改变 Agent 的状态，也不结束它的回合。

## 一轮结束之后

回合结束不等于 Agent 结束：睡着的 Agent 依然活着，新的输入会叫醒它。见[一直活着的 Agent](./life)。
