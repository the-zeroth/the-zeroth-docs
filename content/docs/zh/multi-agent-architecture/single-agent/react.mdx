---
title: ReAct
description: The One 中 Agent 默认采用推理、行动、观察再推理的运行方式。
---

The One 中的所有 Agent 默认使用 ReAct 架构运行：

Agent 在激活状态下将会不停地进行“推理，调用工具，积累上下文继续推理”的循环。一轮只有在 Agent 调用一个结束回合的工具时才结束：用 `sleep_node` 歇下，用 `handoff_work` 沿着边把工作交出去，用 `talk_with_human` 回答或询问你，在 TaskBoard 的任务里用 `report_task_completion`，还有另外几种。纯文本永远不会结束一轮，也不会送到任何人手里——那是 Agent 的内心独白。

回合结束不等于 Agent 结束。睡着的 Agent 依然活着，有新的输入（你的消息、交接、回答或结果）就会醒来。出错的 Agent 也不会被放弃：它按越来越长的间隔重试，间隔最长 10 分钟；服务商要它多等时（比如用量窗口用完了）就等得更久，直到恢复为止。暂停是协作式的：被暂停的 Agent 会先做完手上这一步；只有你能在一步中途打断它，或者用应用菜单或托盘菜单里的**急停所有 Agent**一次停下所有 Agent。
