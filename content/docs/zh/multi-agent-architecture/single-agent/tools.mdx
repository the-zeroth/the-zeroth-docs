---
title: 工具
description: 工具让语言模型真正成为 Agent，工具边界就是能力边界。
---

Tool 让一个 LLM 真正成为 Agent，没有 Tool 的模型再强大也只是一个聊天机器人，Tool 的边界就是 Agent 能力的边界，我们的 Multi-Agent 架构便围绕强大的内置 Tool 展开。

而这个边界，不再是在 Agent 构建时就固定死的。通过 Capability Manager，一个 Agent 可以在工作过程中给自己发现并挂载 Skill、绑定 MCP server；像 `meditate` 这样的内置工具，还让 Agent 不只是作用于外部世界，也能管理自己的上下文。

能力也可以打包。一个**插件**可以把技能、脚本、MCP server、应用和连接器装在一起；把它加给一个角色，这个角色就拿到插件带来的能力，而定义空间里只记着对它的引用。持有插件制作工具的 Agent 也可以自己做一个插件，再把它加给某个角色。见[插件与应用](../../the-one-app/capabilities/plugins)。
