---
title: 单一 Agent
description: 理解一个 Agent 由模型、工具和上下文共同决定。
---

本质上，每个 Agent 由以下三样东西决定：  
1. 模型

Agent 的大脑

2. 可用的工具

Agent 的手脚

3. 已有的全部上下文（包括 system Prompt 和一切 user/assistant 上下文）

Agent 的心智

一切上下文都会影响模型的心智，不仅仅是 system Prompt。

## 逐一展开

- [模型](./model)：为不同角色的 Agent 选择合适的大脑。
- [工具](./tools)：决定 Agent 能触达什么、能改动什么。
- [上下文](./context)：用约束、信息、任务三类上下文建立清晰的心智。
- [ReAct](./react) 与 [行动链（Action Sequence）](./action-sequence)：单个 Agent 如何在行动中推理、并把复杂目标拆成可执行的阶段。
