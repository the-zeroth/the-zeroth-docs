很多 Agent 产品会在“危险”的操作前停下来，请你批准。The One 没有这一步：没有任何东西会拦下、询问或拒绝一次工具调用。安全不靠拦，靠三件事：**记下来、放得回、停得住**。

## 为什么不审批

- 一个要替你长时间做事、在你不在时也做事的 Agent，如果每一步都等你点头，就等于不能替你做事。
- 审批一多，人就不再细看，只是点“同意”。审批给的是安全的样子，不是安全本身。
- 一个工具说明的是 Agent **能**做什么——读文件、改文件、运行命令、访问网络——不是它**被允许**做什么。The One 用这些说明来记录和分辨调用，从不用它们来拦。

## 记下来

每一次工具调用都记在**行动记录**里：哪个 Agent、在哪次运行里、调了什么、结果如何，创建、修改、删除了哪些文件，访问了哪些地址。发生在这台电脑以外的效果——推送代码、发邮件、发布、部署、远程登录、向网上写数据——照常执行，但会被单独标出来，晨报里看得到。

## 放得回

Agent 改动或删除一个文件之前，The One 先留一份副本（依赖和缓存目录这类少数地方除外）。保留期内，你可以把一次调用、一次运行、一个事项，或者某个时间以来的改动放回去；撤回本身也会记下来，还能再撤回。

撤回管不到这台电脑以外的事：已经推送的代码、发出去的邮件、部署出去的服务，只能另想办法收回。这正是这些效果要被单独标出来的原因。

## 停得住

- 给事项设一个用量**边界**：到了，它的工作组停在下一个检查点，等你恢复。
- **急停所有 Agent**：立刻中断所有 Agent，结束它们启动的命令，暂停所有运行和触发器，直到你恢复。

打断和急停只有你能做；宿主自己从不在一步中途打断 Agent，只会在两轮之间暂停它。

在应用里怎么看记录、怎么撤回、怎么急停，见[行动记录、撤回和急停](../the-one-app/action-log)。
