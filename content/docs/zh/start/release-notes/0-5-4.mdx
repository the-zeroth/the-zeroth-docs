这份记录覆盖 The One 0.5.4（macOS 和 Windows）。它在 0.5.3 之后发布。这一版没有 Linux 服务器版，[服务器](../linux-server)仍是 0.5.2。

## 空间的模型

- 空间可以写明它是照哪些模型调的：主模型，以及每个能力槽自己的模型和思考深度。空间里只记模型的名字和深度，比如 `openai/gpt-6.2-sol`，连接和密钥留在每台电脑上；复制空间时它跟着走，官方更新也带着它。详见[模型](../../the-one-app/capabilities/models#空间写明的模型)。
- 空间写的模型，这台电脑上有连接能跑时就用它：先找空间写明的那条连接，再找官方连接（会员才有），然后是这台电脑主模型用的连接、这个模型那一家的直连，最后是别的 OpenRouter 连接；自定义的服务只在空间写明它时才用。哪条都跑不了时，用这台电脑自己的模型设置。
- 官方空间写明用 GPT-6.2 Sol：主模型思考深度**中**，五个能力槽跟着它、用出厂深度。会员的电脑上它跑在官方连接上；不是会员时，用这台电脑上能跑它的 ChatGPT 账号登录、OpenAI 或 OpenRouter 连接。跟着官方更新的副本（比如「我的空间」）也带着这一份，从以前的版本升级的，在升级后第一次启动时收到。所以在这些空间里，只要这台电脑跑得了 GPT-6.2 Sol，你给这台电脑的主模型和能力槽选的模型就用在别处；想换，就改这个空间的模型。
- **设置 › 模型和登录 › 模型**最上面多了**这个空间的模型**：主模型和五个能力槽各写着空间写的模型和深度，以及在这台电脑上跑在哪条连接上，跑不了的写着正在用这台电脑的。下面的**这台电脑的模型**就是原来的主模型、能力槽和保存的配置，用在空间没写模型、或者这台电脑跑不了的时候。
- 在你能编辑的空间里，点**更改**就能改空间的模型；每次改动都记在空间的变更历史里，可以撤回。**不再给这个空间指定模型，改用这台电脑的**会删掉空间的模型文件。官方空间只读，这一块上方有**复制一份以编辑**。
- 主助手输入框旁的模型按钮写着正在跑的主模型：空间写明了主模型时是空间的，在那里换深度或换模型，改的也是空间的；官方空间里改不了。主助手和定义编辑组换主模型或能力槽时，改的也是当前空间的模型。

## 浏览器

- 应用不再给插件配对浏览器扩展，插件也不再能通过配对的扩展操作你的浏览器，插件详情里的**浏览器扩展要求**一栏随之去掉；Agent 上网用应用自带的浏览器，Computer Use 插件从 0.5.0 起只用来操作桌面上的应用。详见[浏览器](../../the-one-app/browser)。
- Agent 在浏览器里做完一步，浏览器至少等一小会儿再把结果交给它：点击之后稍晚才发出的请求（比如提交表单）也算在这一步里，Agent 看到的是提交以后的网页，这次提交也记在这一次调用上。

## 插件

- 鼠标停在扩展中心的**插件**上时，提示改成“安装和管理这台电脑上的插件，每个空间都能用”。详见[插件与应用](../../the-one-app/capabilities/plugins)。
- 在 Windows 上，插件库迁移记下被移到一边的旧文件夹时，路径的写法和其他系统一样。
- 给插件开发者：组件的 `browser_extensions` 在插件清单格式里标为已停用，应用不再理会它；写着它的插件照样能装、能运行。
