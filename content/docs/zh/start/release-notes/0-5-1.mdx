这份记录覆盖 The One 0.5.1（macOS）。它在 0.5.0 之后发布，应用的结构没有变：每个 Space 一个主助手，事项由工作组去做。

## 界面

- 中性的黑白配色：浅色是素白，深色是石墨；一种无衬线字体，圆角更柔和；侧栏贯通窗口的高度。
- 对话栏随窗口变宽，最宽 1040px，窗口宽时正文是 16px。
- 事项页居中，结束事项等操作放在标题栏里。

## 首页

- 每天以主助手的问候开场，对话里有一行标出这一天。
- 用页头的搜索或 Cmd+F 搜索对话。
- 处理过的卡片在原处收成一行，之后还可以改主意。
- 输入框上方一行说明主助手在休息，或者失败的回复什么时候重试。
- 对话停在最新的一句，直到你自己往上翻。

## 全景

- 侧栏的**全景**一页看到所有事项、工作组和 Agent：**组织图**看谁在为哪件事干活，**流动**看今天每个 Agent 的时间线。
- 每个工作组按它的模板画成图；流动可以缩放到最近一小时或三小时，做完的分支会收起来。
- 在侧栏就能结束一个事项。

## 等你和需要你

- 等你的东西只算一次：侧栏、晨报和 Dock 角标的数字一致。
- 结束一个事项，它的东西立刻离开等你和晨报。
- 每张等你的卡片写明它来自哪个工作组；主助手的提问按它问的内容命名。
- 收件箱页统一叫**需要你**。

## 模型连接

- 官方连接的用量用完时，卡片和提示会说用量已用完，并打开订阅页，不再让你重新登录。
- Key 或账号余额不足时按用量上限处理，问你怎么办，而不是当作登录被拒。
- 出错的 Agent 写明它什么时候重试，你也可以让它立即重试。

## 设置和团队

- 设置分成六个部分，每页上方写明它在哪一部分。
- **团队与工具**先列工作组，再列它们干活用的东西。
- 开发者视图默认关闭，开发者要看的东西放在里面。

## 插件

插件在插件库里更新，不跟着应用的版本走。和 0.5.1 一起更新的有：

- **Mailbox 0.2.0**：Google 账号用 Google 登录收发 Gmail，取代 Gmail Control；可以存草稿；回复自己发出的邮件时，回给原来的收件人。官方空间的主助手和通用工作组改用 Mailbox。
- **Computer Use 0.4.0**：在 macOS 上按应用名找到窗口，看到并操作任意应用。要先在系统设置里给 The One 辅助功能和屏幕录制权限。
- **OneCanvas 0.5.0**：跟随应用的主题，显示项目的设计系统；页面卡显示 Agent 做的 HTML 页面。
- **Image Generation 0.5.3**：竖版尺寸不再需要能力清单；插件更新后，图片组不会因为旧的哈希固定而停住。
- **Payments 0.2.0**、**Sites 0.2.0** 和 **Visual Check 0.1.2** 第一次进入插件库；**Blender Control 0.7.0** 带来查看面板和后台任务。
- 插件库会读出一个插件版本需要的宿主接口，需要更新 The One 时先告诉你。

## 其他

- 更多界面文字跟随你的语言，包括启动、登录、插件安装确认窗口和随身通道。
- [Linux 服务器版](../linux-server)可以在 Alpine 等 musl 系统上安装和运行。
