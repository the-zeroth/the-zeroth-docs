这份记录覆盖 The One 0.5.3（macOS 和 Windows）。它在 0.5.2 之后发布，应用的结构没有变：每个空间一个主助手，事项由工作组去做。这一版没有 Linux 服务器版，[服务器](../linux-server)仍是 0.5.2。

## 插件

- 每台电脑一个插件库：一个插件装一次，装的时候校验一次，之后每个空间都直接用它，不再往空间里复制。角色、模板或技能点了名的插件，装好就能用，只读的官方空间也一样。详见[插件与应用](../../the-one-app/capabilities/plugins)。
- **团队与工具 › 插件**的**已安装**列的就是这个插件库：可以**更新**、换回这台电脑留着的上一个版本、**移除本机副本**、**从这台电脑上移除**；上方列出当前空间用到、这台电脑上还用不了的插件；右上角是**打开插件文件夹**。
- 安装、更新和移除，先在系统窗口里确认一次：会改什么、要下载多少、哪些组件会以你的权限运行。确认后插件页上方显示进度，可以**取消**。
- 从官网点**在 The One 中打开**，插件装在这台电脑上，不再问装进哪个空间。
- 插件库只列这个版本的 The One 能运行的版本。
- 移除插件会删掉它的文件，腾出磁盘。装好的某个插件读不出来时，只有它自己用不上，它在**已安装**里标着问题，带着**移除**。
- 本机副本是插件文件夹里的一个插件文件夹，在每个空间里代替安装的版本运行；Agent 要改一个装好的插件时，先复制出这样一份再改。**移除本机副本**只把文件夹移到一边，之后运行的又是安装的版本。
- 本机副本的设置每台电脑一份：在哪个空间里填的，每个空间都用得上。
- 主助手给工作组派活前，会看这个组要用的插件装了没有；缺了又用得上时，它自己装上，并用一句话告诉你装了什么、为什么。插件要的账号和密钥仍然要你来给。
- 升级后第一次启动，以前装的插件按原来的版本搬进插件库，安装包还在的不重新下载；以前的文件夹留一周后删掉。

## Agent 的浏览器

- Agent 有了自己的浏览器：侧栏**全景**下面的**浏览器**，打开的网页就是应用里的真标签页。你看得到它在网页上点了什么、填了什么；你一动手，它这一步就停下，下一步会知道是你接手了。详见[浏览器](../../the-one-app/browser)。
- 每个空间一个浏览器，里面的登录重启后还在；**清空这个空间的浏览器**会删掉它的 Cookie、网站数据和登录。
- 官方空间里上网的 14 个角色（在软件团队、研究组、前端设计组、三维场景组、建站上线组、网店门面组和产品体验评估组里）改用这个浏览器：不再绑 Chrome DevTools 服务器；绑着 Computer Use 插件的，留着它做桌面上的活。
- 官方空间的 Chrome DevTools 服务器改名 **Your Chrome**，连到你自己正在用的 Chrome（144 及以上），这样 Agent 能用你在 Chrome 里的登录：在 Chrome 里打开 `chrome://inspect/#remote-debugging`，打开远程调试，之后每次连接 Chrome 都会问你一次。
- Agent 用浏览器时，网页向网站发出的写请求（比如提交的表单）随这次调用记进行动记录；为事项干活时提交的，周报的**撤回不了的动作**里也看得到。

## 空间

- 新装的 The One 从「我的空间」开始：它是官方空间的一份副本，主助手和进化实验室的改进直接生效，官方空间的更新也照样进来。以前就在官方空间里的，留在原处。
- 从这一版起，在应用里复制出来的官方空间副本都跟着官方更新：你没改过的文件自动换成新版；你或 Agent 改过的保留你的，官方的新版本在空间页上等你挑**用官方的**或**保留我的**。**不再跟随官方**以后不能改回来。以前复制的、导入的空间和副本的副本不跟随。详见[空间](../../the-one-app/capabilities/definition-spaces)。

## 对话和主助手

- 不再需要你的那些行收成一行：一段工作组通知，卡片都已处理，连同主助手其间的记账，合成比如“通用工作组在「结账页改版」上交来 3 份、问了 2 个问题，都处理了”。点它就在原处展开。
- 结束了的事项，它在对话里的那些行留在原处，变淡，带一个**已结束**标签，点它打开那个事项。
- 主助手和通用工作组的助手不再在每次请求里带上所有工具：不常用的工具，以及外部工具（MCP）和插件的工具，用的时候先搜出来。

## 界面

- **上手**留在侧栏里，直到你走完它或点**收起上手**；以后在窗口左上角的 **…** 菜单里点**重新看上手**，它就回来。
- **团队与工具**顶上写着正在用哪个空间，旁边是**管理空间**；下面分成**这个空间的团队**和**所有空间共用**：插件、应用和模型属于这台电脑，每个空间都能用。各编辑页上方写着在改哪个空间。
- 扩展中心不再有自己的空间切换器。
- 结束的事项更好找：侧栏事项列表下面多了**已结束的（N）**；从侧栏或全景结束一个事项后，弹出的提示说它去了哪里，带着**重新打开**。侧栏的**事项**旁写着几件开着，结束按钮换成一个打勾的圆圈。
- 全景上并排放不下的事项换行排，不再从右边出去。
- 第一次打开时的登录页说明 The One 是做什么的，按钮是**登录或注册**，没有账号可以免费注册。
- 连接自定义的服务后，它的模型目录里有旗舰模型或只有一个模型时，主模型一栏会先填上。
- 事项总览里已结束的事项写着什么时候结束的，比如**刚结束**。
