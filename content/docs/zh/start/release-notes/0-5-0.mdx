这份记录覆盖 The One 0.5.0。它是 macOS 0.4.27、Windows 0.4.28 之后的第一个版本。

到 0.4.x 为止，你为每件事新建一个对话，再自己选由哪个 Graph 来做。0.5.0 给每个 Space 一个**主助手**，你交代的事都交给它。比一句回答大的事会变成一个**事项**，也就是一块由卡片组成的看板；主助手把它交给合适的**工作组**（一组 Agent）去做。你在看板上跟进进度，回答需要你回答的问题，评判交回来的结果。

## 核心变化

### 主助手和事项

- 应用打开就是当前 Space 的主助手（侧边栏的**主助手**）。什么事都可以先跟它说：能直接回答的它直接回答，更大的事它开一个事项，并在同一步把工作交给一个工作组。
- **新建对话**没有了。之前的会话（还在干活的和置顶的除外）已一次性移到**已归档**（在**设置 › 所有运行**底部），仍可打开或恢复，没有删除任何内容。
- 事项的**看板**先列出等你处理的事，再按天列出发生了什么，事项本身放在旁边。工作组的提问和交付都以卡片出现在这里。主助手会对照你最初的要求检查每次交付，汇报时先说结论，最后说你要做什么。
- 你可以直接和任何工作组对话，暂停或继续它，重试一直失败的工作组，也可以用自己的话把交付退回返工。**工作组**页面列出侧边栏里各个进行中事项的工作组。
- 每个事项单独统计它的工作组花了多少。给事项设一个用量边界，工作到那里就暂停，等你恢复。事项的**改动**列出这件事改了什么，可以在那里撤回。**剧场**在一屏里显示所有工作组的 Agent 正在做什么。
- 工作组可以为一部分工作开一个子事项，你或主助手可以把它升为独立的事项。同一事项里的工作组可以读写它的看板，也可以互相写信。
- 结束一个事项会暂停它的工作；重新打开后工作继续。

### 能力和设置

- 侧边栏现在是主助手、需要你、晨报、工作组、进行中的事项、**能力**、应用和设置；会话、预设和扩展不再出现在侧边栏。
- **能力**汇集 Agent 干活要用的一切：工作组模板（Graph）、角色（Agent 预设）、技能、提示词、外部工具（MCP）、模型、插件、应用、总图和你的定义空间。
- 所有运行，包括原来带工作链和 Agent 名册的会话视图，都在**设置 › 所有运行**（开发者视图）里。

### 会自己更新的卡片

- 数据卡显示某个插件工具、文件、网页或命令现在的结果。
- 链接卡检查它的地址是否还能打开。
- 面板卡把插件工具的面板放到看板上。
- 带触发器的事项会显示它的节奏，什么时候跑什么一目了然。

### 触发器、“需要你”和晨报

- 定时、Webhook（Stripe、Creem、GitHub 和店铺平台），以及新订单、新邮件、文件、网页或命令输出的变化，都可以唤醒 Agent，或把工作交给事项的工作组。在**设置 › 常驻与触发**里管理。为了触发器，应用会常驻菜单栏或托盘，等待时可以让电脑保持唤醒。
- **需要你**汇集 Agent 主动问你的问题，以及完成或失败的运行，并配有通知、Dock 角标和托盘提示。
- **晨报**开头是三个数字和最先该做的事，已读过的交付会折叠起来，并按事项汇总。每次交付都有一份证据包，读起来就是这次交付的验收记录，包括视觉检查。
- 在**设置 › 随身通道**里连接后，可以用手机和主助手对话，回复会回到你提问的地方。

### 看清并撤回 Agent 做过的事

- **设置 › 行动记录**记下每一次工具调用：创建、修改、删除了哪些文件，访问了哪些地址，结果如何。Agent 改动或删除的文件可以放回。The One 不会在 Agent 动手前拦截或询问；记录和撤回就是你掌控局面的方式。
- 每次运行会显示目前用了多少，你可以给它设用量上限。
- 应用菜单和托盘菜单里的**急停所有 Agent**会中断所有 Agent、结束它们启动的命令，并暂停所有运行和触发器，直到你恢复。
- 审阅面板可以逐块阅读每个 Agent 的改动，逐块接受或拒绝，再把审阅意见发回给 Agent。**产物**列出 Agent 做出来的东西，并可预览。

### 第一次使用

- 第一次使用（**上手**）从连接模型开始：The One 会员自带官方连接，也可以连接你自己的 ChatGPT 账号或 API Key。接着检查 Space 里每个 Agent 的模型是否都连得上，建议你建立自己的 Space，最后把第一句话交给主助手。

### 在 Linux 服务器上运行 The One

- `the-one-server` 可以在没有屏幕的 Linux 机器上运行 The One 的 Agent，支持 x86_64 和 arm64。用 `curl -fsSL https://updates.the-zeroth.com/server/linux/install.sh | sh` 安装，自带 Python 和 Node。详见[在 Linux 服务器上运行 The One](../../the-one-app/settings/linux-server)。

### 模型

- **设置 › API 配置**里，ChatGPT 登录那一行会显示计划用量和重置时间。
- 长时间运行会更多地复用提示词缓存，花费因此更低。
- Claude Code、Gemini CLI Code Assist 和 Gemini Antigravity Code Assist 三种登录已按 0.4.x 的预告移除。Anthropic 和 Gemini 请改用 API Key 连接；OpenAI Codex 仍可用 ChatGPT 登录。
- 没有保存搜索 Key 时，网页搜索使用模型服务商自带的搜索。Tavily 移到了可选的 Tavily Search 插件里。

### 插件、工具和 Skill

- 插件工具的面板（MCP Apps）显示在对话里对应调用的下方，可以固定到侧边面板，全屏时不会重新加载。工具卡片会标出这次调用是只读、会改动东西，还是会访问你电脑以外的地方。
- 支持 2026-07-28 协议的 MCP server 可以在后台执行耗时的工具调用，重启后也能取回结果。
- 基于 Node 的 MCP server 使用 The One 自带的 Node 运行；插件的 Python 在应用按插件锁文件构建的环境里运行。
- 能力包已移除：插件是唯一的扩展类型，插件目录只使用一种签名格式。
- 可以导入整个 Agent Skills 仓库，以及 `.zip` 或 `.skill` 包。

### 记忆、外观和存储

- 记忆和项目笔记按语义排序，默认用应用内置、在你电脑上运行的模型；新会话能看到同一项目里之前会话得出的结论。
- **设置 › 外观**：浅色、深色或跟随系统，还可以做自己的配色。
- **设置 › 存储空间**显示磁盘空间的去向（包括 Docker 和 git worktree），磁盘快满时提醒，并可清理插件工作区。

### 安全、隐私和更新

- 分享 Space 默认是私有的，导出的 Space 不含密钥，下载的内容在使用前都会校验。
- 更新可以分批推送，也可以随时暂停。
- 应用主进程的崩溃报告在发送前会去掉 token、邮箱、账号 ID 和你的用户名。**设置 › 通用**里的**使用统计**默认关闭，只记录打开了哪些页面、启动了哪些内置应用，且只保存在你的电脑上。

## 总结

0.4.x 用插件给 Agent 的能力安了家。0.5.0 给工作本身安了家：一个可以对话的主助手、可以跟进和撤回的事项，以及在你离开时也会继续干活的工作组。
