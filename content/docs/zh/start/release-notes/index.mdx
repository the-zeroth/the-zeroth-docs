这里收录 The One Desktop 的公开版本更新记录。

- [0.5.4](./0-5-4)：空间写明它是照哪些模型调的，这台电脑能跑时就用它们，官方空间写明用 GPT-6.2 Sol；设置里的模型页先列这个空间的模型；应用不再给插件配对浏览器扩展。
- [0.5.3](./0-5-3)：每台电脑一个、每个空间都能用的插件库，Agent 自己的浏览器，跟着官方更新的空间副本，收成一行的已处理通知，以及留到走完为止的上手。
- [0.5.2](./0-5-2)：一个主模型加五个能力槽、由一个负责人动手的软件团队、记住你的做事方式、在对话里处理等你的事和周报，以及大一号的界面。
- [0.5.1](./0-5-1)：更安静的界面、从对话开始的首页、全景页、处处一致的“等你”计数，以及官方空间的主助手改用 Mailbox。
- [0.5.0](./0-5-0)：每个 Space 一个主助手、由工作组推进的事项看板、触发器、“需要你”与晨报、可撤回的行动记录，以及移除三种第三方登录。
- [0.4.x](./0-4-x)：插件与插件目录、只引用插件而不复制插件的 Space，以及预告移除的三种第三方登录。
- [0.3.0](./0-3-0)：自管理上下文（Meditation）、按 Space 的 memory、运行时扩展能力、活的子 Graph、Atlas 画布、自进化实验室、受管的 Default space，以及可见的推理过程。
- [0.2.0](./0-2-0)：Provider 接入、Definition Space、分享平台和 Graph 语义升级。
- [0.1.0](./0-1-0)：第一个桌面端公开版本，完成仓储、编辑、运行、观察的核心闭环。
