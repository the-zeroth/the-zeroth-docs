这里收录 The One Desktop 的公开版本更新记录。

- [0.4.x](./0-4-x)：插件与插件目录、只引用插件而不复制插件的 Space，以及即将移除的三种第三方登录。
- [0.3.0](./0-3-0)：自管理上下文（Meditation）、按 Space 的 memory、运行时扩展能力、活的子 Graph、Atlas 画布、自进化实验室、受管的 Default space，以及可见的推理过程。
- [0.2.0](./0-2-0)：Provider 接入、Definition Space、分享平台和 Graph 语义升级。
- [0.1.0](./0-1-0)：第一个桌面端公开版本，完成仓储、编辑、运行、观察的核心闭环。
