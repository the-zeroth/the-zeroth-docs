title: 模型与价格
description: 官方模型服务和你自己的模型服务有什么不同，会员套餐和用量包怎么收费，费用由谁结算。

The One 的主助手和工作组都靠模型干活。模型可以来自随 The One 会员提供的官方模型服务，也可以来自你自己的模型服务。这一页讲两者的区别和收费方式；每种连接怎么设置见 [API 配置](../the-one-app/settings/api-configuration)，哪个 Agent 用哪个模型见[模型](../the-one-app/capabilities/models)。

## 两种方式

| | 官方模型服务 | 你自己的模型服务 |
| --- | --- | --- |
| 怎么接入 | 开通 The One 会员，官方连接自己出现，不用准备 API Key | 用 ChatGPT 账号登录（OpenAI Codex）；填 OpenAI、Anthropic、Gemini 的 API Key；或者用**自定义提供商**连接兼容 OpenAI 或 Anthropic 接口的服务、团队或企业的模型网关和本机模型 |
| 能用哪些模型 | OpenRouter 上的模型，包括 OpenAI、Anthropic、Google、Meta、Mistral、DeepSeek 等 | 那家服务提供的模型 |
| 怎么收费 | 按各模型在 OpenRouter 上的价格，从会员包含的用量和用量包里扣 | 由那家服务收：API Key 按它的价格结算，ChatGPT 登录计入你 ChatGPT 套餐的 Codex 用量，团队或企业的网关按你们自己的规则 |
| 适合 | 第一次用、不想管 Key、想让所有模型只有一份账单、想多试几种模型 | 已经有账号、团队要求走自己的账号或网关、想用自己电脑上的模型、最在意单次调用的成本 |

两种可以同时用：每个 Agent 走哪条连接，由它用的模型预设决定。用你自己的服务时，不消耗官方模型服务的用量。

## 官方模型服务

官方模型服务随 The One 会员提供，基于 OpenRouter。只登录 The Zeroth 账号不会带来它：还不是会员时，**快速上手**里会出现**开通会员**。开通以后，官方连接就出现在 The One 里。

剩余用量可以在控制台看，也可以在应用里看：**设置 › 模型和登录 › API 配置**里官方连接的卡片写着你的**会员级别**、包含的用量还剩多少，以及**管理订阅**。

这是便利，而不是折扣。用量按各模型在 OpenRouter 上的价格扣减，而每个套餐包含的用量低于套餐价格，所以官方模型服务并不是调用同样模型的更便宜途径。最在意单次调用的成本的话，用你自己的服务商 Key。

## 会员套餐和用量包

所有套餐的功能都一样，差别只在包含多少官方模型服务的用量：Pro 是 Starter 的 3 倍，Max 是 Starter 的 10 倍。

|套餐|价格|每月包含的用量|适合|
| --- | --- | --- | --- |
|Starter|$20 / 月|$15|轻量使用、个人体验、低频的 Agent 工作|
|Pro|$60 / 月|$45|日常稳定使用、多 Agent 工作流、较高频的任务|
|Max|$200 / 月|$150|高频使用、复杂工作流、重度自动化|

包含的用量是 OpenRouter 额度，每个账单周期开始时重置，用不完的不结转。用完以后，等你、晨报和对话里会写**官方连接的额度用完了**，链接打开账户的订阅页，可以在那里升级套餐或买下面的用量包。

某个月用得多、又不想升级套餐时，可以在控制台买**用量包**（Quota pack）：每次 $20，增加 $13 的用量。用量包不改变你的套餐，只增加可用的用量。

- 调用先用套餐包含的用量，用完再用用量包。
- 用量包每 $20 是 $13，比套餐每 $20 含 $15 略少；换来的是它不会过期：不随账单周期重置，套餐到期以后剩下的也照样能用。
