The One 是 The Zeroth 的 AI Agent 桌面端应用。你可以使用随 The One 会员提供的 The Zeroth 官方模型服务，也可以接入你自己已有的第三方模型账号。

我们支持两种使用方式：

1. 使用 The Zeroth 官方模型服务
2. 接入你自己的第三方模型渠道

无论用哪种方式，模型都通过**模型预设**来选：一套预设把模型、Provider 连接、推理强度和服务等级存在一起。其中一套是**全局默认**，所有没单独绑预设的 Agent、Graph 和会话都用它；别的预设可以单独绑给某个 Agent、某个 Graph（作为它各节点的默认）或某一次运行。在**设置 › 默认模型**或标题栏的模型按钮里管理，详见[模型](../the-one-app/capabilities/models)。

## 一、官方模型服务

这是最简单、最推荐的方式。

官方模型服务随 The One 会员提供。开通会员后，官方连接会出现在 The One 里，不需要自己准备 API Key，也不需要单独配置模型供应商。只登录 The Zeroth 账号并不会带来它：不是会员时，**快速上手**里会出现**开通会员**，你也可以接入自己的模型渠道。

The Zeroth 官方模型服务基于 OpenRouter 提供模型访问能力。选择官方模型服务有两个核心优势：

### 1. 模型选择更完整

OpenRouter 聚合了大量主流和前沿模型，你可以在 The One 中使用更丰富的模型选择，包括 OpenAI、Anthropic、Google、Meta、Mistral、DeepSeek 等不同模型生态中的能力。

相比单独接入某一家模型供应商，官方模型服务可以让你更灵活地为不同 Agent、不同任务选择合适模型。

同时，官方服务由 The Zeroth 统一接入和维护，减少你自己管理多个供应商 API 的复杂度。

### 2. 一个账户，一份账单

通过官方模型服务使用的所有模型都计入你的 The Zeroth 账户。剩余用量可以在控制台随时查看，也可以在应用里看：**设置 › API 配置**里官方连接的卡片写着你的会员级别、包含的用量还剩多少，以及**管理订阅**。你不需要分别注册多个模型平台、充值，也不需要创建和轮换 API Key。

这是便利，而不是折扣。用量按 OpenRouter 上各模型的价格扣减，而每个套餐包含的用量低于套餐价格（见下文“收费方式”），所以官方模型服务并不是调用同样模型的更便宜途径。如果你最在意单次调用的成本，请使用自己的供应商 Key。

官方模型服务适合：

|使用场景|是否推荐|
| ----------------------------| ----------|
|第一次使用 The One|推荐|
|不想配置 API Key|推荐|
|希望模型账单统一管理|推荐|
|想快速体验多种模型|推荐|
|希望减少供应商账号管理成本|推荐|

## 二、第三方模型渠道

如果你已经有自己的模型供应商账号，也可以在**设置 › API 配置**里添加自己的 API Key，或用 ChatGPT 账号登录来使用 OpenAI Codex。每种连接的设置见 [API 配置](../the-one-app/settings/api-configuration)。

目前支持的第三方渠道包括：

|渠道|支持方式|
| ------------------| ------------------------------------|
|OpenAI|API Key|
|OpenAI Codex|ChatGPT 账号登录（用你 ChatGPT Plus 或 Pro 套餐里的 Codex 额度）|
|Anthropic Claude|API Key|
|Google Gemini|API Key|
|OpenRouter（自备 Key）|**自定义提供商**，协议选 OpenAI Chat Completions（Base URL：`https://openrouter.ai/api/v1`）|
|其他兼容服务|**自定义提供商**，协议可选 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages，填 API Key|
|本机模型（Ollama、LM Studio、vLLM）|**自定义提供商**，认证方式选**不用 key**|

The One 0.4.28 及更早的版本还提供 Claude Code、Gemini CLI 与 Antigravity 登录。0.5.0 已移除这三种方式，因为 Claude Code、Gemini CLI 与 Antigravity 的条款都不允许第三方应用使用它们的登录。用这些方式建立的连接在更新后无法使用，请改用 API Key 接入 Anthropic 或 Gemini。

自定义提供商适合已经有企业模型网关或私有部署模型的团队、兼容 OpenAI 或 Anthropic 接口的第三方服务，以及跑在你自己电脑上的模型。

使用第三方渠道时，模型调用不会消耗 The Zeroth 官方模型服务额度；费用、额度、速率限制和可用模型范围由对应第三方平台决定。

## 三、收费方式

The Zeroth 官方模型服务支持两种收费方式：

1. 订阅制
2. 用量包制

### 订阅制

订阅制适合持续使用 The One 的用户。不同订阅档位包含不同的官方模型服务使用额度。

当前订阅档位包括：

|套餐|价格|包含用量|适合用户|
| ---------| -----------| -----------| -------------------------------------------|
|Starter|$20 / 月|$15 / 月|轻量使用、个人体验、低频 Agent 工作流|
|Pro|$60 / 月|$45 / 月|日常稳定使用、多 Agent 工作流、较高频任务|
|Max|$200 / 月|$150 / 月|高频使用、复杂工作流、重度自动化场景|

包含用量是 OpenRouter 额度：每次调用按所用模型在 OpenRouter 上的价格扣减。它在每个账单周期开始时重置，不会结转。

所有订阅档位都可以使用 The One 的核心能力，包括：

- 桌面端应用
- 主助手、事项和工作组
- 触发器
- 本地执行
- 运行观察
- 官方模型服务
- 第三方模型渠道接入

套餐之间的主要区别是包含的用量：Pro 是 Starter 的 3 倍，Max 是 Starter 的 10 倍。

### 用量包制

如果你当前订阅中的官方模型服务额度不够，可以额外购买用量包。

用量包适合：

- 某个月临时使用量变高
- 不想升级长期订阅
- 某次项目、交付或集中测试需要更多模型额度

当前用量包为：

|用量包|价格|说明|
| --------| ----------| --------------------------------|
|用量包（Quota pack）|$20 / 次|增加 $13 用量，不会过期|

用量包不会改变你的订阅套餐，只会增加你的官方模型服务可用额度。

两条值得知道的规则：用量包每 $20 增加 $13 用量，而套餐每 $20 含 $15 用量，所以同样的花费下，用量包可用的量略少；作为交换，用量包额度在账户有效期内不会过期，而套餐用量每个账单周期重置。模型调用会先使用套餐用量，用完后再使用用量包。

## 四、第三方渠道如何收费

如果你使用自己的 OpenAI、Anthropic、Gemini 或自定义模型服务，相关费用由对应第三方平台收取。

例如：

|使用方式|费用归属|
| ------------------------------------| ------------------------------------------|
|使用 The Zeroth 官方模型服务|消耗 The Zeroth 账户中的官方模型服务额度|
|使用自己的 OpenAI API Key|由 OpenAI 结算|
|使用自己的 Anthropic API Key|由 Anthropic 结算|
|使用自己的 Gemini API Key|由 Google 结算|
|用 ChatGPT 账号登录使用 OpenAI Codex|计入你 ChatGPT 套餐的 Codex 用量|
|使用企业内部模型网关|由你的团队或企业内部规则决定|

The Zeroth 不会对第三方模型调用重复扣除官方模型服务额度。

## 五、怎么选择

如果你只是想开始使用 AI Agent，推荐选择官方模型服务。它配置最少，模型选择丰富，也更容易统一管理。如果你更在意单次调用的成本，请使用自己的供应商 Key。

如果你已经有自己的供应商账号，或者公司要求模型调用必须走内部账号，可以选择第三方模型渠道。

|使用场景|推荐方式|
| --------------------------------------| ----------------|
|不想配置 API Key|官方模型服务|
|想快速使用多种模型|官方模型服务|
|希望所有模型只用一份账单|官方模型服务|
|希望单次调用成本最低|第三方渠道|
|已经有 OpenAI / Claude / Gemini 账号|第三方渠道|
|公司有统一模型网关|自定义提供商|
|想用自己电脑上的模型|自定义提供商（不用 key）|
|想把模型费用走自己的供应商账单|第三方渠道|

## 总结

The One 支持两种模型使用模式：

- 官方模型服务：随 The One 会员提供，基于 OpenRouter，模型选择丰富、无需管理 Key，使用 The Zeroth 的订阅额度或用量包额度。
- 第三方模型渠道：连接你自己的模型账号或本机模型，费用由第三方平台或你的团队结算。

对大多数用户，官方模型服务是最省心的选择。  
对已经有模型基础设施的团队，第三方渠道可以满足更灵活的接入需求。
