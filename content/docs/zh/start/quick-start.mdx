这份指南带你从安装 The One 走到第一个事项：主助手把它交给一个工作组，你在事项的看板上跟进。

## 1. 安装并登录

从[下载页](https://the-zeroth.com/zh/download)下载 macOS 版（Apple 芯片，macOS 15 或更高）并安装。Windows 版目前还是 0.4.28，没有主助手和事项，所以下面的步骤以 macOS 版为准。

第一次打开时，窗口会请你登录：点 **Sign In**，在浏览器里登录你的 The Zeroth 账号，再回到 The One。在模型配置好之前，应用会打开**快速上手**（侧边栏里的**上手**），带你完成下面几步；配好以后，**上手**就从侧边栏收起来了。

应用打开时是浅色的**素白**，文档里的截图也是；想要深色的**石墨**或跟随系统，在**设置 › 通用 › 外观**里换。

## 2. 连接模型服务

主助手和工作组都靠模型干活，所以这一步排在最前面。

- 如果你是 The One 会员，官方连接已经在了：卡片上写着你的会员级别和剩余用量，直接点**下一步**。刚开通、连接还在准备的话，稍等一下再点**刷新**。
- 如果还不是会员，这里会出现**开通会员**，点它会在浏览器里打开控制台。开通后回到这里，页面会自己再查一次，也可以点**我已开通，刷新**。
- 也可以连接你自己的服务：**用 ChatGPT 账号登录**，用你 ChatGPT Plus 或 Pro 订阅里的 Codex 额度；或者填 OpenAI、Anthropic、Gemini 的 API Key。**其他服务**里还有兼容 OpenAI 或 Anthropic 接口的服务，以及跑在你自己电脑上的模型，比如 Ollama、LM Studio。

![在快速上手里连接模型服务](/docs-assets/images/0.5/zh/quick-start-connect.png)

各种方式的区别见[模型与价格](./models-and-pricing)，每种连接的设置见[模型连接](../the-one-app/settings/api-configuration)。

## 3. 选默认模型

选一个默认模型：主助手和没有单独指定模型的 Agent 都用它。之后随时可以在主助手输入框下方的模型按钮或**设置 › 模型和登录 › 默认模型**里修改，那里也可以保存多套模型预设。详见[模型](../the-one-app/capabilities/models)。

## 4. 检查空间里的模型（需要时才出现）

空间里的 Agent 可以单独指定自己的模型或连接，比如别人分享给你的空间。如果其中有在这台电脑上用不了的，快速上手会多出这一步，列出每一处卡住了哪些 Agent。在你能编辑的空间里，可以让这些 Agent **改用默认模型**；只读的空间改不了它们，就连接它们指定的服务，或者先复制一份空间再改。

## 5. 准备你自己的空间（推荐）

一开始用的是官方空间：侧边栏顶上的空间菜单里叫 **Default**，在**定义空间**页上标着**只读**。里面的工作组模板、角色和技能由官方维护，跟着版本更新，所以主助手和进化实验室找到的改进，在这里只能留作提议。选择**复制官方空间并使用**，换到你自己的空间：它们的改进会直接生效，你自己也可以随意修改。代价是官方空间以后的更新不会自动进到你的副本里。别人分享给你的空间，点**导入 / 管理空间**导入。详见[定义空间](../the-one-app/capabilities/definition-spaces)。

## 6. 对主助手说第一件事

最后一步是**可以开始了**。写下你想让主助手做的事，选**交给主助手**，应用会回到首页，主助手在那里回答你；也可以先选**先去首页看看**。首页就是侧边栏里的**对话**。

![快速上手的最后一步](/docs-assets/images/0.5/zh/quick-start-ready.png)

## 接下来会发生什么

- 主助手马上回复你。如果这件事比一句回答大，它会开一个**事项**（出现在侧边栏的**事项**下），并在同一步把工作交给一个工作组。
- 工作组干活时，事项的看板会慢慢填满：它的提问和交付都以卡片出现。等你的那些也会出现在对话里，就在报告它的那一行下面；对话顶上那一栏写着有几件在等你（比如**等你 2 件**），侧边栏**对话**旁边的数也是它。凭你已经说过的话能答的问题，主助手会先替你答。
- 想看所有工作组此刻在做什么，打开侧边栏的**全景**，见[全景](../the-one-app/panorama)。
- 工作组交付后，主助手会对照你最初的要求检查，先告诉你结论。你用**接受**、**返工**（你的话会转给工作组）或**放弃**来评判。
- 事情办完了，就结束这个事项：在侧边栏把鼠标移到它上面，点右边的结束按钮，或者在事项页点**结束事项**。为它干的活会停在手上那一步，重新打开就接着做，见[事项与看板](../the-one-app/matters)。
- 每天第一次打开应用，或者离开一小时以上、换了一天再回来时，如果有你还没看过的新东西，主助手会先在对话里打个招呼，说上次看过以后发生了什么。点**看晨报**打开**晨报**：交付了什么、还等你什么、花了多少；点**知道了**，这一天就不再打招呼。
