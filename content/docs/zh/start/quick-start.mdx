这份指南带你从安装 The One 走到第一个事项：主助手把它交给一个工作组，你在事项的看板上跟进。

## 1. 安装并登录

从[下载页](https://the-zeroth.com/zh/download)下载 macOS 版（Apple 芯片，macOS 15 或更高）或 Windows 版，安装后用你的 The Zeroth 账号登录。在模型配置好之前，应用会打开**快速上手**（侧边栏的**上手**），带你完成下面几步。

## 2. 连接模型服务

主助手和工作组都靠模型干活，所以这一步排在最前面。

- 如果你是 The One 会员，官方连接已经在了：卡片上显示你的会员级别和剩余用量。
- 如果还不是会员，卡片上会出现**开通会员**，点它会打开控制台。在那里开通后，回到这里点**我已开通，刷新**。
- 也可以连接你自己的服务：**用 ChatGPT 账号登录**，使用你 ChatGPT 套餐里的 Codex 额度；或者填 OpenAI、Anthropic、Gemini 的 API Key。**其他服务**可以连接兼容 OpenAI 或 Anthropic 接口的服务，包括跑在你自己电脑上的模型，比如 Ollama、LM Studio。

{/* screenshot pending: ![在快速上手里连接模型服务](/docs-assets/images/0.5/zh/quick-start-connect.png) */}

各种方式的区别见[模型与价格](./models-and-pricing)，每种连接的设置见 [API 配置](../the-one-app/settings/api-configuration)。

## 3. 选默认模型

选一个默认模型：主助手和没有单独指定模型的 Agent 都用它。之后随时可以在标题栏的模型按钮或**设置 › 默认模型**里修改，那里也可以保存多套模型预设。详见[模型](../the-one-app/capabilities/models)。

## 4. 检查空间里的模型（需要时才出现）

空间里的 Agent 可以单独指定自己的模型或连接，比如别人分享给你的空间。如果其中有在你电脑上连不上的，快速上手会多出这一步并把它们列出来，给你两条路：让这些 Agent **改用默认模型**，或者连接它们指定的服务。

## 5. 准备你自己的空间（推荐）

一开始用的是官方空间。它是只读的：里面的工作组模板、角色和技能由官方维护，跟着版本更新；所以主助手和进化实验室找到的改进，在这里只能留作提议。选择**复制官方空间并使用**，换到你自己的空间：它们的改进会直接生效，你自己也可以随意修改。代价是官方空间以后的更新不会自动进到你的副本里。详见[定义空间](../the-one-app/capabilities/definition-spaces)。

## 6. 对主助手说第一件事

最后一步**可以开始了**会告诉你，记住三个地方就够了：**主助手**、**需要你**和**晨报**。写下你想让它做的事，选择**交给主助手**；也可以选择**先去首页看看**。

## 接下来会发生什么

- 主助手马上回复你。如果这件事比一句回答大，它会开一个**事项**（出现在侧边栏的**事项**下），并在同一步把工作交给一个工作组。
- 工作组干活时，事项的看板会慢慢填满：它的提问和交付都以卡片出现。它的提问也会出现在**需要你**里；凭你已经说过的话能答的，主助手会先替你答。
- 工作组交付后，主助手会对照你最初的要求检查，先告诉你结论。你用**接受**、**返工**（你的话会转给工作组）或**放弃**来评判。
- 第二天早上，**晨报**会总结交付了什么、还等你什么、花了多少。
