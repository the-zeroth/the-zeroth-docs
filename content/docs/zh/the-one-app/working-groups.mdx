工作组是为你的某个事项干活的一组 Agent：主助手把活交出去时，按一个工作组模板开出来的一次运行。你在事项的看板上跟进它，随时可以直接和它说话，并在接受之前审阅它改了什么。

## 从模板到工作组

[工作组模板](./capabilities/working-group-templates)写的是一类活怎么分工：哪些角色、谁先谁后、怎么验收。工作组就是在某个事项上干活的这个模板。主助手把事项的活交给一个模板时，The One 在这份活所在的文件夹里开一次它的运行，事项的看板上随之多出一张工作组卡片。

官方空间自带常见几类活的模板，比如：

| 模板 | 做什么 |
| --- | --- |
| `polished_software_dev` | 代码项目里的软件活。它的负责人和检查员会边做边把需求变成测试。 |
| `deep_research` | 调研和综合，可以分出几路独立收集证据。 |
| `chat` | 普通的多步活，直接用工具做。 |
| `frontend_design_studio`、`image_generation_studio`、`video_production_studio`、`blender_scene_studio` | 网页设计、图片、视频和 3D 场景的工作室。 |
| `storefront_studio`、`store_operator`、`store_reviewer` | 一人公司：店面、日常经营和每周复盘。 |
| `site_deployment_ops` | 网站上线，最后有一道独立的验收。 |
| `atlas` | 写新的模板、角色、技能和插件。 |
| `self_evolution_lab` | 做进化事项的实验室。见[进化：实验室和夜间复盘](./evolution)。 |

一个工作组可以接不止一份活。你在同一个事项上又要别的东西时，主助手会交给已经在上面的那个组，它学到的东西都还在。在一个事项上干活的组，也可以在交回手上的活以后接别的事项的活（见下面）。**能力**页上的**正在为事项干活的模板**列出了此刻在干活的模板。

## 工作组卡片

事项上的每个工作组，在看板的**工作组**一栏里都有一张卡片，上面写着：

- 状态：**在做**、**在提问**、**已交付**、**失败了**、**没开始**或**排队中**。
- **交给它的活**：交给它的是什么。
- **文件夹**：它在哪里干活。它的消息和交付里的相对路径都从这里打开。
- 最后是谁跟它说话，比如**最后是你跟它说话**或**最后是主助手跟它说话**。
- 别的工作组给它写的话，比如“工作组「…」问了它一件事”。
- 它替几个事项干活时，这件事的活排在哪里；以及哪些成员一直在出错。

卡片上的按钮有**和这个组说话**、**暂停**或**继续**，需要时还有**先做这个**和**现在重试**。

## 工作组页

侧边栏的工作组页按事项列出这个空间里开着的事项上的工作组，等你的事项排在前面；子事项上的工作组只显示在它们的看板上。每个组写着名字、状态、交给它的活和最后是谁跟它说话；可以直接和它说话，也可以按**去看板**打开它的事项。这一页读的就是各个看板上的卡片，所以和看板说的总是一样。

## 和工作组说话

按“和这个组说话”，会在窗口右边打开接了这份活的那个 Agent 的对话。你在这里写的话直接发给这个组，算你自己的话，看板随即写上最后是你跟它说话。主助手也看得到：从这时起，这个组的提问它留给你，不再自己答。

在对话里，你的话显示成你的消息。从别处送来的消息显示成写明来源的卡片：主助手交下来的活写着**主助手**，还有**另一个工作组**、**触发器**等等。谁让这个组做了什么，一眼就能看出来。

提问卡上的**去回答**、交付卡上的**打开对话**，打开的是提问或交付的那个 Agent 的对话，它可能是组里的另一个成员。打开它，就算你看过了这个组交回的东西。

你写话时，如果这个组正在做别的事项的活，发出去的话会显示**已留给它**：它所在的工作组回到这个事项的活时就会收到。

## 暂停、继续和重试

- “暂停”是协作式的：每个成员做完手上这一步再停。它为别的事项做的活也一起停。“继续”让它接着做。
- 出错的 Agent 不会放弃，而是自己重试，每次等得更久一些，最长十分钟试一次；服务商说了什么时候再试的，就等到那时。卡片上写着哪个成员在出错、遇到了什么、从什么时候开始、下次什么时候重试。按“现在重试”，出错的成员会马上接着做。
- 只有你能解决的问题（密钥被拒、没有权限、套餐不含这项用量），卡片上给的是**打开这个连接**。如果是这个连接的密钥或登录被拒，你在那里换好以后，出错的成员几秒内就会重试。
- 想一下子停下所有东西，用应用菜单或托盘里的**急停所有 Agent**。详见[行动记录、撤回和急停](./action-log)。

工作组的卡片还写着在做，可里面两分钟都没有动静，或者成员十分钟来只在重试错误，主助手就会收到通知，由它决定下一步怎么办。见[主助手](./main-assistant)。

## 一个组，几个事项

对某类活很熟的工作组，可以替几个事项干活。它一次只做一个事项，其他事项的活在它的队列里等着，那些事项的看板会在组卡上写明：

| 卡片上写着 | 意思 |
| --- | --- |
| **排在下一个**，或者前面还有几件 | 这份活在排队。这一行也写着它眼下在做哪个事项。 |
| **有一条话在等它**或**有一个回答在等它** | 给这个事项的话，等组回到这个事项时才送到。 |
| **先放下了，等你回答** | 组在这里问了你一件事，等你回答的时候先去做别的事项。你一回答，这份活就排到它队列的前头。 |
| **停在了你给这个事项设的边界，等你恢复** | 这个事项的活停在了用量边界上，这期间组去做别的事项。 |
| **插到了最前面** | 你按了“先做这个”。 |

“先做这个”在这个事项的活、话或回答排着、而组正在做别的事项时出现。组做完手上这一步，先来做这个事项的活，做完再回去接着做原来的。

## 工作组之间

一个工作组读写它所在事项的看板，以及上面、下面和旁边那些事项的看板。别人需要知道的事实、决定和清单都写在卡片上，不用经主助手转达。工作组之间也可以直接写信：问一件事、请对方做一件事、回复，或者说对方的回复还有没做到的。收到信的那个组，卡片上会写出来，比如“工作组「…」问了它一件事”；在它的对话里，这条消息标着“另一个工作组”。请对方做事的信，要等对方歇下来才送到，不会插在它手上的活中间。这些都不会叫醒主助手。

## 工作组内部

大一点的模板有一个负责人，它可以把活再拆开：用 TaskBoard 分给几个工人，或者为其中一部分开一个子图，也就是一个更小的团队。这些都算这个组自己的活：花的、改的和问的都算在这个组的事项上，剧场里也显示在这个组下面。有自己目标和交付的部分，可以开成有自己看板的子事项；见[事项与看板](./matters)。

## 剧场

有工作组在做这个事项以后，看板上方的开关可以切到**剧场**：一屏看清所有工作组的 Agent 在做什么。每个工作组一个分区，名字和它的卡片一样，它的子图在里面。最上面一条显示每个 TaskBoard 的进度，以及有几个 Agent 在干活、等你、在等别人、出错、空闲或已停。

- 每个 Agent 一条泳道，排在一根到“现在”为止的时间轴上（往前看 **5 分钟**、**15 分钟**或 **1 小时**），状态是**在想**、**在调工具**、**等你**、**等别人**、**出错**、**空闲**或**已停**之一；旁边一句话写它此刻在做什么。Agent 之间的交接画成箭头。
- 点泳道上的一段，能看到它的起止时间、每次工具调用的人话说明、原始的工具名和参数。
- **实时小窗**显示 Agent 正在写的字、正在跑的命令的最后几行输出，以及它最近看到的画面：默认两个，从正在干活的 Agent 里挑，最多可以钉住四个。
- 点一个 Agent 打开它的对话，和点工作组卡片一样。

剧场只管看：不加任何审批、暂停或上限。

## 审阅

事项页头上的**审阅**显示每个工作组做了什么，一次看一个组；有好几个组时，在上面选一个。接受、拒绝和撤回都只动这个组自己的运行。

- **改动**按块列出这个组的 Agent 改过的文件，写明每一块是谁改的：默认是这份活开始以来的改动（**本次任务**），也可以看这次运行从头以来的（**整个会话**）。每块可以**接受**、**拒绝**或**批注**（键盘：**j** / **k** 上下移动，**a**、**x**、**c** 标记）。然后**提交审阅**，三选一：**只发意见**、**接受交付**或**要求返工**。拒绝的块会写回磁盘上的文件，这次写回本身也能撤回。改过这些地方的 Agent 会收到你的审阅意见；要求返工时，组的负责人也会收到。
- **产物**列出这个组做出来的文件，Markdown、PDF、网页、图片、音视频和代码都能在应用里直接看。网页在沙盒里运行。
- **视觉验收**一轮轮显示它的 Agent 跑过的视觉检查。

审阅是事后的：它从不叫停 Agent，你看的时候它们照常干活。

## 为一份活换模型

想让某份活用别的模型做时，直接说，比如“这件事用最强的那套预设”。主助手可以给这个组的这次运行换用别的模型预设，整组换或者只换其中某个成员，都不用改模板（见[模型](./capabilities/models)）。这只对这一次运行有效；已经在干活的组不换模型。想让以后每次运行都换，就把预设绑到角色或模板上（见[角色](./capabilities/roles)）。
