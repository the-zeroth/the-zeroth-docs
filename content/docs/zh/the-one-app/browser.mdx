Agent 上网用的是 The One 自带的浏览器。它打开的网页就是应用里的真标签页：它在网页上点了什么、填了什么、提交了什么，你都看得到；你一动手，它这一步就停下，网页交到你手里。

## 打开浏览器

点侧边栏**全景**下面的**浏览器**。有 Agent 正在用它时，这一项右边淡淡地写着**在用**。浏览器只在桌面应用里有。

页面最上面是这个空间的浏览器里开着的标签，下面是后退、前进、刷新和地址栏，再往下是选中的那个标签。地址栏右边写着现在谁在操作：**Agent 正在操作**、**你在操作：Agent 下一步会知道你接手了**，或者**空闲**。

- 点一个标签看它，点标签上的 ✕ 关掉它。
- 在地址栏里输入网址，回车打开。
- 还没有开着的网页时，页面写着**还没有打开的网页。Agent 用浏览器时，网页会出现在这里。**

没人看着的标签照常运行，显示器睡着时也一样，所以你离开时 Agent 照样能上网。

## 接手

你在一个标签里点击、按键、滚动、输入地址或者关掉它，Agent 在这个标签里正在做的那一步马上停下；它在这个标签里的下一步，开头会被告知你用过这个标签，让它先重新看一眼页面。别的标签里的 Agent 不受影响。这是交接，不是拦截：没有什么会拦下或询问 Agent 的操作。

一个空间里的几个 Agent 可以同时用浏览器，各用各的标签，各自只听到自己标签里发生的事。

Agent 读到的网页文字都标明是网站的内容，不是你说的话，并提醒它不要照着网页里的指示去做。

## 登录和清空

每个空间一个浏览器，各有各的 Cookie、网站数据和登录，重启应用后还在。在这里登录过的网站，Agent 就能以你的身份用。网站要摄像头、麦克风或位置时，一律不给。

右上角的**清空这个空间的浏览器**会先问一次（**清空浏览器？**），再关掉所有标签，删掉这个空间浏览器里的 Cookie、网站数据和登录。Agent 已经在网站上做了的事（提交的表单、发出的消息）撤不回来。

## 记在行动记录里

Agent 拿着一个标签的那一步里，网页向网站发出的写请求（GET、HEAD、OPTIONS 以外的请求，比如提交表单）随这次调用记进行动记录：方法、地址和是哪个标签，地址里的查询参数只留名字。网站收到的东西撤不回，所以这些调用标着**向网络提交数据**，周报的**撤回不了的动作**里也列着；它们不会当场提醒你，因为很多网页自己就会不停地发统计请求。你自己在标签里操作时发出的请求不算 Agent 的，不记。见[行动记录、撤回和急停](./action-log)。

## 用你自己的 Chrome

Google 账号在这个浏览器里登录不了。要让 Agent 用你自己 Chrome 里的登录（比如 Google 账号或公司的系统），用官方空间带的外部工具服务器 **Your Chrome**：它连到你正在用的 Chrome（144 及以上）。在 Chrome 里打开 `chrome://inspect/#remote-debugging`，打开远程调试；之后每次连接，Chrome 都会问你一次要不要允许。不用装扩展，也不用配对。Chrome 没开、或者没打开远程调试时，Agent 会收到这样的说明，可以转告你。

在官方空间和跟着它更新的副本里，主助手和通用工作组的助手能用全部外部工具，包括它；要给别的角色用，在你自己的空间里把它加给那个角色（见[外部工具（MCP）](./capabilities/mcp)）。

## 谁在用

官方空间里上网的角色都用这个浏览器：软件团队的负责人、研究组的深度网页研究员、前端设计组的三个角色、三维场景组的导演和评审、建站上线组的两个角色、网店门面组的搭建者和验收者，以及产品体验评估组的三个角色。主助手和通用工作组的助手不把浏览器的工具放在每次请求里，要用时先搜出来。

在你自己的空间里，在角色编辑页**能力**标签的**工具**里加上 `browser`，这个角色就能用浏览器（见[角色](./capabilities/roles)）。

0.5.3 以前复制出来的空间不跟着官方更新：那里的角色照旧用原来的 Chrome DevTools 服务器，它自己开一个 Chrome，你在 The One 里看不到。想换成这个浏览器，就在角色编辑页里给它们加上 `browser`，或者让主助手去改。
