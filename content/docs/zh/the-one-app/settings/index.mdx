**设置**决定 The One 在你电脑上怎么运行：账号和版本更新、界面外观、Agent 默认用哪个模型、磁盘空间和记忆搜索、关掉窗口后后台还做什么，以及和模型服务、手机、其他程序的连接。从侧边栏最下面打开，默认停在**通用**。

活儿用什么来做，比如工作组模板、角色、技能、插件和定义空间，不在这里，而在[能力](../capabilities)里。

## 通用

- **账号**：当前登录的邮箱，是个人账号还是组织账号，以及**退出登录**。
- **语言**：**界面语言**，简体中文或 English。选择保存在本机，之后就用你选的，不再跟随系统语言。
- **版本更新**：当前版本和发布日期。应用启动后会自动检查更新，并在后台下载新版本。**检查更新**立即查一次；下载好后点**安装并重启**，会停掉后端服务并重启应用。
- **使用统计**：**统计功能使用次数（内测）**按天统计你打开了哪些页面、启动了哪些内置应用。默认关闭，只记次数、存在本机，不记内容、文件名或对话。
- **维护工具**：**导出诊断包**把运行日志和诊断信息导出成一个文件，方便发给支持排查。**重启后端**重启 The One 的本地服务，应用提示某项改动需要它时再用。

## 外观

选择**跟随系统**、**浅色**或**深色**（默认是深色）。浅色用**宣纸**，深色用**墨夜**；也可以在**配色方案**里给浅色、深色各换一套，另有九套预设可选。

**复制修改**会复制一套方案给你改：7 个基础色，从底色、文字、主色，到表示“等你”“在跑”“已交付”“出错”的颜色，边改边按 WCAG AA 检查对比度；没达标也能保存。**复制配色 JSON** 和**导入…**可以把方案带到另一台电脑。

## 默认模型

**模型预设**把模型、走哪个连接和推理设置存成一套，服务等级在**高级参数**里。没单独绑预设的 Agent、Graph 和会话，都用标着**全局默认**的那一套；改了预设，从它们的下一轮起生效。标题栏的模型按钮可以直接切换全局默认，里面的**管理模型预设**打开同一个编辑器。详见[模型](../capabilities/models)。

## 存储空间

这一页列出应用数据各占多少磁盘：数据库、命令输出、工具结果、日志、行动记录与回收站、证据包、发出的请求，并写明各自保留多久。剩余空间不多时，标题栏会提醒，正在干活的 Agent 也会收到提示；再少就进入保护模式：不再保存完整命令输出和数据库快照，并立即清理过期文件。Agent 照常运行。

**插件工作区**是插件保存的下载内容、渲染结果和浏览器数据，**清空**会永久删除。这一页也统计 Agent 在应用外留下的 Docker 数据和 git worktree，但应用从不删除它们，只给出命令，由你复制到终端自己运行。

## 记忆召回

Agent 搜索记忆、项目知识和以前会话的结论时，结果按意思排序，而不只看字面。在**嵌入模型**里选由谁来做：

- **自动（推荐）**：依次用第一个能用的：本机 Ollama 或 LM Studio 的嵌入模型、默认服务商的嵌入接口、内置模型。
- **内置模型**：在这台电脑上运行，不需要任何 API，第一次用时下载。
- **服务商连接**：用某个连接的嵌入接口；记忆和知识的文本会发给这个服务商。
- **自定义地址**：任何不需要密钥的 OpenAI 兼容嵌入地址。
- **关闭**：只按关键词排序。

**重建索引**会清空已算好的向量，最近 30 天搜索过的范围在后台重新索引。详见[记忆与召回](../capabilities/memory)。

## 行动记录

Agent 每次调用工具都记在这里：新建、修改、删除了哪些文件，访问了哪些地址，结果如何。文件被删除或覆盖前会先留一份副本，所以在副本保留期内（7 天），你可以**撤回**一整次运行、一次调用，或者某个时间之后的全部改动。发生在本机以外的事会列出来，但撤回不了。行动记录覆盖这台电脑上的所有 Space，而且只记录和撤回，从不拦下任何操作。详见[行动记录、撤回和急停](../action-log)。

## 常驻与触发

触发器在到点、有新东西出现（经插件工具来的新订单或新邮件、文件夹里的文件、网页、命令的输出），或者外面发来 Webhook 时叫醒 Agent，人不在电脑前也照常。一般只要说一句，比如“每天 8 点整理一下邮件”，Agent 就会自己建好触发器。在这里可以查看、修改和试一下（**现在触发**），也可以**新建触发器**或**暂停所有**。

**常驻**里有三个开关：**关掉窗口后留在后台运行**（在 Windows 上起作用；macOS 上关掉窗口后应用本来就继续运行，这个开关一直开着）、**开机时在后台启动**，以及**有触发器在等时不让电脑睡**（只在接着电源时有效）。**Webhook 入口**只在本机收请求，默认端口 8013。详见[触发器和后台常驻](../triggers)。

## 随身通道

通过你在 Agent Room 的私人房间，在手机上把活交给主助手、回答 Agent 主动问的问题、看做完的结果。它需要 **Agent Room Channel** 插件。把房间里的邀请文字或 Agent 口令粘进来，点**连接**；再在**绑定你的账号**里生成配对码，发到房间里，之后 The One 只听你一个人的。详见[随身通道和对外调用](../remote)。

## 对外调用

让这台电脑上的 Claude Code、Codex、会说 A2A 的 agent 或你自己的脚本把你的团队当工具用：列出团队、派活、等它交付、回答它的提问。每个程序用一个自己的令牌：**发令牌**只显示一次，同时给出 Claude Code 和 Codex 的配置命令；**安装 the-one** 装上一个命令行工具。调用只在本机接收，默认端口 8014。拿到令牌的程序能让你的团队在这台电脑上做它们能做的任何事，所以只给信得过的程序，不用了就**撤销**。详见[随身通道和对外调用](../remote)。

## API 配置

Agent 发模型请求所走的连接：随 The One 会员提供的官方连接、用 ChatGPT 账号登录、OpenAI、Anthropic、Google Gemini 的 API Key，以及自定义提供商（包括你自己电脑上的模型）。详见 [API 配置](./api-configuration)。

## 所有运行

当前 Space 里每一次运行的开发者视图，包括各个工作组的运行，细到每个 Agent 的消息、上下文和工具。主助手自己的对话不在这里，在首页。详见[所有运行（开发者视图）](./all-runs)。

## 应用菜单和托盘

应用菜单（macOS 上是菜单栏里的 **The One** 菜单）里有**打开日志**（Cmd+L）、**导出诊断包**、**检查更新**、**安装已下载更新**、**重启后端**、**急停所有 Agent**（Cmd+Shift+.）、**退出登录**和**退出**。Windows 上菜单栏是隐藏的：急停用托盘菜单，诊断包、更新和重启后端在设置 › 通用里。

macOS 菜单栏或 Windows 系统托盘里 The One 图标的菜单中也有**急停所有 Agent**。它会中断所有 Agent、结束它们启动的命令，并暂停所有运行和触发器，直到你恢复。详见[行动记录、撤回和急停](../action-log)。

## 键盘快捷键

在没有打字的地方按 **?**，或者按 Cmd+/（Windows 上是 Ctrl+/），就能看到所有快捷键；标题栏的**查看设置**菜单里也有**键盘快捷键**。下面这些在任何地方都能用：

| 按键 | 作用 |
| --- | --- |
| F6 / Shift+F6 | 跳到窗口的下一个或上一个区域 |
| Cmd+K（Ctrl+K） | 跳到这一页的搜索框 |
| Shift+Esc | 跳到输入框 |
| Cmd+Shift+A（Ctrl+Shift+A） | 打开应用菜单 |
| Esc | 关掉弹窗、菜单或抽屉 |

macOS 上应用菜单另有两个：Cmd+L 打开日志，Cmd+Shift+. 急停所有 Agent。

快捷键表里还有会话列表和预设列表、输入框、审阅栏，以及编辑器和画布的快捷键。
