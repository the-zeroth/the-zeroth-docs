**设置**决定 The One 在你电脑上怎么运行：账号和版本更新、界面外观、和模型服务的连接以及 Agent 默认用哪个模型、关掉窗口后后台还做什么、手机和其他程序、Agent 改了什么和应用占了多少磁盘，以及开发者看的东西。从侧边栏最下面打开，默认停在**通用**。

活儿用什么来做，比如工作组、角色、技能和插件，不在这里，而在[团队与工具](../capabilities)里。

设置分六节。每一节打开时停在它的第一页；一节里有几页时，页面上面写着这几页，比如**通用**和**外观**。

| 节 | 里面的页 |
| --- | --- |
| **通用** | **通用**、**外观** |
| **模型和登录** | **模型连接**、**默认模型** |
| **自动做事** | **常驻与触发** |
| **手机和别的程序** | **随身通道**、**对外调用** |
| **数据和撤销** | **行动记录**、**存储空间**、**记忆召回** |
| **开发者** | **开发者视图**、**评测** |

## 通用

### 通用

- **账号**：当前登录的邮箱，是个人账号还是组织账号，以及**退出登录**。
- **语言**：**界面语言**，简体中文或 English。选择保存在本机，之后就用你选的，不再跟随系统语言。
- **版本更新**：当前版本和发布日期。应用启动后会自动检查更新，并在后台下载新版本，下载时标题栏上显示进度。**检查更新**立即查一次；下载好后点这里的**安装并重启**，或者标题栏上的**安装更新**，会停掉后端服务并重启应用。
- **使用统计**：**统计功能使用次数（内测）**按天统计你打开了哪些页面、启动了哪些内置应用。默认关闭，只记次数、存在本机，不记内容、文件名或对话。
- **维护工具**：**导出诊断包**把运行日志和诊断信息导出成一个文件，方便发给支持排查。**重启后端**重启 The One 的本地服务，应用提示某项改动需要它时再用。

### 外观

先选明暗：**跟随系统**、**浅色**或**深色**，默认是浅色。浅色用**素白**，白底黑字、不带色调；深色用**石墨**，中性的深灰。

再在**配色方案**里给浅色、深色各选一套。除了素白和石墨，还有 11 套现成的配色：浅色的**宣纸**、**月白**、**青瓷**、**藕荷**、**霜雪**，深色的**墨夜**、**黛蓝**、**松烟**、**朱漆**、**丁香**、**烟雨**。宣纸和墨夜是以前的默认配色。

想要自己的配色，在一套现成的上点**复制修改**，或者在列表下面点**基于「素白」新建**（深色那边是**基于「石墨」新建**）；做好的配色以后点**编辑**再改。一套配色有 7 个基础色：底色、文字、主色，以及表示“等你”“在跑”“已交付”“出错”的颜色，其余颜色由它们推出。边改边按 WCAG AA 检查对比度，没达标也能保存。编辑器里的**复制配色 JSON**和**导入…**可以把一套配色带到另一台电脑。

## 模型和登录

### 模型连接

Agent 发模型请求所走的连接：随 The One 会员提供的官方连接、用 ChatGPT 账号登录、OpenAI、Anthropic、Google Gemini 的 API Key，以及自定义提供商（包括你自己电脑上的模型）。详见[模型连接](./api-configuration)。

### 默认模型

**模型预设**把模型、走哪个连接和推理设置存成一套；没单独指定模型的 Agent 都用标着**全局默认**的那一套。详见[模型](../capabilities/models)。

## 自动做事

这一节就是**常驻与触发**页：查看、修改、试一下和新建叫醒 Agent 的触发器，以及关掉窗口后让 The One 留在后台的几个开关。详见[触发器和后台常驻](../triggers)。

## 手机和别的程序

### 随身通道

通过你在 Agent Room 的私人房间，在手机上给主助手派活、回答 Agent 的提问、看交付。详见[随身通道和对外调用](../remote)。

### 对外调用

让这台电脑上的 Claude Code、Codex、会说 A2A 的 agent 或你的脚本，凭各自的令牌把你的团队当工具用。拿到令牌的程序能让你的团队做它们能做的任何事，所以只给信得过的程序。详见[随身通道和对外调用](../remote)。

## 数据和撤销

### 行动记录

Agent 每次调用工具都记在这里，被删改的文件在保留期内可以放回；它只记录和撤回，从不拦下任何操作。详见[行动记录、撤回和急停](../action-log)。

### 存储空间

这一页列出应用数据各占多少磁盘：数据库、命令输出、工具结果、日志、行动记录与回收站、证据包、发出的请求，并写明各自保留多久。剩余空间不多时，标题栏会提醒，正在干活的 Agent 也会收到提示；再少就进入保护模式：不再保存完整命令输出和数据库快照，并立即清理过期文件。Agent 照常运行。

**插件工作区**是插件保存的下载内容、渲染结果和浏览器数据，**清空**会永久删除。这一页也统计 Agent 在应用外留下的 Docker 数据和 git worktree，但应用从不删除它们，只给出命令，由你复制到终端自己运行。

### 记忆召回

选由哪个**嵌入模型**给记忆、项目知识和以前会话的结论按意思排序，也可以重建索引。详见[记忆与召回](../capabilities/memory)。

## 开发者

### 开发者视图

**开发者视图**页上的开关**显示开发者看的东西**默认关着。打开以后，同样的数据按开发者看的样子画出来：主助手的对话里显示它的系统提示、写给模型的通知原文、每次工具调用的参数和结果；事项页、等你的卡片和周报的消息记录里显示编号；团队与工具里多出总图、空间、所有运行和评测。只换显示，不换数据。在任何地方按 Cmd+Shift+D（Windows 上是 Ctrl+Shift+D）都能打开或关上它；打开时标题栏上写着**开发者视图**，点一下就关上。

开关下面的**打开所有运行**带你去所有运行：当前空间里的每一次运行，包括各个工作组的运行，细到每个 Agent 的消息、上下文和工具。主助手自己的对话不在这里，在首页。详见[所有运行（开发者视图）](./all-runs)。

## 应用菜单和托盘

### 应用菜单

macOS 菜单栏里的 **The One** 菜单有**打开日志**（Cmd+L）、**导出诊断包**、**检查更新**、**安装已下载更新**、**重启后端**、**急停所有 Agent**（Cmd+Shift+.）、**退出登录**和**退出**。旁边的**视图**菜单有**重新加载**、**开发者工具**和缩放，**编辑**菜单是常用的撤销、剪切、复制和粘贴。

Windows 上菜单栏是隐藏的：急停用托盘菜单，诊断包、更新和重启后端在**设置 › 通用**里。

### 托盘菜单

The One 的图标在 macOS 菜单栏或 Windows 系统托盘里。macOS 上图标旁写着有几件事在等你，和侧边栏**对话**旁边的数一样；Windows 上单击图标打开主助手的对话。图标的菜单里依次有：

- 还没处理的提问、完成和失败各有几个（**未处理：**……；都处理了时写**没有未处理的提问和结果**），下面最多列出五条，点一条就打开它：工作组的到[所有运行](./all-runs)里发出它的那个 Agent，主助手的回首页。
- 有触发器时，一行写着几个在等、下一次是什么时候，点它打开**常驻与触发**；下面是**暂停所有触发器**（暂停时是**恢复所有触发器**）。
- **去对话看等你的事**打开主助手的对话，等你的事都在对话上方那一条里；**显示 The One**把窗口叫到前面。
- **急停所有 Agent**和**退出**。

**急停所有 Agent**先要你确认，然后中断所有 Agent、结束它们启动的命令，并暂停所有运行和触发器，直到你恢复。详见[行动记录、撤回和急停](../action-log)。

### 窗口左上角的 … 菜单

窗口左上角的 **…** 菜单写着版本、发布日期和更新状态，里面有**检查更新**（新版本下载好后换成**安装并重启**）、**打开官网**、**放大**、**缩小**、**重置缩放**和**键盘快捷键**。

## 键盘快捷键

在没有打字的地方按 **?**，或者按 Cmd+/（Windows 上是 Ctrl+/），就能看到所有快捷键；窗口左上角的 **…** 菜单里也有**键盘快捷键**。下面这些在任何地方都能用：

| 按键 | 作用 |
| --- | --- |
| F6 / Shift+F6 | 跳到窗口的下一个或上一个区域 |
| Cmd+K 或 Cmd+F（Ctrl+K 或 Ctrl+F） | 跳到这一页的搜索框 |
| Shift+Esc | 跳到输入框 |
| Cmd+Shift+A（Ctrl+Shift+A） | 打开侧边栏**应用**的快速菜单；插件带来了能打开的应用时才有，见[插件与应用](../capabilities/plugins) |
| Cmd+Shift+D（Ctrl+Shift+D） | 打开或关上开发者视图 |
| Esc | 关掉弹窗、菜单或抽屉 |

macOS 上，应用菜单另有两个：Cmd+L 打开日志，Cmd+Shift+. 急停所有 Agent。

快捷键表里还有会话列表和预设列表、输入框和回答、审阅栏，以及编辑器和画布的快捷键。
