**所有运行**是开发者看 The One 干活的地方：当前 Space 里的每一次运行，包括各个工作组的运行，细到每个 Agent 的完整上下文。平时你在[全景](../panorama)和事项的看板、剧场里跟进工作；想看清某个 Agent 读了什么、写了什么、调了什么，想介入一次运行，或者想自己启动一个 Graph，就来这里。

用**设置 › 开发者**里的**打开所有运行**打开它；打开开发者视图时，[团队与工具](../capabilities)上的**所有运行**也能打开它。在周报的**消息记录**、系统通知或托盘菜单里点开一条，也会来到这里，停在发出它的那个 Agent 上；主助手发出的则打开首页。从侧边栏**应用**打开一个在 The One 里显示的应用时，也会来到这里，应用作为一个标签停在 Agent 名册那一栏。

![所有运行：会话列表、一个工作组的运行和 Agent 名册](/docs-assets/images/0.5/zh/all-runs-run-view.png)

## 会话列表

左边一栏叫**工作区**，最上面是**和主助手说**（回到首页）和**新建 Graph**，下面是搜索会话或项目的搜索框，可以按运行状态、**只看置顶**和**包含已归档**筛选。再往下：

- **项目**：你列表里的项目文件夹，每个下面是在这个文件夹里干活的运行；子 Graph 排在拉起它的那次运行下面。新建 Graph 时选过的文件夹会加进列表。项目那一行可以在这个项目下新建 Graph、删掉它下面所有的 Graph，或者把它从列表里拿掉。
- **对话助手**：以前的对话会话，只在还有的时候出现。
- **Atlas 会话**：你和总图导演的对话，点开会去[总图](../capabilities/atlas)。
- **未归入项目**：文件夹不在上面列表里的运行，比如工作组在别的文件夹里开的，以及没指定文件夹、在应用数据文件夹里干活的。
- **已归档**：你归档的运行。第一次打开 0.5.0 时，以前的会话（正在跑的和置顶的除外）都移到了这里，仍可打开或恢复。

主助手自己的对话不在列表里，它在首页。每一行的菜单里有**在分组内置顶**、**重命名**、**归档**、**复制工作流 ID** 和**删除**。归档只是收拾列表；删除会连同子 Graph 一起删掉，相关的执行记录和会话数据也一并删除。

## 自己启动一个 Graph

**新建 Graph** 不经过主助手，直接把任务交给某一个 Graph：

1. **选择一个 blueprint**：要运行的 Graph。软件团队 `polished_software_dev` 排在最前面，标着**出厂软件团队**。
2. **项目和任务**：**项目根目录（可选）**是运行干活的文件夹；不指定时，它在应用的数据文件夹里干活。**任务（可不填）**会作为你的消息发给 Graph 的第一个 Agent，运行随之开始：写了任务，按钮是**开始任务**，按 Cmd/Ctrl+Enter 也行。不填任务时按钮是**创建 Graph**，只建好运行，由你自己给 Agent 发消息。

**运行它需要什么**会检查这个 Graph 用到的一切：模型、连接、Agent 预设、Prompt、Skill、MCP 服务器和插件，并说明缺了哪一样运行建不起来、哪一样会让模型请求失败、哪一样缺了照样跑。无论如何都可以创建。运行用的是最后保存的 Graph。

这样开的运行不属于任何事项：你写的任务就是它的使命，交付在运行顶部的**使命**一栏里验收（见下面），它的提问和交付也出现在对话上方等你的那一条里。

![新建 Graph，以及运行它需要什么](/docs-assets/images/0.5/zh/all-runs-new-graph.png)

## 看一次运行

顶部写着运行的名字、它的状态（比如**执行中**、**等待唤醒**、**已冻结**）和它来自哪个模板，还有：

- **对话** / **剧场**：看选中 Agent 的对话，或一屏看全队。
- **冻结** / **解冻**和**取消工作流**，见下面的[冻结与停止](#冻结与停止)。
- **Session 默认模型**：只给这次运行换一个模型，只影响用默认模型的 Agent。
- **运行控制**：重试、恢复和用量边界。
- 这次运行到目前为止用了多少 tokens。

运行有了使命（你或主助手交给它的那件事）后，下面多出**使命**一栏：写着要做什么、现在怎样（进行中、第几次交付等你验收、已接受等），附上这次交付的**证据包**，以及**接受**、**返工**、**放弃**，能按哪几个随状态而变。在这里点**返工**只是记下来，要改什么，直接在下面的输入框里告诉 Agent；**放弃**会再问你一次，记成放弃后不再等它交付，Agent 不会被叫停。验收和证据包见[等你和交付](../needs-you)。

再往下是**工作链**（一开始是收起的），一步步画出谁唤醒了谁，包括运行在哪里等过你。

右边的 **Agent 名册**列出这次运行里的每个 Agent，以及各自的 LLM 调用次数、工具调用次数、tokens、上下文窗口用了多少和推理强度。可以按**默认顺序**或**最近运行**排。鼠标移到一行上会出现几个按钮：**隐藏**让它不在名册里显示（**显示已隐藏**再找回来）；**删除 agent** 要再点一次确认，然后把它从 Graph 里摘掉，子 Graph 那一行的删除会删掉整个子 Graph。子 Graph 就地展开，点**返回父图**回来。出错的 Agent 会带一个标记，可以**全部恢复**，**跳到下一个异常**帮你找到它们。**查看 Graph 拓扑图**显示实时的节点和连线。

**剧场**给每个 Agent 一条泳道：在想、在调工具、等你、等别人、出错、空闲或已停，Agent 之间的交接画在泳道之间，时间轴可选最近 5 分钟、15 分钟或 1 小时。点泳道上的一段，能看到这段的工具调用，原始的工具名和参数都在。**实时小窗**显示几个 Agent 正在写的字、命令的输出和最新看到的画面，最多可以钉住 4 个。事项页上看全部[工作组](../working-groups)的剧场就是同一个。

## 查看一个 Agent

在名册或工作链里选一个 Agent，它的视图有五个标签：

| 标签 | 内容 |
| --- | --- |
| **消息** | 它的推理、每次工具调用的参数和结果，以及**已冥想**标记：它在哪里压缩了自己的上下文，压缩前后各有多少条消息。每条回复都能打开它答的那次请求。 |
| **成果** | 它的消息里交出的文件、图片、链接和代码，可以预览。 |
| **上下文** | 它的上下文槽和上下文模式、系统提示词、下一次请求发出去时的完整样子（**发送视图**），以及最近**发出的请求**。 |
| **工具** | 它能调用的工具和各自的 JSON schema。 |
| **共享数据** | Graph 共享给它的数据。 |

服务商拒绝了它的 Key 或登录，或者用策略挡下了它的请求时，这个视图上方会写明原因和该怎么办；**运行控制**里也列着每个出错 Agent 的原因。官方连接的额度用完时，两处都写官方连接的额度用完了，链接打开账户的订阅页。几种拒绝各怎么处理，见[模型连接](./api-configuration#服务商拒绝时)。

## 随时介入

- **给任何 Agent 发消息**：在它的消息下面的输入框里写，可以拖入、粘贴或添加图片和文件。它的提问、确认和选择就停在输入框上方；这些也会出现在对话上方等你的那一条里，工作组的还会上事项的看板。你对工作组说的话算你自己的话，主助手会看到你正在和这个组直接说。
- **中断当前 Agent** 让这个 Agent 停下手上的事；你再给它发消息，它就接着干。
- **编辑**你自己发过的一条消息，点**保存并重发**：这条之后的消息都会丢弃并重新生成。
- 在任意一条消息处**派生分支**，会在同一个 Graph 里生成一个新 Agent，历史保留到这条消息为止。它没有连线，你给它发消息之前什么都不做；原来的 Agent 不受影响。

## 冻结与停止

- **冻结**让这次运行和它的子 Graph 在下一个安全点停下，也就是等正在进行的模型和工具调用返回之后；**解冻**让它接着跑。丢失了执行进程的运行会改为显示**恢复工作流**。
- **取消工作流**要你确认，然后停下这次运行，会话和历史都保留着供查看。
- 出错的 Agent 会持续退避重试，间隔最长 10 分钟；服务商要它多等时（比如用量窗口用完了）就等得更久。**运行控制**里列出它们，**立即重试待恢复 Agent** 马上再试一次。冻结会停止自动重试。
- **运行控制**里的**用量边界**：一次运行在无人介入时用到这么多 tokens 就暂停，可以只对这个 Graph，也可以对所有 Graph。用到 80% 时它的 Agent 会先收到提示；恢复运行就重新获得同样的额度。
- 应用菜单或托盘里的**急停所有 Agent**一次停下全部。详见[行动记录、撤回和急停](../action-log)。

## 审阅栏

运行改过文件或做过视觉验收时，Agent 名册旁边会出现**审阅**：

- **改动**：这次运行的 Agent 改过的每个文件，按块列出，每块写明是谁改的。逐块接受、拒绝或批注（J、K 切换上一块下一块，A 接受，X 拒绝，C 批注）。**审阅范围**可选**本次任务**或**整个会话**。
- **产物**：Agent 做出来或改过、留下来的文件，Markdown、PDF、网页、图片、音视频和代码都能在应用里直接看。
- **视觉验收**：Agent 每次用 Visual Check 插件对比或检查页面的记录。

改动看完后点**提交审阅**（Cmd/Ctrl+Enter），在打开的面板里选**审阅结论**：

- **只发意见**：把你拒绝的块写回改之前的样子，把批注发给改动它们的 Agent，不记结论。
- **接受交付**：在使命上记下“接受”；有批注的照样发给 Agent。
- **要求返工**：在使命上记下“返工”，负责人和改过文件的 Agent 都会收到你的意见。

运行还没有使命、或者使命还没交付过时，不记结论，只写回和发意见。还可以写一段**总的意见**，它放在每条消息的开头，也记进结论。面板会先列出提交后要做什么：写回哪几块、发给谁；已经做完的 Agent 的意见交给它的负责人。写回之后可以当场撤回，也可以在行动记录里撤回。

审阅栏可以占满整页，按 Esc 缩回去。它不会拦住或等待 Agent，你审阅时它们照常干活。
