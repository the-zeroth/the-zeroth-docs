**设置 › 模型和登录 › API 配置**管着 Agent 发模型请求所走的连接：随 The One 会员提供的官方连接、你的 ChatGPT 账号登录、OpenAI、Anthropic 和 Google Gemini 的 API Key，以及任何兼容的服务，包括跑在你自己电脑上的模型。页面上的标题写着**服务商授权**。连接只负责接通；每个 Agent 用哪个模型、走哪个连接，在模型预设或角色里定，见[模型](../capabilities/models)。

![设置 › 模型和登录 › API 配置：一条用 ChatGPT 账号登录的连接](/docs-assets/images/0.5/zh/api-configuration-overview.png)

## 这一页有什么

最上面是**连接**、**OAuth**、**密钥**的数量。下面先是官方连接（账号有的话），然后是**已连接**：其余每一条连接，写着服务商、自定义连接用的协议、怎么认证（OAuth、API Key 或不用 key）和 Base URL，停用的和还没填 Key 的也会标出来。右上角的**添加连接**打开服务商列表。

密钥和登录都保存在这台电脑上，由系统加密。定义空间和模型预设只引用连接，从不带着它的密钥。

## 官方连接

官方连接随 The One 会员提供。它显示为 **Official OpenRouter**，带**官方**标记；卡片上写着你的**会员级别**、套餐包含的用量还剩多少，以及**管理订阅**（在浏览器里打开账户控制台的订阅页）。这条连接由你的账号提供，所以在这里不能编辑或删除。

账号没有官方连接时，这里就没有这张卡片。第一次使用时，**快速上手**（侧边栏的**上手**）里会出现**开通会员**；你也可以照下面的方法连接自己的服务。套餐和用量见[模型与价格](../../start/models-and-pricing)。

## 用 ChatGPT 账号登录

有 ChatGPT Plus 或 Pro 订阅的话，Agent 可以用订阅里的 Codex 额度，不用 API Key。点**添加连接**，在 **OpenAI Codex** 上点 **OAuth**，再在浏览器打开的页面里登录。快速上手里同一个选项叫**用 ChatGPT 账号登录**。

这条连接下面显示 **ChatGPT 计划用量**：每个额度周期用了多少、什么时候重置。额度属于你的 ChatGPT 账号，和你用的其他 Codex 应用共用。登录过期时，在这一行点**重新登录**。

## API Key

OpenAI（Responses API）、Anthropic（Claude Messages API）或 Google Gemini：点**添加连接**，在对应服务商上点**连接**，粘贴你在它的控制台创建的 Key，再点**保存连接**。以后要换 Key，在这条连接上点**更新**；Key 一栏留空就保留原来的。

以前版本里的 Claude Code、Gemini CLI 和 Antigravity 登录已在 0.5.0 移除，Anthropic 和 Gemini 请用 API Key 连接，见 [The One 0.5.0 Release Notes](../../start/release-notes/0-5-0)。

## 自定义提供商和本机模型

**自定义提供商**可以接入任何使用以下三种协议之一的服务。点**添加连接**，在**自定义**下点**添加**，然后填写：

- **名称**：这条连接在列表和模型预设里显示的名字。
- **协议**：**OpenAI Chat Completions** 把请求发往 `<Base URL>/chat/completions`，大多数兼容服务用这个，Base URL 通常以 `/v1` 结尾。**OpenAI Responses** 发往 `<Base URL>/responses`，只有服务实现了这个接口时才选它。**Anthropic Messages** 发往 `<Base URL>/v1/messages`，所以 Base URL 不要带 `/v1`，和给 Claude Code 配 `ANTHROPIC_BASE_URL` 时填的值一样。
- **API Base URL**：服务的地址。
- **认证方式**：**API Key**（OpenAI 的两种协议放在 `Authorization: Bearer` 里，Anthropic Messages 放在 `x-api-key` 里），或者**不用 key**，给不需要凭据的服务用，比如本机的 Ollama、LM Studio 或 vLLM。选了不用 key，请求就不带任何 key，环境变量里的也不带。

两个例子：

| 接什么 | 协议 | Base URL | 认证方式 |
| --- | --- | --- | --- |
| 自备 Key 的 OpenRouter | OpenAI Chat Completions | `https://openrouter.ai/api/v1` | API Key |
| 本机的 Ollama | OpenAI Chat Completions | `http://127.0.0.1:11434/v1` | 不用 key |

![添加自定义提供商：协议和认证方式](/docs-assets/images/0.5/zh/api-configuration-custom.png)

## 改动立即生效

保存连接后马上生效，不用重启应用。如果提示后端没能热更新，到设置 › 通用点**重启后端**。

要让 Agent 用上一条连接，就让一套模型预设走它（在**设置 › 模型和登录 › 默认模型**里），或者在角色的**模型与参数**里单独配置模型时选它。预设编辑器里的**刷新模型目录**会向这个连接取它现在提供的模型。详见[模型](../capabilities/models)和[角色](../capabilities/roles)。

## 删除连接

点这条连接上的垃圾桶图标。没有角色直接指定这个连接时，它马上就删掉，不再问你。有的话会弹出对话框列出这些角色，点**迁移并删除**就把它们迁到另一个可用的连接（没有可用连接时清空，回到默认）。用这个连接的模型预设不会跟着改，请到设置 › 模型和登录 › 默认模型给它们换一个连接；为这个连接设过的模型容量覆盖会一起删掉。

## 服务商拒绝时

服务商拒绝请求分三种，处理办法不一样：

- **拒绝了 Key 或登录**（HTTP 401）：Agent 在[所有运行](./all-runs)里写着这个连接**拒绝了它的凭据**，带着**打开这个连接**的链接；事项的工作组碰到时，对话上面的等你一栏还会出现**要你登录**的卡片，**去设置里处理**直接来到这条连接（见[等你、交付和晨报](../needs-you)）。在你更新 Key 或重新登录之前，经这个连接的请求留在本机，不再发给服务商；Agent 照样自己重试，这个连接每 30 分钟重新检查一次。保存新的 Key 或重新登录后马上放行；在运行的**运行控制**里点**立即重试待恢复 Agent**，也会马上再试一次。
- **拒绝访问**（HTTP 403）：这个账号可能无权用这个模型，或者所在地区用不了。这不会暂停连接；检查这条连接的权限，或者换一个模型。
- **请求被服务商的策略挡下**：Agent 显示**模型提供商阻止了本次请求**，Agent 名册上标着**需人工处理**。同样的请求不会自动再发，**全部恢复**和**立即重试待恢复 Agent**也会跳过它。编辑任务，说清楚你被授权做的范围；或者换一个适用、有授权的模型连接；或者取消任务。改过的请求、换过的连接会照常发出去。
