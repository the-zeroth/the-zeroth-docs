全景把所有开着的事项画在一页上：每个事项的工作组和它们的 Agent，此刻在想、在调工具、在等谁，还是出错了。不用一个个打开事项，就能看清谁在为哪件事干活、哪里在等你、哪里卡住了。

## 打开全景

点侧边栏里**对话**下面的**全景**。有 Agent 在干活时，这一项右边淡淡地写着几个，比如**3 个在干活**：数的是开着的事项上此刻正在干活（在想或在调工具）的 Agent，主助手不算。

页面右上角的开关在两个视图之间切换：

- **组织图**：谁在为哪件事干活，现在。
- **流动**：今天，每个 Agent 一条时间线。

页面最上面一行是几个数，比如“5 件事项 · 4 个工作组 · 12 个 Agent · 3 个在干活 · 2 件等你”：开着的事项、在这些事项上的工作组（替几个事项干活的组只算一次）、它们的 Agent、此刻在干活的 Agent，以及等你的事。在干活的数就是侧边栏**全景**旁边的数；等你的数就是侧边栏**对话**旁边的数（见[等你、交付和晨报](./needs-you#等你)）。

页面开着时它自己更新，Agent 一有动静就跟上。还没有开着的事项时，页面写着**还没有在做的事项**，**去跟主助手说**带你到主助手的输入框。

## 组织图

最上面是**你**和**主助手**，主助手那里写着它此刻在做什么。下面一条线挂着每个开着的事项一栏：等你的排在最前，然后是在做的、出了问题的。交付了、或者没在做什么的事项不占栏，放在图下面的[安静的事项](#安静的事项)里。事项多、一屏排不下时，这一块可以左右滚动，你和主助手一直留在看得见的那一段正中。

每栏最上面是事项卡：标题和一行现状，说法和颜色同侧边栏（见[侧边栏里的事项](./matters#侧边栏里的事项)）。下面是在为它干活的工作组；还没有工作组时写着**还没有工作组**。子事项不单独占一栏：它的工作组画在它所在事项那一栏里，写着**子事项「…」**。

### 读懂一个工作组

每个工作组头上是它的名字（比如**软件团队**），旁边是它的模板版本，比如 **v6.6**。下面这个组照它的模板画成一张小图：

- **每个 Agent 一行**。左边一条竖线把组里的 Agent 串起来，每人的色点在线上。色点的颜色和后面几个字说它此刻在做什么，用的是剧场的说法：**在想**；在调工具时写着在调什么，比如在写哪个文件；**等你**；**等别人**，知道在等谁时写“等”加上那个 Agent 的名字；**出错**，在自动重试时写**重试第 N 次**；**已停**。刚交回活的写**交回了**，压缩自己的对话历史时写**在压缩对话历史**；只是空闲的只有一个灰点，名字多占点地方。鼠标停在一行上，能看到剧场里关于它的那一整句话。
- **箭头**是模板里写好的交接：谁把活交给谁。相邻两行之间的箭头沿竖线走；两头都有箭头的线，表示活交下去还会退回来，比如负责人和检查员之间。隔着几行的交接绕到竖线左边的一条道上，短的靠里、长的靠外。
- 组里有两个以上 Agent 时，第一个 Agent 头上有一个往里指的箭头：活从这里进组。
- **分身**是组里的 Agent 复制出来的新 Agent，配置、上下文和工具都和原来那个一样。它缩进在原身下面，写着**分身**（一个 Agent 有几个分身时写**分身 2** 这样的编号），色点外面套一圈虚线，从原身那里拐过来一条虚线。分身交接的路子和原身一样，所以它的箭头不再画一遍。
- **分支**：负责人用 TaskBoard 分出去的一层任务，或者组为一部分活开的团队，在组里各占一个虚线框，框里也照它自己的交接画。TaskBoard 那一层写着**分支 ×3** 这样的任务数（一个任务一个工人，检查它的 Agent 不另算）；组开的团队写它的名字，比如**软件团队**；子事项的活在这里跑时，框上写**子事项「…」**。
- 做完了的分支不再一个个画，收成一行**另有 N 个分支已做完**，点它到这个事项的剧场里看它们做过什么。

等你的事挂在交来它或者问它的那个工作组下面，一件占两行：是什么（比如**等你验收**）、什么时候来的，以及开头几个字。停在边界上的事项、要你修的模型连接，挂在事项卡下面。

图下面一行是图例：七种状态的颜色（**在想**、**在调工具**、**等你**、**等别人**、**出错**、**空闲**、**已停**），以及**分身**、**交接**（一头有箭头）和**来回**（两头都有箭头）。

## 点一下会怎样

- **点一个 Agent**：图右边打开它的详情。最上面是它的名字、它所在的组和事项，以及它此刻的状态；下面是**在做**（它此刻在做什么）、**刚做过**（最近几步，带时刻），以及**目前**：**模型**、**用量**、**上下文**占了多少、**调用**了几次模型和工具。**打开对话**打开这个 Agent 的对话，和在看板上打开组的对话一样，你在那里写的话直接发给它，算你自己的；**看剧场**打开这个事项的剧场。再点一下同一个 Agent、点右上角的关闭按钮或者按 Esc，详情就关上。
- **点主助手**：同样打开它的详情，按钮是**去主助手的对话**，带你回首页。
- **点一件等你的事**：它的整张卡在图右边打开，标题是**等你处理**，按钮都在那里：验收、回答、去修或者恢复。处理完它就不再等你，卡也跟着关上；Esc 也能关上。
- **点工作组的名字**：打开这个事项的[剧场](./working-groups#剧场)。
- **点事项卡**：打开这个事项的看板。

## 安静的事项

交付了、或者没在做什么的事项，在图下面排成一排，标题是**安静的事项 · N**，把栏和宽度让给在干活的事项。每件一张虚线小卡：标题和一行现状；有开着的触发器时，这一行淡淡地写着下次什么时候醒来，比如**明天 09:00 醒来**。组里有两个以上 Agent 的，卡上还有一排小圆点，一个点一个 Agent。点一张卡打开那个事项。

## 结束一个事项

鼠标移到一张事项卡上（或用键盘走到它），右上角会露出结束按钮，栏里的和安静的事项都有。按下去 The One 会再问一次，并列出这个事项还有哪些事在等你：**先去处理**带你去事项页，**结束事项**才结束。结束的事项离开全景和侧边栏，为它干的活停在手上那一步，它等你的事也一起收起，直到你重新打开它。详见[结束和重新打开](./matters#结束和重新打开)。

## 流动

**流动**把今天画成一根根时间线：

- 最上面一条是**你**，然后是**主助手**，再往下每个开着的事项一条，安静的事项也在里面。事项那条左边写着标题（点它打开事项）、在为它干活的工作组和一行现状；安静、又没有触发器的写**安静**。
- 事项那条里，它的每个 Agent 一根细轨，用剧场的颜色画出它今天什么时候在想、在调工具、在等或者出错；空闲和停下的时候只是一条细线。做完了的分支里的 Agent 也在。点左边 Agent 的名字，打开它的详情，和组织图上一样。
- 时间线一直画到右边的“现在”，那里写着**现在 14:05** 这样的时刻。
- 线上的点是发生过的事：你那条上是还在等你的交付、提问和出了问题的事，画在它们来的时刻；事项那条上是它今天的交付，以及还在等你的提问和出错；主助手那条上是今天新开的事项，点旁边写着**开了「…」**。鼠标停在点上，能看到它是什么。
- 右边一列是**接下来**：你那一行列出几件等你的事，比如**等你看：…**、**等你回答：…**；有触发器的安静事项写它下次什么时候醒来；别的事项写主助手维护的一句话现状。

泳道名字上面可以选看多长：**近 1 小时**、**近 3 小时**，或者**今天**（默认，从今天第一个 Agent 动起来的那个整点开始）。时间线上的竖线落在钟面的整点、半点或整刻上。

流动下面也有图例：七种状态的颜色，以及两种点：**你交代的事往下走**（主助手开的事项）和**交付和问题回到你**。

## 动效

在想和在调工具的色点在轻轻呼吸。主助手刚把活交给一个事项的工作组，或者这个组刚交付，两分钟内，主助手连到那一栏的线上有个点在走：往下是交活，往上是交付。组里两个 Agent 刚交接过，也有个点顺着它们之间的箭头走。系统设置里打开了减少动态效果时，这些都不动。
