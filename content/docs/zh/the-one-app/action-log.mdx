The One 让 Agent 不必先问你就能动手。你掌控局面靠的是记录和退路：**行动记录**记下 Agent 的每一次工具调用，文件被改动或删除之前先留一份副本，所以随时能把文件放回去。用量边界、暂停和**急停所有 Agent**让你想停就停。

## 为什么没有审批这一步

如果每个动作之前都要你点头，Agent 就没法在你不在时替你做事，你也看不出点头的那一步到底做了什么。所以没有任何东西会拦下、询问或拒绝 Agent 的调用：每次调用都有记录，每处文件改动都能撤回，代价只是看一眼这次调用碰到的文件的那点时间。这样设计的道理，见[没有审批这一步](../multi-agent-architecture/record-and-undo)。

## 行动记录记什么

每一次工具调用记下：

- 哪个 Agent、哪次运行发起的，用的什么工具、什么参数（像密钥或密码的值不写进去）；
- 新建、修改、删除了哪些文件，每个文件都带着改动前和改动后的版本；
- 访问了哪些地址，结果如何。

两次调用之间发现的改动，比如你自己或别的程序改了文件，也记成**观察到的改动**，同样能撤回。你自己通过插件的面板发起的调用（在对话里或看板上），记在你名下。

记录只追加不修改：每条记录都带着上一条的哈希，任何一条被改动或删掉都能查出来。行动记录是整台电脑一份，不分 Space，所以这台电脑上 Agent 做过的事都看得到、撤得回。它只在桌面应用里保存。

## 行动记录页

**设置 › 数据和撤销 › 行动记录**从上到下是：

- **删改可撤回**：最近 7 天 Agent 修改或删除文件多少次、其中多少次能放回，以及哪些文件没能留副本、为什么。下面是**回收站**占了多少，和**记录完整性**：点**校验**核对整条记录链。
- **按时间撤回**：把某个时间之后的全部改动放回原样。
- **撤回记录**：每一次撤回，你的和 Agent 的，最新的在前，每一次都能再撤回。
- **不属于运行的调用**：不属于哪个运行的调用，比如你经事项看板上的面板做的，各写着为哪个事项。
- **最近的运行**：每次运行一行，写着调用了几次、新建修改删除了几个文件；展开看改动的文件、访问的地址和一次次工具调用。

从证据包里点一条记录过来时，页面最上面先打开那条原始记录。

## 撤回

可以按四种范围撤回：

| 撤回什么 | 在哪里 |
| --- | --- |
| 一次调用 | 在**最近的运行**里展开那次运行，在那次调用上点**撤回这次调用**。不属于运行的调用，在**不属于运行的调用**里逐个撤回；事项页**改动**一节写着你经面板做了几次调用，链到那里。 |
| 一整次运行 | **最近的运行**里那次运行的**撤回**。 |
| 一个事项的活 | 事项页**改动**一节里的**撤回这些改动**。子事项的活，和你经这个事项看板上的面板做的调用，都算在内。 |
| 某个时间之后的全部改动 | **按时间撤回**：选好时间，点**预览**。 |

每次撤回都先预览，确认之前不动任何文件：

- 每个文件回到所选范围里第一次改动之前的样子，Agent 新建的文件被移除；
- 之后又被改过的文件默认不动，勾上**这些也放回（会覆盖之后的改动）**才放回；
- 没留副本或副本已过保留期的文件如实列出，不去猜。

撤回本身也记下来，列在**撤回记录**里，在那里点**撤回这次撤回**，文件就回到那次撤回之前的样子。按事项和按时间的撤回不属于哪个运行，只有在这里找得到；事项的**改动**一节写着这个事项上次被撤回的时间，链到这里。

![撤回一个事项的改动，先看预览](/docs-assets/images/0.5/zh/action-log-matter-undo.png)

### 回收站

副本放在应用的回收站里，保留 7 天后自动清理；磁盘快满时（剩余不足 5 GB，进入保护模式）只保留 1 天，最旧的先清。在能克隆文件的磁盘上（比如 Mac 的 APFS），副本和原文件共用磁盘空间，直到原文件被改（单个文件最多 4 GB）；其他磁盘上 The One 完整复制一份，单个文件最多 64 MB，保护模式下最多 1 MB。**设置 › 数据和撤销 › 存储空间**显示行动记录和回收站占了多少。

### 撤回管不到的

- **出了这台电脑的动作**：收付款、推送、发邮件、发布、部署、远程命令，以及向网络提交数据的请求。它们照常执行，在运行上标着“发生在本机以外，撤回不了”，晨报的**撤回不了的动作**里也会列出。
- **依赖和缓存目录**，比如 `node_modules`、`.git`、`.venv`，以及 `.gitignore` 里写着的目录，除非命令直接点名了其中的文件。
- **家目录本身，和直接放在家目录下的大文件夹**，比如文稿、桌面、下载：命令在这些地方跑时，The One 不给整个文件夹留副本，只给命令点名的文件留。
- **MCP 工具写在别处的东西**：MCP 工具只给参数里写了完整路径的文件留副本，你经面板做的调用也一样。比如收款插件的工具记的账本不留副本：这些调用列得出来，却没有能放回的文件。
- **应用数据库里的东西**：Agent、Graph 和预设在数据库里的改动只记下来，不在这里撤回。
- **副本已过期或没能留下的文件。**

## 逐块审阅改动

事项页上的**审阅**按块列出每个工作组的改动，你逐块**接受**、**拒绝**或**批注**，再点**提交审阅**：拒绝的块写回改之前的样子，这也记成一次撤回，能在**撤回记录**里再撤回。详见[工作组](./working-groups)。

## 边界和暂停

不必全部停下，也能让工作停在你想停的地方：

- **事项的用量边界**：在事项页头点**设边界**，这个事项的工作组在你没介入时花到这么多 token，就停在下一个检查点等你恢复，见[事项与看板](./matters)。
- **运行的用量边界**：在所有运行的**运行控制**里设**用量边界**，某个 Graph 的每次运行（或所有 Graph 的运行）花到这么多就暂停，见[所有运行（开发者视图）](./settings/all-runs)。
- **一个工作组**：看板上组卡的**暂停**让每个成员做完手上这一步就停，它为别的事项做的活也一起停；**继续**让它接着做。
- **整个事项**：**结束事项**让它的活和触发器都停下，**重新打开事项**从停下的地方接着做。

这些都是协作式的：每个 Agent 先做完手上这一步，再停下。

## 全部急停

**急停所有 Agent** 在应用菜单里（macOS 上是 **The One** 菜单，Cmd+Shift+.），托盘菜单里也有。Windows 上菜单栏是隐藏的，请用托盘菜单。点**全部停止**确认之后：

- 正在执行的工具调用被中断，Agent 启动的命令被结束；
- 所有运行都暂停，直到你恢复；
- 所有触发器都暂停，直到你恢复。

和上面那些暂停不同，急停不等手上这一步做完。只有一种不受影响：已经转到后台、稍后才交回结果的工具任务，会自己跑完。只有你能这样叫停 Agent；任何 Agent，包括主助手，都做不到。

要接着做：在事项看板的组卡上点**继续**恢复一个工作组，或者在所有运行里点**解冻**恢复一次运行，原来在干活的 Agent 会接着干。触发器从托盘菜单的**恢复所有触发器**，或**设置 › 自动做事**里的**恢复所有**恢复（见[触发器和后台常驻](./triggers)）。
