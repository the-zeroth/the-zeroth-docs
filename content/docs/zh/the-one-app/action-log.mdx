The One 让 Agent 不必先问你就能动手。你掌控局面靠的是记录和退路：**行动记录**记下 Agent 的每一次工具调用，文件被改动或删除之前先留一份副本，所以随时能把文件放回去。用量边界、暂停和**急停所有 Agent**让你想停就停。

## 为什么没有审批这一步

The One 里的 Agent 自己干活，只在它自己觉得需要时才来问你。如果每个动作之前都弹一次确认，你会被叫回来无数次，而且看不出这一步到底做了什么。所以没有任何东西会拦下、询问或拒绝 Agent 的调用；取而代之的是每次调用都有记录、每处文件改动都能撤回。记录的代价只是看一眼这次调用碰到的文件的那点时间。

## 行动记录记什么

**设置 › 行动记录**列出最近的运行。每一次工具调用记下：

- 哪个 Agent、哪次运行发起的，用的什么工具、什么参数（像密钥或密码的值不写进去）；
- 新建、修改、删除了哪些文件，每个文件都带着改动前和改动后的版本；
- 访问了哪些地址，结果如何。

你自己通过插件的面板发起的调用（在对话里或看板上），记在你名下。

记录只追加不修改：每条记录都带着上一条的哈希，任何一条被改动或删掉都能查出来，在**记录完整性**里点**校验**就能核对整条链。行动记录是整台电脑一份，不分 Space，所以这台电脑上 Agent 做过的事都看得到、撤得回。它只在桌面应用里保存。

页面顶上的**删改可撤回**写着最近 7 天 Agent 修改或删除文件多少次、其中多少次能放回，以及哪些文件没能留副本、为什么。

## 撤回

可以按四种范围撤回：

| 撤回什么 | 在哪里 |
| --- | --- |
| 一次调用 | 在**最近的运行**里展开一次运行，在那次调用上点**撤回这次调用**。 |
| 一整次运行 | **最近的运行**里那次运行的**撤回**。 |
| 一个事项的活 | 事项页**改动**一节里的**撤回这些改动**，子事项的活也算在内。 |
| 某个时间之后的全部改动 | 行动记录页上的**按时间撤回**：选好时间，点**预览**。 |

每次撤回都先预览，确认之前不动任何文件：

- 每个文件回到所选范围里第一次改动之前的样子，Agent 新建的文件被移除；
- 之后又被改过的文件默认不动，勾上**这些也放回（会覆盖之后的改动）**才放回；
- 没留副本或副本已过保留期的文件如实列出，不去猜；
- 撤回本身也会记进行动记录，所以还能**撤回这次撤回**。

### 回收站

副本放在应用的回收站里，保留 7 天后自动清理；磁盘快满时（剩余不足 5 GB，进入保护模式）只保留 1 天，最旧的先清。在能克隆文件的磁盘上（比如 Mac 的 APFS），副本和原文件共用磁盘空间，直到原文件被改（单个文件最多 4 GB）；其他磁盘上 The One 完整复制一份，单个文件最多 64 MB，保护模式下最多 1 MB。**设置 › 存储空间**显示行动记录和回收站占了多少。

### 撤回管不到的

- **出了这台电脑的动作**：收付款、推送、发邮件、发布、部署、远程命令，以及向网络提交数据的请求。它们照常执行，在运行上标着“发生在本机以外，撤回不了”，晨报的**撤回不了的动作**里也会列出。
- **依赖和缓存目录**，比如 `node_modules`、`.git`、`.venv`，以及 `.gitignore` 里写着的目录，除非命令直接点名了其中的文件。
- **副本已过期或没能留下的文件。**

## 逐块审阅改动

事项页上的**审阅**按块列出每个工作组的改动，并标明每块是谁改的。在每块上**接受**、**拒绝**或**批注**，然后点**提交审阅**：拒绝的块写回改之前的样子（这也记成一次撤回，能再撤回），批注交给 Agent。详见[工作组](./working-groups)。

## 边界和暂停

不必全部停下，也能让工作停在你想停的地方：

- **事项的用量边界。** 在事项页头点**设边界**，填**无人值守最多**多少**百万 token**（至少 1 万 token）。这个事项的工作组（连同子事项）在你上次介入以后花到这么多，就停在下一个检查点；正在做的那一步会先做完。用到 80% 时 Agent 会先收到提示。停下时页头下面出现横幅，窗口里也弹出提示，首页的“需要你”里也会列出；点**恢复**后重新算起。也可以让主助手替你设边界或恢复。
- **运行的用量边界。** 在设置 › 所有运行里，**用量边界**让某个 Graph 的每次运行（或所有 Graph 的运行）花到你设的 token 数就暂停（见[所有运行（开发者视图）](./settings/all-runs)）。
- **一个工作组。** 看板上组卡的**暂停**让每个成员做完手上这一步就停，它为别的事项做的活也一起停；**继续**让它接着做。
- **整个事项。** **结束**会让它的活和触发器都停下，**重新打开**从停下的地方接着做。见[事项与看板](./matters)。

这些都是协作式的：每个 Agent 先做完手上这一步，再停下。

## 全部急停

**急停所有 Agent** 在应用菜单里（macOS 上是 **The One** 菜单，Cmd+Shift+.），托盘菜单里也有。Windows 上菜单栏是隐藏的，请用托盘菜单。确认之后：

- 正在执行的工具调用被中断，Agent 启动的命令被结束；
- 所有运行都暂停，直到你恢复；
- 所有触发器都暂停，直到你恢复。

和上面那些暂停不同，急停不等手上这一步做完。只有你能这样叫停 Agent；任何 Agent，包括主助手，都做不到。

要接着做：在事项看板的组卡上点**继续**恢复一个工作组，或者在设置 › 所有运行里点**解冻**恢复一次运行，原来在干活的 Agent 会接着干。触发器从托盘菜单的**恢复所有触发器**，或**设置 › 常驻与触发**里的**恢复所有**恢复（见[触发器和后台常驻](./triggers)）。
