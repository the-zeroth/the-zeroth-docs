有些事只有你能定：Agent 主动问你的问题、交回来等你评判的工作、没做成的运行、只有你能修的模型连接，以及停在你设的边界上的事项。The One 把这些叫作**等你**的事：一件一张卡，都在主助手对话上方那一条里，在哪里看到都是同一张，处处是同一个数。所以你可以放手让工作继续：回来时主助手先打个招呼，说上次看过以后发生了什么（见[每天的招呼](./main-assistant#每天的招呼)）；想回头看这一周，打开侧边栏的[周报](./weekly)。

Agent 自己干活，只在它们自己觉得需要你时才来找你。这里没有任何审批：The One 从不拦下 Agent 的动作等你同意。你掌控局面靠的是记录和撤回，见[行动记录、撤回和急停](./action-log)。

## 等你

有事在等你时，主助手对话上方有一条写着有几件（比如**等你 3 件**），前三件各一个按钮，写着要做什么、在哪儿，比如**验收 · 结账页改版**或**回答 · 退款政策**；其余的收在**还有 N 件**里，点开是一个列表。点一个，对话就滚到这件事的卡片（就在报告它的那一行下面），卡片会闪一下；对话里那个位置没有它的，比如要修的模型连接、停在边界上的事项，或者更早的通知带来的，卡片就在这一条下面打开。处理完的卡片离开这一条；没有等你的事时，这一条就不出现。

等你的事有六种，每种都在它的卡片上当场处理：

| 卡片 | 等你的是什么 | 你能做什么 |
| --- | --- | --- |
| **等你验收** | 一份等你评判的交付。 | **接受**、**返工**或**放弃**；**证据包**打开它的证据包。 |
| **没做完** | 一份没做完的交付。 | **返工**或**放弃**；**证据包**。 |
| **等你回答** | Agent 问你的一个问题。 | 回答它（见下面的[回答问题](#回答问题)），或者点**不用回答了**收起。 |
| **停下了** | 一次失败的运行，没有它的交付在等你评判。 | **去看看**打开它来自的那段对话；**不管了**收起它。 |
| **要你登录**、**访问被拒**、**套餐不支持**或**额度用完了** | 一个拒绝了工作组的活、要你来修的模型连接，写着有哪些事项在等它。标签照拒绝的原因写，依次是拒绝了 Key 或登录、拒绝了访问、套餐不含这项用量，或者 Key 或账户的额度用完了，见[服务商拒绝时](./settings/api-configuration#服务商拒绝时)。 | **去设置里处理**打开那个连接；官方连接的额度用完时是**去订阅页**，打开账户的订阅页续订或加额度。 |
| **停在边界上** | 一个无人值守花到了你设的边界、活停下来的事项。 | **恢复**，或者点**去事项页**改边界。 |

同一张卡出现在好几个地方：主助手对话里报告它的那一行下面、这一条、事项看板的**等你**、[全景](./panorama)上交来它的工作组下面，以及交付的证据包页面。在哪里处理都一样，处理完各处一起消失。每张卡写着它属于哪个事项、来自哪个工作组；打开开发者视图时，还会写出它背后的编号，比如使命和运行。

有几件事在等你，这个数处处一样：侧边栏**对话**旁边、这一条、全景最上面那一行、主助手每天的招呼，以及 Mac 上的 Dock 图标和菜单栏图标。

交付有了验收结论才离开等你，看过了也一样。不算等你的有两种：

- 主助手什么都不问、只是告诉你的话，是消息。
- 你结束了的事项（或者它上面那个事项结束了）上的提问、交付和失败。结束以后它们从等你里收起来，重新打开事项就回来，见[结束和重新打开](./matters#结束和重新打开)。

## 回答问题

等你回答的问题，直接在卡片上回答：

- 选择题把选项列成按钮；确认题是**确认**和**拒绝**，或者 Agent 自己写的按钮文字。
- 要用话回答的问题，点**写回答…**打开回复框，写好后点**发送回答**（或按 Ctrl/⌘ + Enter）。
- 少数几种问题只能在会话里回答，卡片上写着**这个问题要在它的会话里回答。**，点**去会话里回答**过去。
- 不打算回答，就点**不用回答了**；如果 Agent 是用卡片问的，它会知道卡片被取消了。

你的回答直接交给提问的 Agent，它接着做。

### 工作组的提问

事项上的工作组一提问，问题马上出现在事项的看板上，先由主助手接着。看板上的卡片、你以前说过的话或常识能定的，它替你答，看板上的提问卡会写明是它答的。只有你能定的（你的口味、你的钱和账号、你还没做的选择），或者你正在跟这个组直接说话，它就把问题留给你，你马上会收到提醒。它从不替你编答案。问题开着满三分钟，主助手既没答、也没留给你，你照样会收到提醒，所以不会有问题被悄悄压着。

## 通知

每个提问、交付和失败都只告诉你一次：The One 在后台时弹系统通知，在前台时在窗口里提示；同一时间来超过三条，会合成一条通知（**来了 N 条新消息**），点开就是主助手的对话。在首页时，主助手自己交回的话不再另外提示，因为对话里已经有了。托盘菜单第一行写着还没处理的提问、完成和失败各有几个（**未处理：**……），并列出其中最多五条，**去对话看等你的事**打开主助手的对话；在 Mac 上 Dock 图标显示有几件事在等你。

有些交付是安静进来的：不弹通知，但等你验收的照样在对话上方那一条里，也照样记进[周报](./weekly)：

- 触发器开的工作，除非这个触发器勾了**做完也提醒**（见[触发器和后台常驻](./triggers)）；
- 外部程序派的活，因为交付已经直接交给了那个程序（见[随身通道和对外调用](./remote)）；
- 你跟 Agent 说过做完不用告诉你，它交回的工作。

提问和失败从不安静进来。只是别人通常会先答的提问，会等一会儿再提醒你：等主助手三分钟，等外部程序一分钟。

## 验收交付

等你验收的交付有三个按钮，在主助手对话里它的卡片上、对话上方那一条、事项看板、全景、周报和这份交付的证据包页面上都一样：

| 按钮 | 会发生什么 |
| --- | --- |
| **接受** | 你收下这份工作。 |
| **返工** | 写下要改什么，点**发回去返工**，你的原话交给交付的那个 Agent。它所在的工作组正在做别的事项时，等它回到这件事，最先听到的就是你的话。 |
| **放弃** | 再问你一次，确认后记成放弃，不再等它交付；Agent 不会被叫停。 |

验收只是一条记录：除了返工会把你的话交出去，它不叫醒、也不叫停任何人。以后还能在证据包页面点**改主意**，或者在主助手对话里这张卡收成的那一行上点。如果页面打开之后又来了一次新的交付，这次什么都不记，会提示你先看新的那份。

不按按钮也可以：

- 对主助手说你对这份交付的看法（“可以了，谢谢”“总数不对”），它替你记下验收；要返工时，它把你的原话转给工作组。它从不替你评判，结束一个事项也不算评判。
- 交付之后你直接回复 Agent，也照样读：要改算返工，道谢算接受。
- 你看过的交付 12 小时没提修改，记为**视为接受**。
- 还在做或失败了、7 天没有动静的，记为放弃。

只有你自己给的验收（按钮或你说的话）才算进一次通过率；视为接受的另外计数。一次通过率在[周报](./weekly)里看。

## 证据包

每次交付后约 15 秒，The One 为它写一份证据包，让你不必只听 Agent 自己怎么说，就能复核这次交付。在任何一份交付上点**证据包**打开。页面标题是**证据包 · 第 N 次交付**，内容有：

| 栏目 | 内容 |
| --- | --- |
| **结论** | 交付的 Agent 自己写的话，标明是它的说法，不是证据。 |
| **还等你回答** | 同一个工作组在这个事项上还开着、等你回答的问题，附去回答的链接。 |
| **你的验收** | 验收以后：它现在怎样、返工时你说的话，以及**改主意**。还在等你时，换成页头下面它的那张卡：三个按钮，以及现在通过算不算一次通过。 |
| **核对** | 跑没跑测试、最后一次过没过、之后有没有又改了文件，以及 Agent 提到的文件是不是都在。 |
| **改了什么** | 从开始做到这次交付，新建、修改、删除了哪些文件，附改动对比。 |
| **测试和检查命令** | 测试、构建、类型检查和 lint，带工作目录、退出码和输出；点**复制命令**可以拿去重跑。 |
| **视觉检查**、**截图**、**产出文件** | 视觉检查的报告、Agent 看过的图片，以及它们做出来的文件。 |
| **关键经过** | 目标、提问和回答、计划的变化、本机以外的动作、撤回。 |
| **花费** | token、模型调用、工具调用和用时，分这次交付和整件事两列。 |

证据来自应用自己的记录，主要是行动记录，不来自 Agent。**校验**重算包里每个文件的哈希，并确认它背后的行动记录没被改过。**请主助手复核**让主助手拿着证据包到项目里逐项核对、重跑测试（它自己做，或交给一个工作组），结果回到首页告诉你；会花 token，只有你按了才开始。**打开文件夹**在磁盘上打开这个包。

![一份已验收的交付的证据包：结论、核对和改了什么，右边是你的验收](/docs-assets/images/0.5/zh/needs-you-evidence.png)

证据包只存在这台电脑上，从不上传。文字部分保留 180 天，截图和产出文件的副本保留 30 天，磁盘快满时更早清理。**设置 › 数据和撤销 › 存储空间**里的**证据包**一行显示它们占多少。证据包只在桌面应用里生成。
