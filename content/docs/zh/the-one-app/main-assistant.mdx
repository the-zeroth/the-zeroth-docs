主助手是 The One 一打开就看到的那段对话，也是你交代任何事的地方。能当场答的它直接答；大一点的事它记成事项，交给工作组去做，并一直跟进，直到你满意。

## 一段一直在的对话

每个空间都有自己的主助手：侧边栏里是**对话**，页面上叫**主助手**。它是一段永久的对话，跨越很多天、很多事项一直延续下去。没有“新建对话”，也没有会话列表要整理：你说的每件事都落在同一个地方，所以它能把你上周说的和今天要的连起来。

主助手属于它所在的空间。在侧边栏顶上切换空间，看到的就是那个空间的主助手、事项、等你的事和晨报。如果还有 Agent 在干活，The One 会先问你，因为切换会先停掉它们（**停止并切换**）。

主助手本身也是一个 Agent。它的角色 `main-assistant` 在**团队与工具 › 角色**里；它用你的默认模型（**设置 › 模型和登录 › 默认模型**），除非你在自己的空间里给这个角色单独绑一套模型预设。它的对话在首页，不在所有运行里。

从 0.4 升级过来、想知道以前的会话去了哪里，见 [0.5.0 发布说明](../start/release-notes/0-5-0)。

## 哪些它自己做，哪些开成事项

每件事它都自己判断：

- 当轮几秒就能定的，它直接答：一个问题、一次快速查询或状态检查、一处小改动。
- 跟已经在做的事有关的追问、补充或改主意，它放到那个事项上，转给正在做的工作组。
- 要产出交付物、要反复改和测、要从多处收集资料，或者之后还要跟进的，它开一个新事项。

新事项有一个短标题和一张概述卡，写明这件事要做到哪一步，以及你要看到的每一项结果。概述很要紧：之后的交付都要拿它来对照。

开事项的同一步，主助手就把活交给一个工作组。工作组马上开工，主助手则腾出手来照顾你和别的事项。它从空间的工作组模板里挑：代码项目里的软件活交给软件团队（`polished_software_dev`），它的负责人和检查员会边做边把需求变成测试；调研和各类工作室的活交给对应的模板；其余普通的多步活交给**通用工作组**（`chat`）。合适的模板有好几个时，它优先选做过这类活、而且做得好的。只有都不合适、这类活以后还会再来时，它才让**定义编辑组**（`atlas`）写一个新模板。

详见[工作组模板](./capabilities/working-group-templates)、[事项与看板](./matters)和[工作组](./working-groups)。

## 你的原话

主助手给工作组布置活时，把你的话整段原样抄进去，不转述。它只补工作组不知道的：项目文件夹、时限，以及你在别处说过、跟这件事有关的话。怎么拆分、测什么、用哪些角色，它不替工作组定。

这是有意的。转述过的要求带着主助手自己的理解，工作组就会照它的理解去定那些你没说清的地方，而不是照你的本意。后续的话也一样：你回答、纠正或者提新要求时，主助手把你的原话转给已经在这个事项上的工作组。

## 工作组干活时

主助手会让每个进行中事项的一句话现状保持最新：到哪一步了、在等谁。这句话写在事项页的标题下面；事项总览里没有更要紧的事要说时，显示的也是这一句，侧边栏里鼠标停在事项上也能看到。想一眼看到所有工作组和它们的 Agent 此刻在做什么，打开[全景](./panorama)。

### 提问

工作组的提问先到主助手这里。看板上的卡片、你以前说过的话或常识能定的，它替你答；只有你能定的，它马上留给你。它从不替你编答案。它等多久、什么时候提醒你，见[工作组的提问](./needs-you#工作组的提问)。

### 交付

工作组交回工作时，主助手拿它对照你要的：你要看到的每一项结果在不在、站不站得住。结果是空的、检查没过、数字出自组自己修好之前，不管组怎么说，都算没达到。

- 差在组自己能补的地方（查原因、修、重跑、补上缺的），主助手直接让组接着做，并用一句话告诉你。
- 下一步要你来定（花钱、账号或密钥、只有你能做的决定、重启应用），它问你一个具体的问题，并给出选项。
- 做到了，它告诉你结果怎样。

它汇报时先说对照目标的结论，而不是“做完了”：到没到、意味着什么；再说要紧的数字；没达到时说为什么；最后是下一步：谁接着做什么，你现在要做什么。工作组自己的原话在看板上都有，它不再重复。

每份交付最后由你评判：主助手从不替你评判，结束一个事项也不算评判。在哪里按**接受**、**返工**或**放弃**，以及怎样直接用话告诉它，见[验收交付](./needs-you#验收交付)。

### 停住的工作组

工作组的卡片还写着在做、里面却没了动静，或者成员一直只在重试错误时，主助手会收到通知，由它决定下一步。它怎么判断、能做什么，见[停住的工作组](./working-groups#停住的工作组)。

### 安静的活

不提醒的触发器带来的活，交回时只记在事项的看板上，主助手不来告诉你，除非结果没达到要求。详见[触发器和后台常驻](./triggers)。

## 它能替你做什么

你在事项页上能做的，主助手都能做。你一句话，它就能结束或重新打开事项，暂停、继续或重试一个工作组，让事项排着的活先做。设用量边界、去掉边界，以及恢复停在边界上的活，它只照你的话做。它也会在看板上写卡片：笔记、清单、链接、文件、数据和面板。

它对你的工作有完全的权限，包括这台电脑上的登录和保存的密钥，以及工作需要的花费。任何动作都不等你批准；它只在自己觉得需要时才问你，比如只有你知道的信息卡住了进度。让你掌控局面的，是 Agent 做过的每件事的记录，以及配套的撤回：详见[行动记录、撤回和急停](./action-log)。

它也能改进空间本身。要一个新的模板、角色或技能，它会自己写定义，或者交给定义编辑组去写；要它让空间把自己的活做得更好，它会开进化事项（见[进化：实验室和夜间复盘](./evolution)）。这些改动只在你自己的空间里生效；在只读的官方空间里，它们只能留作提议。详见[定义空间](./capabilities/definition-spaces)。

## 首页

首页就是和主助手的这段对话。窗口够宽时，对话旁边还有一块概览（见下面）。

### 侧边栏

侧边栏最上面是 The One 和你现在所在的空间，点空间名可以换一个空间。往下依次是：

- **对话**：回到这段对话。旁边的数是有几件事在等你。
- **全景**：所有开着的事项上，工作组和它们的 Agent 此刻在做什么。有 Agent 在干活时，旁边淡淡地写着几个，比如**3 个在干活**。见[全景](./panorama)。
- **上手**：只在还没配好模型时出现，见[快速入门](../start/quick-start)。
- **事项**：标题写着开着的有几个（比如**全部 4**），点它打开事项总览；下面是每个开着的事项。列表最下面的**新事项：对主助手说**带你回到这里，光标就在输入框里。见[事项与看板](./matters)。
- **团队与工具**：每个工作组会什么、在为哪些事项干活，以及插件、技能、角色和模型。见[团队与工具](./capabilities)。
- **应用**：插件带来能打开的应用时才出现，见[插件与应用](./capabilities/plugins)。
- **设置**：见[设置](./settings)。

“需要你”页和晨报不在侧边栏里：等你的事在对话上面那一栏，晨报从每天的招呼里打开。

### 对话上面那一栏

有事在等你时，对话上面有一栏写着有几件（比如**等你 3 件**），前三件各一个按钮，其余的收在**还有 N 件**里。点一个按钮，对话就滚到它的卡片，你当场回答、验收或者去修。这一栏的数就是侧边栏**对话**旁边的数。详见[等你、交付和晨报](./needs-you#等你)。

### 搜索对话

右上角的**搜索对话**，或者 Cmd+F（Windows 上是 Ctrl+F），会在对话上方打开一条搜索。它搜的是对话里显示出来的话：你说的、主助手说的，以及说某个事项上发生了什么的那些行。结果新的在前；点一条或按回车就跳到那条消息，它会闪一下，Esc 关掉搜索。它只搜对话里已经载入的部分。

### 概览

窗口宽到 1500 像素以上时，对话右边有一块概览，平时开着；右上角的概览按钮（图标，鼠标停上去写着**概览**）收起或打开它，应用会记住你的选择。窗口窄一些时它不占地方，要看时点这个按钮，它浮在对话上面。开发者视图里没有它。它分三块，每块最多三行：

- **在做**：正在干活的工作组、它在为哪个事项干活，以及最近一次动静是什么时候。点一行打开那个事项。
- **最近交付**：最近的交付和它是第几份，还等你看的标着**等你看**。点一行打开它的证据包。
- **接下来**：接下来几次触发是什么时候、为哪个事项，以及到了花费上限、等你决定的事项。旁边的**全部**打开触发器的设置；触发器都暂停着时，这里写着**自动做事暂停着**。

看着这段对话，主助手交回的东西就算你看过了。

### 每天的招呼

每天第一次打开应用，或者离开一小时以上、换了一天之后回到窗口，如果有你还没看过的新东西，主助手会在对话里先打个招呼：**早上好**（或者下午好、晚上好），上次看过以后发生了什么，以及有几件事在上面那一栏里等你。这个招呼是主助手在打招呼那一刻发的一条消息，你接下来写的话排在它下面。**看晨报**打开完整的晨报（见[晨报](./needs-you#晨报)），**知道了**收起招呼，当天不再出现。

## 给它写话

**Enter** 发送，**Shift + Enter** 换行。

- 用回形针（**添加图片或文件**）、拖进对话或粘贴来附上图片和文件。图片会压缩到 5 MB 以内，其他文件最大 10 MB。
- **模板**会插入一份空间里的请求模板，你把空填好就能发，比如**实现功能**、**诊断并修复问题**和**审查并验收**。
- **发送**旁边的按钮写着现在的默认模型预设，点开可以换一套，见[模型](./capabilities/models)。

你自己的话显示成你的消息，从手机发的也是（下面标着**来自手机**）。主助手的话完整显示；它中间做的事收成一行，用平常的话写着做了什么，点开是一步一行。它问你事情时，问题上标着**等你回答**，点**回这一条**，你接下来发的就是对它的回答。每天第一条消息上面有一行写着是哪天：**今天**或**昨天**加上日期，更早的只写日期。

从别处送来的消息收成一行，说发生了什么，不会和你的话混在一起：哪个工作组在哪个事项上问了问题、交来一份、没做完、一直出错或停下了（点**打开**去那个事项），触发器到点了，或者外部程序发来了什么。这一行用工作组的中文名，比如**软件团队**。它带来的提问或交付还在等你时，那张卡片就在这一行下面，写着事项和来自哪个工作组，你在这里当场回答或验收。处理完以后，卡片在原处收成一行，说后来怎么样了：比如“你接受了「结账页改版」第 1 份”，旁边的**看看**打开它的证据；或者“主助手替你回答「退款政策」”，后面是它的回答。一份活最新的那次交付，这一行上还有**改主意**，点开能重新给出它眼下还能给的结论。

主助手在忙时，输入框上面有一行说它在做什么（在想、在做事、在压缩对话历史或在重试），点**停一下**就打断它；它歇着时这一行不出现。一次回话没回成时，那条消息用平常的话说为什么，比如模型那边太忙了；输入框上面那一行写着多久以后再试，点**现在就试**马上再试。想在手机上跟主助手说话，见[随身通道和对外调用](./remote)。

想看主助手的系统提示、写给模型的通知原文和每次工具调用的参数，打开开发者视图，见[设置](./settings)。

## 还没配好模型时

主助手要有模型才能开工。在你连好模型服务、选好默认模型之前，首页写着**主助手还没有可用的模型**，输入框的按钮是**先连接模型**：它打开**快速上手**里还缺的那一步。你照样可以先写下想让它做的事：这些话会留着，主助手一开工就放进它的输入框。详见[快速入门](../start/quick-start)。
