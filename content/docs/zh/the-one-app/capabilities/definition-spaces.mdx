**定义空间**是 Agent 干活所需的一整套东西：工作组模板、角色、提示词、技能、外部工具（MCP）、脚本、请求模板，以及这个空间的记忆，外加它的角色用到哪些插件的清单。空间想建几个都行，比如每个客户一个、每类工作一个，彼此互不影响。

在**定义空间**页里管理它们。侧栏顶上、**The One** 旁边的空间切换器显示当前空间，从它的菜单里选一个就切换过去；菜单最下面的**管理空间...**会打开这个页面。扩展中心里它就在**插件**旁边（**团队与工具 › 插件**）；打开开发者视图时，**团队与工具**的**开发者视图里**也列着它。

![定义空间页面：官方空间和一个副本](/docs-assets/images/0.5/zh/definition-spaces-page.png)

## 空间里有什么，这台电脑上有什么

空间里的东西都是空间文件夹里的文件：

- 工作组模板、角色、提示词、技能、外部工具（MCP）的设置，以及脚本；
- 请求模板，也就是输入框**模板**菜单里的那些；
- 空间的记忆（见[记忆与召回](./memory)）；
- 它的角色用到哪些插件，以及这些插件不涉密的设置。

换一个空间，就换了这一整套。另一些东西属于这台电脑，所有空间共用：

- **模型预设和模型连接**（见[模型](./models)）。角色或模板指定预设时，记下的是预设的 ID，所以你把空间分享给别人，对方电脑上也得有能用的模型。
- **装好的插件**和它们带来的应用，以及插件的连接和密钥（见[插件与应用](./plugins)）。每个空间自己选用哪些插件。
- **设置 › 数据和撤销 › 行动记录**：它覆盖所有空间，这样撤回才够得着每一处改动（见[行动记录、撤回和急停](../action-log)）。
- 还有几处也不分空间：晨报里每天的花费是所有空间的合计；触发器的**暂停所有**会停下所有空间的触发器；同一个项目文件夹里以前会话的结论，换了空间也找得到（见[记忆与召回](./memory)）。

新东西该放哪？角色、提示词、模板和请求模板属于空间。有自己的代码、依赖、设置、密钥或应用界面的能力，应该做成插件：每个空间都能用它，它也能单独更新。只在某一个空间里才有意义的技能或外部工具，留在那个空间里就行。

## 每个空间都自带的

每个空间都带着五个内置模板，以及它们要用的角色、提示词和技能：

| 模板 | 应用里叫 | 是什么 |
| --- | --- | --- |
| `main_assistant` | **主助手** | [主助手](../main-assistant)本身。应用给每个空间留着一个它的运行。 |
| `chat` | **通用工作组** | 一个助手，直接用工具做普通的多步工作。 |
| `atlas` | **定义编辑组** | 它的导演编写和修改工作组模板、角色、提示词、技能、外部工具（MCP）和插件；[总图](./atlas)底部的 **The Director** 指令栏跑的也是它。 |
| `nightly_review` | **夜间复盘** | 每晚 03:30，有新情况要复盘时应用才开它。 |
| `self_evolution_lab` | **自我改进组** | 负责进化事项的实验室，有总监、改动员和验证员三个角色。 |

后两个见[进化：实验室和夜间复盘](../evolution)。每个空间还带着六个内置请求模板，比如**实现功能**、**诊断并修复问题**和**制作 The One 插件**，它们出现在输入框的**模板**菜单里。

新建、复制或导入空间时，以及每次应用启动时，The One 都会把缺了的补上。已经在的文件一律不覆盖，所以你对它们做的修改会留下来；反过来，官方以后对这些内置定义的改进，也不会进到你已经有的那份里。内置模板不在模板列表里，所以团队与工具只在它为某个事项干活时才给它一张卡片。

所以一个新建的空白空间，一开始只有这五个模板，没有别的，也没有外部工具（MCP）服务器。在它有自己的模板之前，主助手会把普通的活交给通用工作组（`chat`）。

## 官方空间和你自己的副本

The One 自带官方空间，列表里叫 **Default**。它是只读的：应用每次启动都会刷新它，所以它总带着当前版本的工作组模板、角色和技能，除此之外谁都改不了它。在官方空间里：

- 模板、角色、提示词、技能和外部工具（MCP）只能看，修改会被拒绝；
- 主助手和进化实验室找到的改进只能留作提议（见[进化：实验室和夜间复盘](../evolution)）；
- Agent 写不了记忆；
- 插件可以装到这台电脑上，但接不进官方空间：不能在这里把插件加给角色，插件带来的工具和应用在这里也用不上。

模型预设不受影响，它们存在这台电脑上。

所以把它变成你自己的。有三个地方能复制它：

- **快速上手**里的**复制官方空间并使用**，以及角色、提示词和技能编辑页上方提示条里的**复制一份以编辑**：复制一份，并直接切换过去；
- 定义空间页上官方空间那一行的**复制一份以编辑**：复制一份，再点**切换到此**用上它。

得到的副本，你、主助手和进化实验室都能随意修改。代价是官方空间以后的更新不会自动进到你的副本里；升级 The One 时，新增的内置定义还是会补进来（见上文）。

列表里每个空间都带一个标记：正在用的标**当前**，其余的标**只读**或**可编辑**。

## 跟着当前空间走的东西

同一时间只有一个空间处于激活状态，应用显示的是这个空间里的工作：

- 主助手和它的对话：每个空间各有一个；
- 事项、工作组和**需要你**；
- 触发器：别的空间的触发器先等着，切回那个空间时默认补触发一次；
- 晨报和夜间复盘；
- 所有运行里的运行记录。

## 切换、新建、复制和删除

- **切换到此**或侧栏顶上的切换器会立刻换掉当前空间，不用重启。如果还有 Agent 在干活，The One 会告诉你有几个执行在跑，并提供**停止并切换**：先停掉所有正在运行的执行。确认框会提醒，停掉的执行无法恢复。
- **新建空间**得到一个空的空间，只带每个空间都自带的那些（见上文）。
- **复制**会把空间连同记忆和它选用的插件一起复制一份。
- **编辑**可以给你自己的空间改名或改描述。
- **删除**会永久删除你自己的空间，连同其中所有的定义和记忆。当前空间和官方空间不能删除。

## 导出和导入

**导出**把一个空间打包成 `.zerospace` 文件，打包前会抹掉 MCP 设置里的密钥、令牌和口令。**包含 agent 记忆**默认是勾上的；取消勾选，就不带上记忆。见[记忆与召回](./memory)。

**导入**会先读 `.zerospace` 文件，在写入任何内容之前把里面有什么列出来：有多少 Agent、提示词、Graph、MCP 服务和技能，导入后 Agent 可能直接运行哪些脚本，哪些 MCP 服务会在你电脑上运行命令或连到外部，以及哪些地方没通过校验（有这类问题时不能导入）。空间里带脚本或本机命令时，按钮会变成**我信任来源，确认导入**：只导入你信任来源的空间。

空间里只带着它的角色所用插件的引用，从不带插件本身。导入之后，插件页会列出新空间的角色还缺哪些插件，你可以装上这台电脑支持的那些。见[插件与应用](./plugins)。

## 在官网分享

**分享到平台**会把空间发布到 the-zeroth.com 的分享平台。分享要先在 The One 里登录你的账号（**设置 › 通用**）。

- **可见性**：第一次分享时选的是**私有**；**不公开列出**表示知道链接的人能打开，**公开**表示所有人都看得到。
- 可以加几个标签，用逗号分隔。
- **包含 agent 记忆**默认不勾，所以你的私人笔记和项目上下文默认留在你的电脑上。
- MCP 设置里的密钥、令牌和口令（包括地址和连接串里的）会在上传前抹掉；仍含密钥的包会被分享平台拒收。

同一个空间再分享一次，会上传一个新版本：对话框从上次的可见性和标签开始，可见性按你这次选的算。生成分享链接之前，需要先在官网控制台设置用户名。

要用别人分享的空间，点**浏览分享平台**，在 [the-zeroth.com](https://the-zeroth.com/zh/spaces) 上找到它，点**在 The One 中打开**：应用会把它下载下来，显示和从文件导入时一样的预览。
