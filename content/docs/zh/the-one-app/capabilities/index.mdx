**团队与工具**里能看到主助手为每个事项挑团队时从哪些工作组里挑、每个组会什么、在为哪些事项干活，以及活儿用什么来做：插件和它们带来的应用、技能、角色、提示词、外部工具和模型。你来这里查看某个团队或某样工具，或者修改它。

**团队与工具**在侧边栏下方，**设置**的上面；有插件带来能打开的应用时，两者之间还有**应用**。

![团队与工具页面：先是工作组，再是插件和应用，然后是做法、角色和模型](/docs-assets/images/0.5/zh/capabilities-overview.png)

## 工作组

页面先列工作组，每个组一张卡片，上面写着：

- 组名和一句话说它会什么。官方空间带的组用中文名，比如**软件团队**；你自己建的组显示模板的 ID 和它描述的第一句。
- 有几个角色，比如 **4 个角色**；
- 在为哪些开着的事项干活，比如**在为 2 件事干活：**，后面是这些事项的标题，点一个打开它的看板；没在干活时写**现在没在做事**；
- **看看它会什么**：在模板编辑页里打开它的模板（见[工作组模板](./working-group-templates)）。

标题旁写着一共几个组，比如 **13 个，在干活的在前**。在干活的组排在前面，为最多事项干活的最前；然后是官方空间带的组，按固定的顺序排，接的活面广的在前；你自己建的排在最后。一开始只列六个，点**看全部**（比如**看全部 13 个**）列出其余的。

**看各组现在在做什么**打开工作组页，列出你开着的事项上的每个组，以及它们在做什么（见[工作组](../working-groups)）。想一眼看到所有事项上的组和它们的 Agent，打开[全景](../panorama)。

通用工作组这样的内置组不在模板列表里，所以只有在为某个事项干活时才有卡片，卡片上没有角色数，也没有**看看它会什么**。主助手本身和夜间复盘不算可以挑的团队，没有卡片。

工作组下面通向各样东西的编辑页。大多数地方写着里面有多少，比如 **12 个角色**；什么都没有时写着**还没有**。

## 哪些在空间里，哪些不在

这一页上的模板、角色、提示词、技能和外部工具，都是你正在用的空间（当前的定义空间）里的文件；换一个空间，就换了一整套，连同属于它的主助手、事项、触发器和运行。**模型**预设和装好的**插件**不属于任何空间，所有空间共用。

每个空间都自带五个内置模板：**主助手**、**通用工作组**、**定义编辑组**、**夜间复盘**和**自我改进组**。哪些在空间里、哪些在这台电脑上，新东西该放哪，以及这些内置模板各是做什么的，见[定义空间](./definition-spaces)。

## 谁能修改

- **你自己**：在每一处的编辑页里改。模板、角色、提示词、技能和外部工具的编辑页都有**原文**，只读地显示这条定义保存在磁盘上的文件和路径。
- **主助手**：你开口它就改。它可以自己写新的、改现有的，也可以把编写的活交给定义编辑组（`atlas`）。遇到没有合适的模板、以后还会再来的活，它会让人新写一个；值得反复用的经验，它和其他带编写工具的 Agent 会写成技能。
- **总图底部的 The Director 指令栏**：当着你的面编写和修改工作组模板、角色、提示词、技能、外部工具（MCP）和插件（见[总图](./atlas)）。
- **进化实验室**：你让空间把自己的活干得更好时，它改出问题的最小那一层：记忆、技能、角色、模板或代码。
- **夜间复盘**：每晚看一遍 Agent 在哪里反复卡住，把反复出现的问题写成记忆里的一条教训，或者改好一个技能；第二天的晨报里能看到每处改动，也能撤回。

后两个见[进化：实验室和夜间复盘](../evolution)。

Agent 改定义前不会停下来等谁批准。它改的每一处都记在**设置 › 数据和撤销 › 行动记录**里，可以在那里撤回。见[行动记录、撤回和急停](../action-log)。

## 在官方空间里能改什么

官方空间是只读的。在它里面，这一页上的东西大多只能看：

| 东西 | 在官方空间里 |
| --- | --- |
| 模型预设和全局默认 | 能改：它们存在这台电脑上，不属于任何空间。 |
| 工作组模板 | 能看、能校验、能**导出**，也能用**开始任务**跑一次；修改、新建、删除和导入都要先复制一份空间，编辑页提示条里的**复制一份以编辑**就是做这个的。 |
| 角色、提示词和技能 | 编辑页是只读的，上方的提示条里有**复制一份以编辑**；也不能导入技能。 |
| 外部工具（MCP） | 只能看；添加或修改服务器要先复制一份空间。 |
| 插件 | 能装到这台电脑上，但不能加给官方空间里的角色；要用，先复制一份空间。 |

主助手和进化实验室在官方空间里找到的改进，也只能留作提议。**复制一份以编辑**会复制整个空间并切换过去，之后你、主助手和进化实验室都能改它；代价是官方空间以后的更新不会自动进到你的副本里。见[定义空间](./definition-spaces)。

从 [A-Genetic Engineering（Agent 基因工程）](../../multi-agent-architecture/a-genetic-engineering)的角度看，空间就是你的基因库：每个可复用工作组的完整定义都在这里，在这里被编辑，随空间一起传承。
