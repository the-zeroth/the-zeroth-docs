**团队与工具**里能看到主助手为每个事项挑团队时从哪些工作组里挑、每个组会什么、在为哪些事项干活，以及活儿用什么来做：插件和它们带来的应用、技能、角色、提示词、外部工具和模型。你来这里查看某个团队或某样工具，或者修改它。

**团队与工具**在侧边栏下方，**设置**的上面；有插件带来能打开的应用时，两者之间还有**应用**。

## 工作组

页面先列工作组，每个组一张卡片，上面写着：

- 组的中文名，比如**软件团队**，以及一句话说它会什么；
- 有几个角色，比如 **4 个角色**；
- 在为哪些开着的事项干活，比如**在为 2 件事干活：**，后面是这些事项的标题，点一个打开它的看板；没在干活时写**现在没在做事**；
- **看看它会什么**：在工作组模板的编辑页里打开它的模板（见[工作组模板](./working-group-templates)）。

在干活的组排在前面，为最多事项干活的最前；然后是官方空间自带的组，按固定的顺序排，接的活面广的在前；你自己建的排在后面。一开始只列六个，点**看全部**（比如**看全部 13 个**）列出其余的。**看各组现在在做什么**打开工作组页，列出你开着的事项上的每个组，以及它们在做什么（见[工作组](../working-groups)）。

通用工作组这样的内置组不在模板列表里，所以只有在为某个事项干活时才有卡片，卡片上没有角色数，也没有**看看它会什么**。主助手本身和夜间复盘不算可以挑的团队，没有卡片。

## 哪些在空间里，哪些不在

模板、角色、提示词、技能和外部工具的设置，都是你正在用的空间（当前的定义空间）里的文件。输入框**模板**菜单里的请求模板、空间的记忆（见[记忆与召回](./memory)）也在里面。换一个空间，就换了一整套，连同属于它的主助手、事项、触发器和运行。见[定义空间](./definition-spaces)。

这页上有两处不属于任何空间：

- **模型**：模型预设存在这台电脑上，所有空间共用同一批。角色或模板指定预设时，记下的是预设的 ID；所以你把空间分享给别人，对方电脑上也得有能用的模型。见[模型](./models)。
- **插件**和它们带来的**应用**装在这台电脑上，在所有空间之外。空间只记着它的角色用了哪些插件，以及其中不涉密的设置；连接和密钥留在这台电脑上，分享出去的空间带的是这些引用，不是插件本身。见[插件与应用](./plugins)。

新东西该放哪？角色、提示词、模板和请求模板属于空间。有自己的代码、依赖、设置、密钥或应用界面的能力，应该做成插件：每个空间都能用它，它也能单独更新。只在某一个空间里才有意义的技能或外部工具，留在那个空间里就行。

## 每个空间都自带的

每个空间都带着五个内置模板，以及它们要用的角色：

| 模板 | 是什么 |
| --- | --- |
| `main_assistant` | [主助手](../main-assistant)本身。应用给每个空间留着一个它的运行。 |
| `chat` | **通用工作组**：一个助手，直接用工具做普通的多步工作。 |
| `atlas` | **定义编辑组**：由它的导演角色编写模板、角色、提示词、技能和插件。[总图](./atlas)画布底部的 **The Director** 指令栏跑的也是它。 |
| `nightly_review` | **夜间复盘**。每晚 03:30，有新情况要复盘时应用才开它。 |
| `self_evolution_lab` | **自我改进组**：负责进化事项的三角色实验室。 |

后两个见[进化：实验室和夜间复盘](../evolution)。

新建、复制或导入空间时，以及每次应用启动时，The One 都会把缺了的补上，连同它们用到的提示词和技能。已经在的文件一律不覆盖，所以你对它们做的修改会留下来。内置模板不在模板列表里，所以团队与工具只在它为某个事项干活时才给它一张卡片；它们的角色会出现在“角色”里。

所以一个新建的空白空间，一开始只有这五个模板，没有别的。在它有自己的模板之前，主助手会把普通的活交给通用工作组（`chat`）。

## 谁能修改

- **你自己**：在每一处的编辑页里改。模板、角色、提示词、技能和外部工具的编辑页都有**原文**，只读地显示这条定义保存在磁盘上的文件和路径。
- **主助手**：你开口它就改。它可以自己改定义，也可以把编写的活交给定义编辑组（`atlas`）。遇到没有合适的模板、以后还会再来的活，它会让人新写一个。
- **进化实验室**和**夜间复盘**：根据 Agent 在哪里反复卡住的证据来改进空间。见[进化：实验室和夜间复盘](../evolution)。

在官方空间里，这些都改不进去。官方空间是只读的：编辑页上会出现**复制一份以编辑**，主助手和进化实验室找到的改进也只能留作提议。想修改，就在你自己的副本里改。见[定义空间](./definition-spaces)。

Agent 改定义前不会停下来等谁批准。它改的每一处都记在**设置 › 数据和撤销 › 行动记录**里，可以在那里撤回。见[行动记录、撤回和急停](../action-log)。

从 [A-Genetic Engineering（Agent 基因工程）](../../multi-agent-architecture/a-genetic-engineering)的角度看，空间就是你的基因库：每个可复用工作组的完整定义都在这里，在这里被编辑，随空间一起传承。
