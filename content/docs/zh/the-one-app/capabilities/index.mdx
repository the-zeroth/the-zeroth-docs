**团队与工具**里能看到主助手为每个事项挑团队时从哪些工作组里挑、每个组会什么、在为哪些事项干活，以及活儿用什么来做：角色、技能、提示词、外部工具，还有插件、应用和模型。你来这里查看某个团队或某样工具，或者修改它。

**团队与工具**在侧边栏下方，**设置**的上面；有插件带来能打开的应用时，两者之间还有**应用**。

页面顶上写着正在用的空间，旁边是和侧栏顶上同一个空间切换器，以及**管理空间**，它打开[空间](./definition-spaces)页。下面分两块：**这个空间的团队**跟着空间走，**所有空间共用**的装在这台电脑上。

![团队与工具页面：顶上是正在用的空间，下面是这个空间的团队和它们由什么组成](/docs-assets/images/0.5/zh/capabilities-overview.png)

## 这个空间的团队

这一块开头有一句话：这些跟着空间走，换一个空间就是另一套，改它们只改正在用的这个空间。在只读的官方空间里，这句话说这里只能看，要改先在**管理空间**里复制一份。

### 工作组

先列的是工作组，每个组一张卡片，上面写着：

- 组名和一句话说它会什么。官方空间带的组用中文名，比如**软件团队**；你自己建的组显示模板的 ID 和它描述的第一句。
- 有几个角色，比如 **4 个角色**；
- 在为哪些开着的事项干活，比如**在为 2 件事干活：**，后面是这些事项的标题，点一个打开它的看板；
- **看看它会什么**：在模板编辑页里打开它的模板（见[工作组模板](./working-group-templates)）。

标题旁写着一共几个组，比如 **14 个，在干活的在前**；都没在干活时写 **14 个，现在都没在做事**。在干活的组排在前面，为最多事项干活的最前；然后是官方空间带的组，按固定的顺序排，接的活面广的在前；你自己建的排在最后。一开始只列六个，点**看全部**（比如**看全部 14 个**）列出其余的。

**看各组现在在做什么**打开[全景](../panorama)：所有开着的事项上的工作组和它们的 Agent，一页看完。一个事项自己的页面上也画着它的工作组（见[工作组](../working-groups)）。

通用工作组每个空间都有，接的活也最多，所以不管在不在干活都列着，没在干活时排在没在干活的组最前面。它和别的内置组一样不在模板列表里，卡片上没有角色数，也没有**看看它会什么**；别的内置组只在为某个事项干活时才有卡片。主助手本身和夜间复盘不算可以挑的团队，没有卡片。

### 它们由什么组成

工作组下面是**它们由什么组成**，通向各样东西的编辑页。每一处写着里面有多少，比如 **12 个角色**；什么都没有时写着**还没有**。

| 地方 | 放着什么 | 页面 |
| --- | --- | --- |
| **角色** | 工作组里的每个 Agent：做什么，用哪个模型，用哪些提示词、技能、工具和插件。 | [角色](./roles) |
| **技能** | 写下来的做法和流程，角色用到时才去读。 | [技能与提示词](./skills-and-prompts) |
| **提示词** | 几个角色共用的长段说明和规矩。 | [技能与提示词](./skills-and-prompts) |
| **外部工具（MCP）** | 把 Agent 接到外部服务和数据源的 MCP 服务器。 | [外部工具（MCP）](./mcp) |

各编辑页的标签上面有一行：左边的**团队与工具**回到这一页，右边写着在改哪个空间，比如**在改「我的空间」**；只读的空间写着它的名字和“只读”。

## 所有空间共用

这一块的东西装在这台电脑上，每个空间都能用，换空间也不变：

| 地方 | 放着什么 | 页面 |
| --- | --- | --- |
| **插件** | 官方和本地插件，以及它们带来的工具和连接；写着装了几个。 | [插件与应用](./plugins) |
| **应用** | 插件自带的应用界面，侧边栏的**应用**也能打开它们；写着几个能打开。 | [插件与应用](./plugins) |
| **模型** | 主模型和各能力槽用哪家的哪个模型、想多深；写着这台电脑的主模型和它的思考深度，比如**主模型 GPT-6.2-Sol · 高**。点进去是**设置 › 模型和登录 › 模型**，最上面是这个空间写明的模型。 | [模型](./models) |

## 开发者视图里

打开开发者视图后（**设置 › 开发者**里的开关，或者按 ⌘⇧D，Windows 和 Linux 上是 Ctrl+Shift+D），最下面多出一节**开发者视图里**，放着开发者看的东西：

| 地方 | 放着什么 | 页面 |
| --- | --- | --- |
| **总图** | 模板、角色和提示词摆在一张画布上，看它们怎么连。 | [总图](./atlas) |
| **所有运行** | 每一次运行原样的记录：会话、子图和它们的 Agent，以及每个 Agent 的消息和上下文。 | [所有运行（开发者视图）](../settings/all-runs) |
| **评测** | 拿固定的任务考工作组，看改动以后是变好还是变差。 | [设置](../settings) |

不开开发者视图也能去这几处：总图就是各编辑页列表上方的**总图**标签；**设置 › 开发者**里有**打开所有运行**和**评测**。

## 哪些在空间里，哪些不在

这一页上半块的模板、角色、提示词、技能和外部工具，都是你正在用的空间（当前空间）里的文件；换一个空间，就换了一整套，连同属于它的主助手、事项、触发器和运行。下半块的**插件**、**应用**和**模型**（这台电脑的主模型和能力槽）不属于任何空间，所有空间共用；空间还可以写明它是照哪些模型调的，这台电脑能跑时就用它们（见[模型](./models#空间写明的模型)）。

每个空间都自带五个内置模板：**主助手**、**通用工作组**、**定义编辑组**、**夜间复盘**和**自我改进组**。哪些在空间里、哪些在这台电脑上，新东西该放哪，以及这些内置模板各是做什么的，见[空间](./definition-spaces)。

## 谁能修改

- **你自己**：在每一处的编辑页里改。模板、角色、提示词、技能和外部工具的编辑页都有**原文**，只读地显示这条定义保存在磁盘上的文件和路径。
- **主助手**：你开口它就改。它可以自己写新的、改现有的，也可以把编写的活交给定义编辑组（`atlas`）。遇到没有合适的模板、以后还会再来的活，它会让人新写一个；值得反复用的经验，它和其他带编写工具的 Agent 会写成技能。
- **总图底部的 The Director 指令栏**：当着你的面编写和修改工作组模板、角色、提示词、技能、外部工具（MCP）和插件（见[总图](./atlas)）。
- **进化实验室**：你让空间把自己的活干得更好时，它改出问题的最小那一层：记忆、技能、角色、模板或代码。
- **夜间复盘**：每晚看一遍 Agent 在哪里反复卡住，把反复出现的问题写成记忆里的一条教训，或者改好一个技能；周报的**它自己改了什么**里能看到每处改动，也能撤回。

后两个见[进化：实验室和夜间复盘](../evolution)。

Agent 改定义前不会停下来等谁批准。它改的每一处都记在**设置 › 数据和撤销 › 行动记录**里，可以在那里撤回。见[行动记录、撤回和急停](../action-log)。

## 在官方空间里能改什么

官方空间是只读的。在它里面，这一页上的东西大多只能看：

| 东西 | 在官方空间里 |
| --- | --- |
| 模型 | 这台电脑的主模型和能力槽能改，它们不属于任何空间。官方空间写明的模型（GPT-6.2 Sol）只能看：这台电脑跑得了它时，官方空间就用它；要换，先复制一份空间。 |
| 工作组模板 | 能看、能校验、能**导出**，也能用**开始任务**跑一次；修改、新建、删除和导入都要先复制一份空间，编辑页提示条里的**复制一份以编辑**就是做这个的。 |
| 角色、提示词和技能 | 编辑页是只读的，上方的提示条里有**复制一份以编辑**；也不能导入技能。 |
| 外部工具（MCP） | 只能看；添加或修改服务器要先复制一份空间。 |
| 插件 | 能装到这台电脑上，点了名的角色装好就能用；但不能在这里把插件加给角色，要加先复制一份空间。 |

主助手和进化实验室在官方空间里找到的改进，也只能留作提议。**复制一份以编辑**会复制整个空间并切换过去，之后你、主助手和进化实验室都能改它。这份副本仍跟着官方更新：你没改过的文件自动换成新版，改过的保留你的，官方的新版本等你挑。见[空间](./definition-spaces)。

从 [A-Genetic Engineering（Agent 基因工程）](../../multi-agent-architecture/a-genetic-engineering)的角度看，空间就是你的基因库：每个可复用工作组的完整定义都在这里，在这里被编辑，随空间一起传承。
