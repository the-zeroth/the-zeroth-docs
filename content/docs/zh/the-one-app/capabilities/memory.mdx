记忆让 The One 里的 Agent 接着以前的工作往下做，而不是每次从零开始：空间里留着 Agent 自己选择记下的理由和教训，项目里有它自己的笔记，新会话还能找到同一项目里以前的会话得出了什么结论。召回按意思给记忆、笔记和以前的结论排序，让真正相关的那几条到达每个 Agent 面前。

## 空间的记忆

空间的记忆是一组简短的条目，Agent 觉得某个决定或教训对以后的工作有用时才会写下来：比如某个模板为什么这样搭，或者某个不该再犯的错。每条都是空间 `memory` 文件夹里的一个 Markdown 文件，带一句话描述、类型（理由或教训）和出处：什么时候写的、哪个 Agent 用哪个模型写的、在哪次会话里写的。条目还可以写明到什么时候为止有效，或者它取代了哪条旧的。

记不记是 Agent 的选择，而不是每次都要走的步骤：只有对以后有用的才留下。记忆在你自己的空间里积累：在只读的官方空间里，Agent 写不了记忆。

**Agent 怎么看到记忆。** 每一轮开始前，带有记忆工具的 Agent 会拿到最多 20 张记忆卡片，按它最近收到的两条请求挑出最相关的（总共约 1,600 token 的预算）。卡片上是条目的描述和出处；Agent 需要时才展开全文，也可以按意思搜索全部记忆。过期的、被取代的条目不会上卡，也不会出现在搜索里，但仍留在磁盘上。

官方空间里，带记忆工具的是主助手、通用 `chat` 工作组的助手、夜间复盘的复盘员，以及进化实验室的总监。在角色编辑页里给你自己的角色加上记忆工具，它也就能看到记忆。

**历史和撤回。** 条目被修改或删除时，旧版本会保留下来：每条在空间里保留最近五个版本。Agent 写入、修改或删除的每一条记忆也都记在**设置 › 行动记录**里，可以在那里放回旧版本。见[行动记录、撤回和急停](../action-log)。

## 项目笔记和 AGENTS.md

Agent 在某个项目文件夹里干活时，还会看到属于这个项目的知识，不管它在哪个空间里：

- **`.zeroth/knowledge/` 里的笔记。** 项目这个文件夹里的 Markdown 笔记也会变成卡片：最多 20 张，约 1,200 token，同样按最近的请求排序。软件团队的负责人会在第一次改动之前，把仓库的事实（比如怎么构建、怎么测试）写到这里。The One 不会自己创建这个文件夹。
- **项目的 `AGENTS.md`。** 项目文件夹里有这个文件时（Codex、Claude Code 等编码 agent 也读的开放格式），在这个项目里干活的每个 Agent 都会拿到它的全文，最多 32 KiB；文件改了，下一轮就能看到。

## 以前的会话

Agent 的上下文快满时，冥想会把它的历史折成一份摘要，记下它找到了什么、决定了什么（见 [Meditation](../../multi-agent-architecture/more-possibilities/meditation)）。冥想不写记忆；以后的会话能找到的，正是这些摘要。有嵌入模型时，带记忆工具的 Agent 在同一项目里还会拿到最多三张别的会话的摘要卡片，只在和刚问的事明显相关时才出现，每张写着会话标题和日期。Agent 也可以一次同时搜索记忆、项目笔记和这些摘要。

## 设置 › 记忆召回

有嵌入模型时，召回按意思排序，用中文提问也能找到英文写的记忆；没有时按关键词排序。**设置 › 记忆召回**显示**正在使用**的模型，也可以在**嵌入模型**里换一个：

- **自动（推荐）**：按顺序用第一个能用的：本机 Ollama 或 LM Studio 的嵌入模型、默认服务商的嵌入接口、内置模型。
- **内置模型**：`embeddinggemma-300m`，约 218 MB，第一次需要时下载，之后在这台电脑的 CPU 上运行，不调用任何 API，也不需要联网。下载完之前按关键词排序。另一个内置选择是 `bge-m3`，约 586 MB。
- **服务商连接**：一个带 API Key 的连接，或一个不用 key 的自定义服务。记忆和笔记的文本会发给这个服务商。
- **自定义地址**：任何不需要密钥的 OpenAI 兼容嵌入地址，比如本机的 Ollama。
- **关闭**：只按关键词排序。

**索引**一栏按记忆、项目知识和会话结论分别显示索引了多少、进度如何。**重建索引**会清掉所有算好的向量，再在后台把最近 30 天里搜过的内容重新嵌入；用服务商接口时会产生费用。

## 谁会写记忆

- **干活中的 Agent**：带有记忆工具、并且觉得某个教训或决定值得留下时。
- **夜间复盘**：每天夜里 3:30，如果你的真实使用里出现了新的摩擦，复盘员可能往记忆里写一条教训或改一个技能，每晚最多改三处。晨报的**昨夜复盘**会列出每处改动，你可以撤回。见[进化：实验室和夜间复盘](../evolution)。
- **进化实验室的总监**：某一轮的结果应该改变干活的 Agent 的做法时。

冥想不在这份名单上。

## 记忆跟着空间走

记忆存在空间里，空间到哪里，它就到哪里。**复制**会把它一起复制；**导出**默认带上它，除非取消勾选**包含 agent 记忆**；**分享到平台**默认不带它，除非你勾上这个选项。见[定义空间](./definition-spaces)。
