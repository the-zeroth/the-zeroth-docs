**插件**把 Agent 能用的能力（技能、脚本、MCP 服务、应用，以及到在线服务的连接）打成一个包，让你作为一个整体来安装、配置、分享，并交给某个角色。插件是 The One 唯一的扩展形式；有的插件自带应用，从**应用**打开。

## 插件里有什么

一个插件可以任意组合五类组件：

| 组件 | 带来什么 |
| --- | --- |
| Skill | 写下来的做法，角色用到时才去读 |
| 脚本 | 插件替 Agent 运行的程序，以工具的形式提供 |
| MCP | 一个 MCP 服务及其工具 |
| 应用程序 | 有自己界面的应用，从“应用”打开 |
| 连接器 | 插件用你的 API Key 或登录去访问的在线服务 |

插件存在任何定义空间之外。它们装在你的电脑上，空间里只记着它的角色用哪些插件，以及这些插件不涉密的设置。所以导出或分享的空间里从来不含插件本身，只有对所需插件的引用。

## 插件库

打开**能力 › 插件**。插件和定义空间在同一个窗口里，标题是**扩展中心**；插件有两个视图：

- **插件库**：官方插件和其他人分享的插件。每一行显示版本和用途；点开可以看它的组件、它声明的访问范围和它的设置。
- **已安装**：这台电脑上的插件，包括你自己做的；插件库有新版本时会出现**更新**。

## 安装插件

安装会把插件装到这台电脑上，并加入当前空间；当前空间必须是你自己的空间。官方空间是只读的，所以要先复制一份（见[定义空间](./definition-spaces)）。

1. 在插件那一行点**安装插件**。
2. **检查插件变更计划**会列出要装什么、它要哪些权限，以及运行前必须填的设置。
3. 点**继续确认**：The One 会弹出自己的确认窗口，让你确认这些变更和权限，然后在后台完成安装。

在官网的[插件目录](https://the-zeroth.com/zh/extensions)里点某个插件的**在 The One 中打开**，会从浏览器走同样的流程：应用先验证签名发布物，这时还什么都没装；然后问你装进哪个空间。下载、批准完全本地访问、写入空间，都会分别请你确认。

{/* screenshot pending: ![从官网打开插件时的安装窗口](/docs-assets/images/0.5/zh/plugins-install.png) */}

插件不需要你的电脑装有 Python 或 Node。The One 会按插件自带的锁定依赖清单，为它建一个 Python 环境，第一次建可能要几分钟；用 Node 写的服务可以直接跑在 The One 自带的 Node 上。

## 设置和连接

插件详情里有两类设置：

- **配置插件**：模型、端点等普通参数。
- **插件连接**：API Token、OAuth 登录和共享账户。登录会打开你的浏览器。

密钥和登录状态加密保存在这台电脑上，从不进入插件包或定义空间。Agent 需要一个它拿不到的密钥时，可以用一张安全设置卡片向你要：你在卡片里填的内容直接存进系统保护的存储，Agent 只会知道连接是否就绪。

## 把插件交给角色

装好插件并不会运行它，也还没有角色在用它。在插件详情里点**添加给 Agent**，不用打开角色编辑页就能把整个插件加给一个角色；也可以在角色编辑页的**插件**里选（见[角色](./roles)）。主助手也能做这件事，还能用技能、脚本和 MCP 服务自己做出插件。

空间里的角色引用了你还没装的插件时（比如导入一个空间之后），插件页会提示**部分 Agent 的插件尚未就绪**。从插件库装上你需要的那些即可；暂时不用的角色，它们的插件可以以后再装。

## 应用

侧边栏的**应用**会弹出一个快速菜单，列出插件带来的应用；在应用的任何页面按 Cmd/Ctrl+Shift+A 也能打开它。双击**应用**或选**管理所有应用**，进入完整列表；**能力 › 应用**也是这里。应用按各自支持的方式打开：在 The One 内、在隔离的 Web 窗口、在系统浏览器，或作为原生应用。关闭应用自己的窗口，应用也会随之停止。

## 插件在你电脑上能做什么

可执行的组件以你本人的用户权限运行：运行时可以读写文件、访问网络、启动程序。插件在**访问与能力披露**里写的内容，以及**完全本地访问**标记，说明的是它预期会做什么，而不是沙箱。发布者签名（**来源已验证**）证明插件由谁发布、文件发布后没被改动过，但不代表代码已被认定为安全。

和所有工具一样，Agent 通过插件做的事都记在**设置 › 行动记录**里。见[行动记录、撤回和急停](../action-log)。

## 制作和分享插件

在**已安装**里，**制作插件**会打开插件的清单：一个 JSON 文件，在里面手动声明它的技能、脚本、MCP 服务、应用和连接器。让主助手来做通常更省事。要分享你自己做的插件，点**分享插件**，选可见性（**公开**，一开始就选着它，审核通过后进入插件库；**不公开列出**，只能通过链接访问；**私有**，只有你的账号可见），再加几个标签。The One 会一步完成打包、签名、上传和提交。插件设置项的名称和说明会一起分享；你的 Token、账号和填写的值都不会上传。审核进度可以点**在官网管理**查看。

从 0.5.0 起，插件目录只使用一种签名格式，能力包已经移除。

## 官方插件

| 插件 | 做什么 |
| --- | --- |
| Computer Use | 让 Agent 看到并操作浏览器和桌面应用 |
| OneCanvas | 一张无限画布应用，你和 Agent 在同一块画布上摆放、标注和连接内容 |
| Image Generation | 生图提示词设计与生成，可接 Image2 兼容服务、Gemini、OpenRouter 或 APIFrame 账号 |
| Video Production | 规划和审阅视频制作，并通过火山引擎方舟账号运行 Seedance 视频任务 |
| Blender Control | 用你电脑上装的 Blender 搭场景、渲染和导出 |
| Gmail Control | 用 Google 账号登录后，搜索、阅读、起草、发送和整理 Gmail 邮件 |
| Tavily Search | 让内置的网页搜索使用你自己的 Tavily 账号；不装的话，网页搜索用模型服务商自带的搜索 |
| Agent Room Channel | 让**设置 › 随身通道**通过 Agent Room 从手机找到你的 Agent；见[随身通道和对外调用](../remote) |
