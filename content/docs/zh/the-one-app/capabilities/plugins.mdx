**插件**把 Agent 能用的能力（技能、脚本、MCP 服务、应用，以及到在线服务的连接）打成一个包，让你作为一个整体来安装、配置、分享，并交给某个角色。插件是 The One 唯一的扩展形式；有的插件自带应用，从**应用**打开。

## 插件里有什么

一个插件可以任意组合五类组件：

| 组件 | 带来什么 |
| --- | --- |
| Skill | 写下来的做法，角色用到时才去读 |
| 脚本 | 插件替 Agent 运行的程序，以工具的形式提供 |
| MCP | 一个 MCP 服务及其工具 |
| 应用程序 | 有自己界面的应用，从“应用”打开 |
| 连接器 | 插件用你的 API Key 或登录去访问的在线服务 |

插件存在任何空间之外。它们装在这台电脑的插件库里，空间里只记着它的角色用哪些插件，以及这些插件不涉密的设置。所以导出或分享的空间里从来不含插件本身，只有对所需插件的引用。哪些东西在空间里、哪些在这台电脑上，见[空间](./definition-spaces)。

## 一台电脑一个插件库

一个插件在这台电脑上只装一次，装的时候对照签名目录校验一次，之后不往任何空间里复制：

- 每个空间都直接用插件库里的插件。角色、模板或技能里点了名的插件，装好就能用，只读的官方空间也一样。
- 装好的版本是只读的。更新以后，上一个版本还留在这台电脑上，可以一步换回去，不用再下载。
- 从这台电脑上移除一个插件，会删掉它的文件，腾出磁盘。
- 装好的某个插件读不出来了（比如它的安装记录或文件坏了），只有它自己用不上，别的插件照常；它在**已安装**里标着问题，带着**移除**，移除后可以重新装。读不出来的本机副本也标着问题，旁边是**打开插件文件夹**。

从 0.5.2 或更早的版本升级后，第一次启动会把以前装的插件搬进插件库，版本不变；以前下载的安装包还在的，不用重新下载。以前的文件夹先留一周，之后删掉。

## 插件页

打开**团队与工具 › 插件**。插件和空间在同一个页面里，标题是**扩展中心**。插件页有两个标签：

- **插件库**：官方插件与社区用户分享的插件，每个插件一行，写着版本和用途。这里只列这个版本的 The One 能运行的版本。
- **已安装**：这台电脑上的插件，包括本机副本（见下文）。当前空间用到的标着**当前空间正在使用**；插件库里有新版本时，那一行有**更新**。右上角的**打开插件文件夹**打开放本机副本的文件夹。

点一行打开插件的详情，分**概览**、**组件**和**设置**几栏。插件库里一个插件有几个版本时，详情里可以选**版本**：默认是这台电脑能装的最新版，列表标出**推荐给此设备**和**最新**，没有这台电脑能用的安装包的版本标着**不支持此设备**。

![扩展中心的插件页：插件库和已安装两个标签，插件库里每个插件一行，右边是安装插件或已安装](/docs-assets/images/0.5/zh/plugins-library.png)

## 安装、更新和移除

在插件库里一个插件那一行点**安装插件**。The One 先读出这次会改什么，再弹出系统的确认窗口问你一次：装哪个插件的哪个版本，它还会一起装上哪些它需要的插件，哪些组件不适合这台电脑所以不装，要下载多少；有可执行组件时，还写明 Agent 用到它们时，它们以你的系统用户权限运行（**完全本地访问**）。安装只校验并保存插件文件，不运行插件的代码。

确认以后，插件页上方出现一块进度，写着在下载哪个组件、做到百分之几，随时可以**取消**；做完后写着每个插件的结果，比如**已安装 0.5.3**。

在**已安装**里打开一个插件：

- **更新**：换成插件库里的新版本。
- **换回 …**（在**设置**里，比如**换回 0.5.2**）：换回这台电脑留着的上一个版本，不用下载。
- **从这台电脑上移除**（在**设置**里）：删掉这个插件。用到它的 Agent 会在没有它的情况下运行，直到再装上它；空间里的角色、模板和对它的引用都会留着。

这几样也都先在系统窗口里确认一次。一个版本没有这台电脑能用的安装包时，详情里会说明，请你换一个版本。

在官网的[插件目录](https://the-zeroth.com/zh/extensions)里点某个插件的**在 The One 中打开**，会从浏览器走同样的流程：应用打开**安装扩展**窗口，先核对签名发布物和官方目录（**验证并继续**），这时还什么都没装；再点**安装到这台电脑**，在系统窗口里确认一次。它装在这台电脑上，每个空间都能用，不用选空间。

![从官网打开插件时的安装窗口：验证并继续之前，什么都还没装](/docs-assets/images/0.5/zh/plugins-install.png)

插件不需要你的电脑装有 Python 或 Node。The One 会按插件自带的锁定依赖清单，为它建一个 Python 环境，第一次建可能要几分钟；用 Node 写的服务可以直接跑在 The One 自带的 Node 上。

## 本机副本

本机副本是插件文件夹里的一个插件文件夹，里面有它的 `plugin.json`。它照原样在每个空间里运行，不用注册；同一个插件有本机副本时，运行的是本机副本，不是安装的版本。

- Agent 要改一个装好的插件时，先把装好的版本复制到插件文件夹里，再改这份副本。你或 Agent 在插件文件夹里新做的插件，也作为本机副本出现在**已安装**里。
- 本机副本在**已安装**里标着**本机副本**；详情里写着它的文件夹，以及它是代替哪个安装的版本在运行。**设置**里的**打开文件夹**在文件管理器里打开它。
- **移除本机副本**（在**设置**里）先在系统窗口里确认一次，然后把它的文件夹移进插件文件夹旁边的 `plugins-removed` 文件夹：不会删掉，以后可以移回来。之后运行的又是安装的版本；没有安装的版本时，用到它的 Agent 会在没有它的情况下运行。

## 设置和连接

插件详情的**设置**里有两类设置：

- **配置插件**：模型、端点等运行参数。这些值保存在这台电脑上，不写进空间，每个空间都用同一份；本机副本也一样。
- **插件连接**：API Token、OAuth 登录和共享账号。登录会打开你的浏览器。连接存在这台电脑上，每个空间都能用。**当前空间使用**显示这个空间的角色用哪一个连接，在这里不能改：角色写明了用哪个就用哪个；没写明时，用连接槽是 `default` 的那个，只有一个连接时就用它。

密钥和登录状态加密保存在这台电脑上，从不进入插件包或空间。Agent 需要一个它拿不到的密钥时，可以用一张安全设置卡片向你要：你在卡片里填的内容直接存进系统保护的存储，Agent 只会知道连接是否就绪。

插件详情的**概览**里标着当前空间用没用它（**当前空间正在使用**或**当前空间未使用**）。当前空间用到它时，还有一行**运行状态**：**可用**、**需要操作**或**不可用**；缺哪项设置、要不要登录或选账号，都写在这里。

## 插件交给谁用

角色、模板或技能里写明了要用的插件，装好就能用，在每个空间里都一样。很多内置角色已经把官方插件列为可选插件，见下面表里的“官方空间里谁在用”：在官方空间和从它复制出来的空间里，这些插件装好以后不用再加给它们。

要把插件加给别的角色，在插件详情里点**添加给角色**，选好角色，再点**添加插件**，不用打开角色编辑页；也可以在角色编辑页的**插件**里选（见[角色](./roles)）。这两处都要在你自己的空间里用：官方空间是只读的（见[空间](./definition-spaces)）。主助手也能做这件事，还能用技能、脚本和 MCP 服务自己做出插件。

主助手给工作组派活之前，会看这个组要用的插件在这台电脑上有没有。缺了、这件活又用得上时，它自己从官方插件库装上，经过同样的签名校验，不弹确认窗口，并用一句话告诉你装了什么、为什么；这次调用和别的工具调用一样记在行动记录里。它装的插件在详情里标着**Agent 安装的**。插件要的账号和密钥要你来给：主助手会用安全设置卡片向你要。这台电脑没有这个插件能用的版本时，它会告诉你这个组没有它会怎么做。

空间里的角色用到这台电脑上还用不了的插件时（比如导入一个空间之后），**已安装**上方会列出**这个空间用到的一些插件还用不了**，每个写着原因；能装的旁边有**安装插件**。

## 应用

有插件带来能打开的应用时，侧边栏里会出现**应用**：点它弹出一个快速菜单，列出插件带来的应用；在应用的任何页面按 Cmd/Ctrl+Shift+A 也能打开它。双击**应用**或选**管理所有应用**，进入完整列表；**团队与工具 › 应用**也是这里。

应用跟着当前空间走：列出的是当前空间用到的插件带来的应用，换一个空间，列表也跟着换。

点一下，能在 The One 内打开的应用（比如 OneCanvas）会在**所有运行**页的工作区里作为一个标签打开。应用详情里的**打开方式**列着它支持的每一种：在 The One 内打开、在隔离 Web 窗口打开、在系统浏览器打开，或者打开原生应用，默认的那种标着**默认**。关闭应用的独立窗口，应用也会随之停止。

![应用快速菜单](/docs-assets/images/0.5/zh/plugins-apps-menu.png)

## 插件在你电脑上能做什么

可执行的组件以你本人的用户权限运行：运行时可以读写文件、访问网络、启动程序。插件在**访问与能力披露**里写的内容，以及**完全本地访问**标记，说明的是它预期会做什么，而不是沙箱。发布者签名（**来源已验证**）证明插件由谁发布、文件发布后没被改动过，但不代表代码已被认定为安全。

和所有工具一样，Agent 通过插件做的事都记在**设置 › 数据和撤销 › 行动记录**里。见[行动记录、撤回和急停](../action-log)。

## 制作和分享插件

一个插件就是一个带 `plugin.json` 的文件夹。让主助手来做最省事：它用技能、脚本和 MCP 服务做出插件，放进插件文件夹，这就是一个本机副本，每个空间都能用，再加给要用它的角色。你自己放进插件文件夹的插件文件夹，也会出现在**已安装**里。

要分享你自己做的插件，在**已安装**里打开它，点**设置**里的**分享插件**，选可见性（**公开**，一开始就选着它，审核通过后进入插件库；**不公开列出**，只能通过链接访问；**私有**，只有你的账号可见），再加几个标签。分享要先登录你的 The Zeroth 账号；可见性和标签只在第一次分享时设，以后的版本沿用官网上的设置。The One 会一步完成打包、签名、上传和提交。插件设置项的名称和说明会一起分享；你的 Token、账号和填写的值都不会上传。审核进度可以点**在官网管理**查看。

## 官方插件

| 插件 | 做什么 | 官方空间里谁在用 |
| --- | --- | --- |
| Computer Use | 让 Agent 看到并操作浏览器和桌面应用 | 前端设计组、建站上线组、网店门面组、产品体验评估组 |
| OneCanvas | 一张无限画布应用，你和 Agent 在同一块画布上摆放、标注和连接内容 | 主助手、通用工作组、前端设计组 |
| Image Generation | 生图提示词设计与生成，可接 Image2 兼容服务、Gemini、OpenRouter 或 APIFrame 账号 | 图片组、前端设计组 |
| Video Production | 规划和审阅视频制作，并通过火山引擎方舟账号运行 Seedance 视频任务 | 视频组、前端设计组 |
| Blender Control | 用你电脑上装的 Blender 搭场景、渲染和导出 | 主助手、通用工作组、三维场景组 |
| Mailbox | 收发、搜索和整理真实邮箱里的邮件，也能存草稿：Google 账号用 Google 登录（Gmail）；QQ 邮箱、网易、iCloud 等通过 IMAP 和 SMTP，用邮箱给邮件客户端的授权码或应用专用密码（Outlook 和 Microsoft 365 邮箱暂不支持）；先在本地演练，演练时发信不会真的发出去 | 主助手、通用工作组、建站上线组、网店运营组、网店周报组、网店门面组 |
| Payments | 用 Creem 或 Stripe 收款：商品、付款链接、订单、退款和收入；先在本地演练，再用服务商的测试模式，最后才动真钱 | 建站上线组、网店运营组、网店周报组、网店门面组 |
| Sites | 用 Cloudflare 把网站上线：发布一个文件夹、回滚、绑定域名、设置 DNS 记录和注册域名；先在本机演练 | 建站上线组、网店运营组、网店周报组、网店门面组 |
| Visual Check | 渲染网页、PDF 或图片并截图，和参考图对比，标出并说明哪里不一样 | 前端设计组、图片组、软件团队、网店门面组 |
| Tavily Search | 让内置的网页搜索使用你自己的 Tavily 账号；不装的话，网页搜索用模型服务商自带的搜索 | 装好、填上 Key 就生效，不用加给角色 |
| Agent Room Channel | 让**设置 › 手机和别的程序 › 随身通道**通过 Agent Room 从手机找到你的 Agent；见[随身通道和对外调用](../remote) | 随身通道用它，不用加给角色 |

表里用 Computer Use 的这几个组，它们的角色现在用 Agent 自己的[浏览器](../browser)看网页，这个不用装插件；它们绑着的 Computer Use 留给桌面上的活。

Computer Use 和 OneCanvas 要用屏幕，没有 [Linux 服务器](../../start/linux-server)版。
