The One 里每个 Agent 用的模型，都从你选的一个**主模型**开始：主助手直接用它；产品自带的五个**能力槽**（**规划**、**编码**、**视觉**、**写作**和**快速**）默认也都跑在它上面，只是各按自己的思考深度。所以选好一个主模型，每个工作组就都能干活；想细分时，再给某个能力槽换一个模型，可以是别家的。

工作组里的角色按自己干的活绑能力槽，而不是绑某个具体的模型。换模型因此只在一处改：给**写作**换一个模型，绑着它的每个角色从下一轮起都跟着换，不用一个个去改角色。

主模型和能力槽可以由空间来定：空间可以写明它是照哪些模型调的，这台电脑上有能跑它们的连接时，这个空间就用它们；空间没写、或者这台电脑跑不了时，用这台电脑自己的设置。官方空间写明用 GPT-6.2 Sol。见下面的[空间写明的模型](#空间写明的模型)。

## 在哪里设置

- **设置 › 模型和登录 › 模型**：最上面是**这个空间的模型**，列着当前空间写明的主模型和五个能力槽，以及它们在这台电脑上跑在哪里（见[空间写明的模型](#空间写明的模型)）。下面是**这台电脑的模型**：上面是主模型，下面是五个能力槽，每个槽写着它的模型和深度，跟随主模型的还标着**跟随主模型**。从**团队与工具 › 模型**进去也是这里。
- **主助手的输入框**：输入框下方、**发送**旁边的按钮写着主模型和它的思考深度。点开可以直接换主模型的思考深度，或者在**让主模型换成**下面选一个能力槽或保存的配置正在用的模型；**管理模型**在一个窗口里打开同样的设置。空间写明了主模型、这台电脑又跑得了时，按钮上写的是空间的主模型，在这里换深度或换模型，改的也是空间的；只读的官方空间里，这两样是灰的。
- 给某个角色或模板选能力槽，在它们各自的编辑页里（见下面的[优先顺序](#模型的优先顺序)）。

还没有模型连接、或者还没设主模型时，窗口顶部会有一行提示，链到能解决的地方：**添加连接**或**设置主模型**。

## 主模型

这一节和下一节讲的是**这台电脑的模型**里的主模型和能力槽；空间写明的那些在**这个空间的模型**里改，见[空间写明的模型](#空间写明的模型)。

主助手，以及没绑能力槽、也没指定模型的角色，都用主模型；能力槽默认也跟着它。在**主模型**这一栏里选：

1. **模型连接**：请求走哪个连接。连接在**设置 › 模型和登录 › 模型连接**里添加，见[模型连接](../settings/api-configuration)。
2. **模型**：从服务商的模型目录里选。**刷新模型目录**会向服务商重新取一遍最新列表，比如刚有新模型发布时。目录是空的或取不到时，可以直接填模型 ID。
3. **思考深度**：模型回答前想多深，从**最低**到**最高**，能选哪几档看这个模型；也可以选**自动（用模型自己的默认）**，交给模型自己定。
4. **高级参数**：**思考的更多选项**里，有的模型还能选**思考摘要**的详略，或者设思考 Token 预算、推理模式，有的模型强制思考，不能关；**速度 / 服务等级**有**快速（优先）**、**弹性**这样的选项，只有服务商的模型目录提供时才会出现；还有模型容量覆盖，给不报上下文大小的服务商用。

点**保存主模型**。跟随主模型的角色和能力槽从下一轮起用上新配置，正在生成的回复照原样写完。**主模型**旁边的**原文**只读显示它在应用偏好文件里存成的样子。

还没有主模型时（在**上手**里和这一页都一样），只要连好的那家服务商的模型目录里有它的旗舰模型，**模型**一栏就已经填上了，思考深度是**中**：直接点**保存主模型**就行，也可以换一个。自定义的服务（中转、Ollama、LM Studio 这类）列着这些旗舰模型之一时填它，只有一个模型时填那一个，有好几个、又没有旗舰模型时不填。换了连接，填的模型跟着换；你自己选了或输入了模型，它就不再替你改。自定义提供商不填，要你自己选。

没有温度（temperature）设置：每次请求都用服务商的默认值。旧定义里还写着的 temperature 照常读取，但不会发给模型。

## 能力槽

五个能力槽是产品自带的，不能新建、改名或删除。每个槽有自己的出厂深度：

| 能力槽 | 给谁用 | 出厂深度 |
| --- | --- | --- |
| **规划** | 负责人、导演、评审、研究和决策 | 高 |
| **编码** | 写、改、跑、测代码 | 最高 |
| **视觉** | 看图、出图、视觉设计和界面观感 | 中 |
| **写作** | 故事、剧本、文案和编辑 | 中 |
| **快速** | 跑工具、执行分派好的步骤、判断少的帮手 | 低 |

槽默认跟随主模型：用主模型的模型、连接和服务等级，但按槽自己的深度想。比如主模型的深度是**中**，**编码**用同一个模型按**最高**想，**快速**按**低**。主模型的深度不会传到槽上。深度越高，模型想得越久，用量通常也越多；想省一些，先把用得最多的那个槽调低一档。

点一个槽右边的**更改**，可以：

- 在**模型**里选**用别的模型**，再选连接和模型，可以是别家的。改回**跟随主模型**，这个槽就重新跟着主模型，深度不变。
- 在**思考深度**里换一档，或者选**出厂深度（…）**，回到它出厂的那一档。

点**保存**。绑着这个槽的角色从下一轮起都跟着变。

官方空间里的角色已经按干的活绑好了能力槽：软件团队的负责人绑**编码**；研究组的负责人绑**规划**，替它查资料的成员绑**快速**；前端设计组的角色都绑**视觉**；通用工作组的助手和定义编辑组的导演绑**规划**。主助手不绑槽，直接用主模型和主模型的深度。

0.5.2 以前从官方空间复制出来的空间不会跟着更新：那时官方的角色还没有绑能力槽，所以副本里的角色都跑在主模型上（你自己给它们绑过预设的除外）。想让它们按能力分，就在角色的编辑页里给它们选能力槽，或者让主助手去改。

## 空间写明的模型

空间里的角色、提示词和团队是照着某个模型调的，所以空间可以写明它用哪些模型：主模型，以及每个能力槽自己的模型和思考深度。它们写在空间文件夹里的 `models/models.yaml`，只有模型的名字和深度：模型连同它的服务商一起写，比如 `openai/gpt-6.2-sol`；在设置里选的模型，还记着当时选的是哪条连接。连接和密钥从不写进去，它们留在每台电脑上。复制空间时这个文件跟着走，官方更新也带着它。

空间写的模型，这台电脑上有连接能跑时就用它。连接按下面的顺序找，用第一条能用（启用着，填了 Key 或登录过，不用 Key 的本机服务也算）、又能跑这个模型的：

1. 空间写明的那条连接；
2. 官方连接（The One 会员才有）；
3. 这台电脑的主模型用的连接；
4. 这个模型那一家的直连：OpenAI（API Key 或 ChatGPT 账号登录）、Anthropic、Gemini 或 TypeSafe；
5. 别的 OpenRouter 连接。

自定义的服务（中转、Ollama、LM Studio 这类）只在空间写明了它时才用。哪条都跑不了时，这一项用这台电脑自己的设置：空间的主模型跑不了，就用这台电脑的主模型；能力槽也一样。

没写自己模型的能力槽，跟着空间的主模型跑，按空间给它的深度，没给就用出厂深度；这时这台电脑上给这个槽选的模型和深度都不用。空间的主模型这台电脑跑不了时，这些槽也用这台电脑的。写了自己模型的槽，单独看它跑不跑得了。按名字保存的配置、某次运行选的模型和角色单独指定的模型，都不看空间写的模型。

没有这个文件的空间，比如新建的空白空间，以及以前复制、不跟着官方更新的空间，照旧用这台电脑的模型。

### 官方空间和它的副本

官方空间写明它是照 GPT-6.2 Sol 调的：主模型 `openai/gpt-6.2-sol`，思考深度**中**；五个能力槽跟着它，用出厂深度（**规划**高、**编码**最高、**视觉**中、**写作**中、**快速**低）。它没写连接，所以在会员的电脑上，它跑在官方连接上；不是会员时，用这台电脑上能跑它的 ChatGPT 账号登录、OpenAI 或 OpenRouter 连接；都没有时，官方空间用这台电脑的模型。

跟着官方更新的副本（「我的空间」也是）也带着这个文件：新装的一开始就有，从以前的版本升级的，在升级后第一次启动时收到，和别的官方更新一样（见[空间](./definition-spaces#跟着官方更新)）。所以在这些空间里，只要这台电脑跑得了 GPT-6.2 Sol，你给这台电脑的主模型和能力槽选的模型就用在别处；想让这个空间用别的模型，就改这个空间的模型。

### 在设置里看和改

**设置 › 模型和登录 › 模型**最上面的**这个空间的模型**说的是当前空间。主模型和五个能力槽各占一行，写着空间写的模型和思考深度：这台电脑跑得了的，下面写着**在「…」上运行**，没有自己模型的能力槽写着**跟随空间的主模型**；跑不了的，写着这台电脑上没有能跑它的连接、现在用这台电脑的模型，添加一个能跑它的模型连接，就会改用它。

- 在你能编辑的空间里，点一行的**更改**。主模型选模型连接、模型和思考深度；能力槽选**跟随空间的主模型**或**用别的模型**（再选连接和模型），然后选思考深度，或者选**出厂深度（…）**，回到出厂的那一档。点**保存**，跟着它的 Agent 从下一轮起用上。
- 每次改动都是空间变更历史里的一条，和别的定义改动一样可以撤回。
- 空间还没写模型时，这一块只有一句：这个空间没有写用哪个模型，用这台电脑的模型。点旁边的**给这个空间选模型**，先给它选主模型，五个能力槽就跟着它，用出厂深度。
- 这一块最下面的**不再给这个空间指定模型，改用这台电脑的**会删掉这个空间的模型文件，之后这个空间用这台电脑的模型。
- 官方空间只读：这一块上方写着它的模型照官方的来，要换就复制一份；旁边的**复制一份以编辑**复制官方空间并切换过去。副本带着同样的模型文件，你可以改它，副本也照样收到官方更新。

## 模型的优先顺序

一个 Agent 用哪个模型，从下面第一个适用的算起，排在前面的优先：

1. **这一次运行选的**：主助手给事项开一个新的工作组时，可以只为这次运行选模型：一个能力槽、主模型或一套保存的配置，整组用一个，或者给某个成员单独选。Agent 开子图时也能这样选；Agent 往运行里新加或克隆一个 Agent 时，也可以只给它选。你跟主助手说“这件事换个模型做”就行，模板和角色都不用改。已经在干活的工作组，主助手不能再给它换；要换模型，只能把活交给一个新开的工作组。
2. **角色**：在角色编辑页的**模型与参数**里，绑一个能力槽或一套保存的配置、勾着**使用主模型**，或者单独配置模型。见[角色](./roles)。
3. **所有运行里这次运行的会话默认模型**（开发者视图）：运行上方的**主模型**按钮，只为这次运行换掉主模型。角色没有自己模型的 Agent 从下一轮起用上它，绑了能力槽或指定了模型的不受影响。见[所有运行（开发者视图）](../settings/all-runs)。
4. **工作组模板**：模板编辑页工具栏里的模型菜单，给模板里角色没有自己模型的节点选一个能力槽。见[工作组模板](./working-group-templates)。
5. **主模型**：其余所有情况。

这里说的主模型和能力槽，在空间写明了模型、这台电脑又跑得了时，是空间写的那些；其余时候是这台电脑的。

主模型或某个能力槽改了，用着它们的 Agent 都从下一轮起跟着变，正在干活的也一样。

这些也都可以直接交给主助手：它能说出主模型和每个能力槽现在用的是什么，按你的话换主模型、给某个能力槽换模型或深度、给角色或模板绑能力槽，或者让某一件事用另一个模型来做。它（以及定义编辑组的导演）换主模型或能力槽时，改的是当前空间写明的模型，空间还没写时替它写上；只读的官方空间里改不了，要先复制一份。

## 以前保存的预设

0.5.2 以前，模型是一套套起了名字的预设，其中一套是全局默认。升级以后，原来的全局默认就是你的主模型，模型和深度都不变。以前保存的预设都列在这一页最下面的**其他保存的模型配置**里，Agent 为某次运行存下的配置也在那里，展开就能看到每一套用的模型和深度；绑着它们的角色和运行照常能跑。不要了，点它旁边的垃圾桶图标，再点**删除**：还在用它的角色或运行之后会报错，要改绑别的。这一页不再新建命名的预设，要按能力细分，就用上面的能力槽。

升级后，官方空间的角色改按各自能力槽的深度跑，比如**编码**是**最高**，不再都用以前全局默认的那一档。觉得太慢或用量太多，就把那个槽的深度调低。

## 这台电脑上的模型设置

**这台电脑的模型**（主模型、能力槽和保存的配置）存在你的电脑上，不在[空间](./definition-spaces)里，所以哪个空间里都能改，只读的官方空间里也一样。空间没写模型、或者这台电脑跑不了空间写的模型时，用的就是它们。给官方空间里的角色或模板换绑能力槽、改官方空间写明的模型，都要先复制一份空间，见[在官方空间里能改什么](../capabilities#在官方空间里能改什么)。

角色和模板按名字绑能力槽，所以空间换到另一台电脑上，角色就跑在那台电脑的主模型和能力槽上。指定了某套保存的配置或某个连接的角色不一样：别的电脑上做出来的空间，可能指定了你这里没有的配置或连接，这些角色要等你改过才跑得起来。**上手**的**检查空间里的模型**一步会把它们列出来，并提供**改用主模型**；所有运行里的**新建 Graph** 也会在开运行之前检查每个角色的模型和连接。

这台电脑还没设主模型、空间也没有这台电脑跑得了的主模型时，没有自己模型的能力槽也就没有模型可用，绑着它们的角色会报错，告诉你先选主模型。删除一个连接不会改动这台电脑上用它的主模型、能力槽或配置：在你给它们换一个连接之前，用它们的 Agent 都连不上模型。

能连接哪些服务商、官方模型服务怎么收费，见[模型与价格](../../start/models-and-pricing)。
