**模型预设**是一套起了名字的模型配置：用哪个模型、请求走哪个连接、想多深、走哪一档速度。每个 Agent 默认都用全局默认那一套，除非它的角色、模板或这次运行另有指定。

有了预设，一键就能换掉整个应用的默认模型；同时又能让吃重的角色用更强的模型、简单的检查用更便宜的模型，不必逐个改 Agent。

## 在哪里设置模型

- **标题栏**：模型按钮上显示的是当前作为全局默认的预设。点开可以切换到另一套已保存的预设，选**管理模型预设**进入编辑。
- **设置 › 默认模型**：同一个编辑器，单独成页。从**能力 › 模型**进去也是这里。

还没有模型连接、或者还没设默认模型时，窗口顶部会有一行提示，并链到能解决的地方：**添加连接**或**设置默认模型**。

## 新建一套预设

编辑器左侧是**已保存的预设**，全局默认那一套带**全局默认**标记。点**新建预设**，然后依次填写：

1. **预设名称**：能区分开就行，比如“日常助手”“深度研究”。
2. **Provider 连接**：请求走哪个连接。连接在**设置 › API 配置**里添加，见[API 配置](../settings/api-configuration)。
3. **模型**：从服务商的模型目录里选。**刷新模型目录**会向服务商重新取一遍最新列表，比如刚有新模型发布时。目录是空的或取不到时，可以直接填模型 ID。
4. **思考 (Reasoning)**：模型回答前要不要先思考、想多深（**思考强度**）。能调哪些取决于所选模型声明了什么：有的模型还能设思考 Token 预算或推理模式，有的模型强制思考、不能关。
5. **高级参数**：**速度 / 服务等级**，比如**快速（优先）**或**弹性**，只有服务商的模型目录提供时才会出现；还有模型容量覆盖，给不报上下文大小的服务商用。

点**保存预设**；要让它成为默认，再点**设为全局默认**。改动从各个 Agent 的下一轮开始生效，正在生成的回复照原样写完。预设改名不影响绑定，因为绑定认的是预设的 ID，不是名字。

没有温度（temperature）设置：每次请求都用服务商的默认值。旧定义里还写着的 temperature 照常读取，但不会发给模型。

## 全局默认

没单独指定模型的角色，都用全局默认这一套；官方空间里的主助手也是这样。可以在标题栏切换，也可以在编辑器里点**设为全局默认**。正在作为全局默认的预设不能删除，先把别的设为默认。

## 给角色、模板或一次运行单独配模型

预设可以绑在几个层级上，越具体的越优先：

1. **某一次运行**：主助手把活交给工作组时，可以只为这个工作组的这次运行选预设。跟它说某件事换个模型来做，别的都不受影响。工作组开工后不换模型：要把活挪到别的模型上，主助手会把它交给一个新的工作组。
2. **角色**：在角色的编辑页**模型与参数**里，选一套预设、保持**使用默认模型**，或者单独配置模型。见[角色](./roles)。
3. **开发者视图里某次运行的默认模型**：在**设置 › 所有运行**里，运行上方的**默认模型**按钮可以为这次运行里使用默认模型的角色换掉全局默认。见[所有运行（开发者视图）](../settings/all-runs)。
4. **工作组模板**：模板编辑页工具栏里的模型预设菜单，给模板里没单独配模型的角色定一个默认。见[工作组模板](./working-group-templates)。
5. **全局默认**：其余所有情况。

这些也都可以直接交给主助手：它能列出和修改预设，给角色或模板绑定预设，或者让某一件事用另一个模型来做。

## 预设保存在这台电脑上

预设存在你的电脑上，不在[定义空间](./definition-spaces)里。空间里的角色和模板按 ID 引用预设，预设只引用它的连接，不复制任何密钥。所以别的电脑上做出来的空间，可能指定了你这里没有的预设；这些角色要等你绑上自己的预设、或改用默认模型后才跑得起来。**快速上手**的**检查空间里的模型**一步会把它们列出来，并提供**改用默认模型**；设置 › 所有运行里的**新建 Graph** 也会在开运行之前检查每个角色的模型和连接。

删除一套预设后，仍绑定它的角色和模板需要重新选：The One 会报告预设缺失，而不会悄悄换成别的模型。删除一个连接不会改动用它的预设：在你给这些预设换一个连接之前，用它们的 Agent 都连不上模型。

编辑器里预设名称旁边的**原文**，只读显示这套预设在应用偏好文件里存成的样子。

能连接哪些服务商、官方模型服务怎么收费，见[模型与价格](../../start/models-and-pricing)。
