不坐在 The One 的窗口前，也有两种办法给它派活。**随身通道**让 The One 待在你 Agent Room 的私人房间里，你在手机上就能和主助手说话、回答 Agent 的提问。**对外调用**让这台电脑上的程序，比如 Claude Code、Codex 或你自己的脚本，把活交给你的团队，再把交付拿回去。

两者都只是多开了一个入口。Agent 照旧在你的电脑上干活，权限和平时一样，做过的事都记进行动记录，可以撤回（见[行动记录、撤回和急停](./action-log)）。

## 随身通道

The One 以网络 Agent 的身份进到你在 Agent Room（agentroom.chat）的私人房间，只听你一个人的。手机和房间说话，活在你的电脑上做，所以电脑要开着，The One 也要在运行。

### 连上

1. 打开**设置 › 手机和别的程序 › 随身通道**。页面提示需要 **Agent Room Channel** 插件时，点**去安装**先装好它。The One 在房间里的身份加密存在这个插件的保险库里，Agent 和别的插件都拿不到。
2. 在 Agent Room 你的房间里点「接入 Agent」，把整段邀请文字（或只把 Agent 口令，样子是 XXXX-XXXX-XXXX）粘到 **Agent 口令或邀请文字**，点**连接**。想让它在房间里用别的名字，填**在房间里的名字（留空就是 The One）**。
   - 有口令就直接进。建号有时要几分钟，这期间可以先离开这个页面。
   - 只有房间号时 The One 会去敲门，等房间的管理者在 Agent Room 网页上点「让它进来」。一个小时没人放行，这次敲门就作废。
3. 进了房间以后，The One 会在房间里说怎么绑定，页面上显示一个 6 位**配对码**，10 分钟内有效（点**换一个**换新的）。把它发到房间里，你就成了主人，页面上写着**已绑定**和你的名字。

之后只有你的话会派活。房间里别人的消息一律忽略，只在页面上计个数。

![设置 › 手机和别的程序 › 随身通道：还没连接，等你填房间的 Agent 口令或邀请文字](/docs-assets/images/0.5/zh/remote-phone-channel.png)

### 在手机上怎么用

| 你做什么 | 会发生什么 |
| --- | --- |
| 在房间里直接说一句话 | 交给这个空间的主助手，就像在首页对它说的一样。它自己办，或交给一个工作组；它的回复，以及工作组为这件事的提问和结果，都回到你这条消息下面。 |
| 回复某条消息 | 接着那件事说，交给正在做它的 Agent。 |
| 回复一个提问 | 回答它：发选项的编号或原文，确认题回“是”或“否”，或者直接写你的回答。电脑上那个问题也随之关掉。要填插件密钥或登录的问题只能在电脑上答。 |
| 发 `/待办`（或 `/todo`） | 列出还在等你回答的问题，最多 10 个，先问的在前。 |
| 发 `/帮助`（或 `/help`） | 说明怎么用。 |

随身通道只收文字；发图片或文件会收到一句提示。

### 什么会发到手机

- 从手机派的活，它的提问、结果和失败都回到手机，挂在派活的那条消息下面。
- 电脑上开始的活，提问在电脑上 1 分钟没人答才发到手机；结果默认留在电脑上，打开**电脑上开始的活，结果也发到手机**才发。
- 你最后一次是在手机上跟主助手说话时，它的回复发到手机；之后你在电脑上跟它说了话，回复就留在电脑上。
- 工作组的提问先等主助手来答，最多三分钟，和在电脑上一样。
- 提问、结果和失败都会 @ 你，房间会把它们标出来。在电脑上答掉的问题，手机上那条下面会补一句已经在电脑上回答了。
- 超过 4000 字的内容会截断，并说明全文在电脑上：对话上方等你的那一条里。
- 只发当前空间的条目，和对话上方那一条一样。

### 语言

随身通道自己在房间里说的话只有中文：欢迎语和帮助、“收到，交给主助手了”这类回执、提问和结果的标题，以及怎么回复的提示。英文命令 `/todo`、`/help` 也认，英文的 yes、no 和选项编号同样能用。Agent 写的内容照它写的样子发给你。

### 还要知道

- 一台电脑只连一个房间、一个主人。要换到另一个房间，点**换个房间**，贴那个房间的口令或邀请文字：The One 进了新房间就离开旧房间，你要在新房间里重新发配对码绑定。
- The One 只在房间里发消息，自己不会往手机推送通知。
- 电脑关着或 The One 没开时你发的话，等它下次连上再处理。
- Agent Room 不再接受 The One 的身份时（它被移出房间、被停用，或 30 天没用），页面会说明，粘贴新的口令重新连接。
- **断开**会让 The One 离开房间、令牌作废、绑定解除。**解除绑定**只是去掉你这个主人，在房间里发新的配对码就能重新绑定。

## 对外调用

**设置 › 手机和别的程序 › 对外调用**让这台电脑上的程序把你的团队当工具用：列出团队、给一支团队派活、等它交付、回答它的提问。你正在 Claude Code 或 Codex 里写代码，想把部署、写文档或一套固定流程交给 The One 里的团队，又不想切窗口时，就用它。

这里的团队是当前空间的工作组模板，自带的 chat 和 atlas 也在其中。每个程序用一个在这个页面发的令牌。

### 接上

1. 填**新令牌的名字**（写上给哪个程序用），点**发令牌**。勾上**只能调用选中的团队**可以限定范围。
2. 令牌只显示这一次，下面的配置命令已经带上它。
3. 把 The One 加到你的程序里：

| 程序 | 怎么加 |
| --- | --- |
| Claude Code | 在终端运行页面给出的命令：`claude mcp add --scope user --transport http the-one http://127.0.0.1:8014/mcp --header "Authorization: Bearer <token>"`。之后你在这台电脑上的所有项目都能用。 |
| Codex | 把页面给出的四行加到 `~/.codex/config.toml`。最后一行让这些工具的调用直接放行，少了它 `codex exec` 会拒掉每次调用。 |
| 其他 MCP 客户端 | streamable HTTP，地址 `http://127.0.0.1:8014/mcp`，请求头 `Authorization: Bearer <token>`。 |
| 会说 A2A 的 agent | A2A 1.0，地址 `http://127.0.0.1:8014/a2a`。新活默认交给 chat，消息里写了团队就交给那支团队；每支团队也是一个单独的 agent，地址是这个地址加 `/` 和团队 id。页面附一段用官方 a2a-sdk 的 Python 示例。 |
| 终端、脚本、CI | 点**安装 the-one**：一个 Python 文件（Python 3.9 以上就行），放进应用的数据文件夹，页面给出加进 PATH 的命令。它也能当 stdio MCP 服务器，给只能用命令启动服务器的客户端用。 |

安装 the-one 时，页面上刚发的令牌会一起写进它旁边的设置文件，之后运行它不用再给令牌；没带令牌的，运行时用 `--token` 或环境变量 `THE_ONE_TOKEN` 给它一个。它带的令牌撤销以后，发一个新令牌，趁新令牌还显示在页面上点**更新**。

入口只在本机 127.0.0.1 上收调用，默认端口 8014。发了令牌才打开，而且 The One 要开着才收得到。可以在页面上改端口，填 0 关掉入口；改了端口，已经加好的程序要用新地址重新加一次。

![设置 › 手机和别的程序 › 对外调用：入口、令牌，以及在 Claude Code、Codex 里怎么用](/docs-assets/images/0.5/zh/remote-outside-callers.png)

### 程序能做什么

通过 MCP，它多出四个工具：`list_teams` 列出这个令牌能调的团队，`run_team` 给一支团队派活（可以带项目文件夹和事项；不带项目文件夹时，团队在应用的数据文件夹里干活），`check_task` 等它做完，`reply_to_task` 回答团队的提问或提新要求。每个结果都写着下一步该做什么，调用的程序据此决定是接着等、回答问题还是读交付。

`the-one` 用命令做同样的事：`the-one teams`、`the-one run 团队 "要做的事"`、`the-one check 任务`、`the-one reply 任务 "回答"`。退出码说明进展：0 交付了，2 团队在问，3 还在做，1 失败或出错。

### 在 The One 里看到什么

- 每个任务都是看板上的一个事项：没指定时开一个新事项，标题取任务的第一行；程序指定了哪个事项，就挂在那个事项上。团队作为工作组在上面干活，由调用的程序跟进，所以它的提问和交付不会叫醒主助手。活交付了，事项自己关上；程序再发话，事项重新打开。
- 团队收到的话开头一行写明是谁发来的：令牌的名字和那个程序，比如“【本条消息来自外部调用方：Claude Code（…）】”。
- 提问也会出现在对话上方那一条里，你也可以在那里回答。调用的程序通常几秒内就答了，所以提问开着满 1 分钟才提醒你。
- 交付交给调用的程序，不另外提醒你。失败马上提醒你。
- 程序发来的话不算你介入：事项的无人值守用量不会因此重新算起，停在用量边界上的活也不会因此恢复，要等你自己恢复（见[事项与看板](./matters)）。

### 令牌和信任

- 页面列出每个令牌的名字、最后 4 位、什么时候发的，以及最近一次什么时候被哪个程序用过。
- **撤销**立即生效。已经派出去的任务照常做完，结果留在 The One 里。
- 拿到令牌的程序能让你的团队在这台电脑上做它们能做的任何事。只给信得过的程序，不用了就撤销。
