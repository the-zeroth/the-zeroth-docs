The One 是 The Zeroth 出品的桌面应用，支持 macOS 和 Windows。你把事交代给**主助手**；比一句回答大的事会变成一个**事项**，有自己的看板，主助手把它交给一个**工作组**——一组在你自己电脑上干活的 AI Agent。

## 工作是怎么组织的

- **主助手**：每个空间都有一个常驻的主助手，什么事都先跟它说。能直接回答的它直接回答，更大的事它开成事项，并一直跟进。
- **事项**：一个事项就是一块由卡片组成的看板：等你处理的事、按天记下的进展，以及这件事本身——目标、工作组、清单、链接和文件。
- **工作组**：工作组是按工作组模板（也就是 Graph）组建的一组 Agent。它的提问和交付以卡片出现在看板上，你也可以直接和它对话。
- **需要你和晨报**：只有你能拍板的问题、等你评判的交付，都在**需要你**里等你。每天的**晨报**总结交付了什么、还等你什么、花了多少。
- **触发器**：定时、Webhook，以及新邮件、新订单、文件或网页的变化，让固定的工作在你离开时也继续推进。
- **能力**：空间里的工作组模板、角色、技能、提示词、外部工具（MCP）、模型和插件。在你自己的空间里，主助手和进化实验室也能改进它们。

## 没有黑箱

多 Agent 的工作，只有看得见才值得信任。在 The One 里，你可以在**剧场**里看一个事项的工作组怎么干活，读每个 Agent 的消息、工具调用和上下文，并逐块审阅每一处改动。Agent 不会每一步都停下来请你批准；它做的每件事都记在**行动记录**里，被它改动或删除的文件可以放回。
