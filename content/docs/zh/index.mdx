The One 是 The Zeroth 出品的桌面应用，支持 macOS 和 Windows。你把事交代给**主助手**；比一句回答大的事会变成一个**事项**，有自己的看板，主助手把它交给一个**工作组**——一组在你自己电脑上干活的 AI Agent。

Windows 版目前还是 0.4.28，没有主助手和事项，所以这份文档按 macOS 版来写。没有屏幕的 Linux 机器也能跑 The One，见[在 Linux 服务器上运行 The One](./start/linux-server)。

## 侧边栏里有什么

侧边栏最上面，**The One** 旁边写着你正在用的空间：一整套工作组模板、角色和技能，点它可以换到别的空间。下面从上到下是：

- **对话**：这就是主助手。每个空间都有一个常驻的主助手，什么事都先跟它说：能直接回答的它直接回答，更大的事它开成事项，交给工作组，并一直跟进。等你的事都在对话上方那一条里，写着有几件（比如**等你 2 件**），每件一个按钮，点一下就到它的卡片；侧边栏里**对话**旁边的数也是它。
- **全景**：所有进行中的事项摆在一页上：每个事项的工作组和它们的 Agent，此刻在想、在干活还是在等。
- **事项**：一个事项就是一块由卡片组成的看板：等你处理的事、按天记下的进展，以及这件事本身——目标、工作组、清单、链接和文件。工作组是按工作组模板（也就是 Graph）组建的一组 Agent；它的提问和交付以卡片出现在看板上，你也可以直接和它对话。
- **自动做事**：触发器让固定的工作在你离开时也继续推进：定时、Webhook，以及新邮件、新订单、文件或网页的变化；事项也可以有自己的触发器。它打开**设置 › 自动做事**。
- **周报**：回头看近 7 天：交付了什么、一次过了多少、找了你几次、花了多少，和它自己改了什么。
- **团队与工具**：主助手从中挑选的工作组，以及空间里的角色、技能、提示词、外部工具（MCP）、模型和插件。在你自己的空间里，主助手和进化实验室也能改进它们。
- **设置**：账号和外观、模型和登录、自动做事、手机上的随身通道、行动记录和撤回。

还没连好模型时，**对话**下面还有**上手**；插件自带应用时，还会多出**应用**。

你不在时发生的事不用去哪里找：每天有你没看过的新东西时，主助手先在对话里打个招呼，说上次看过以后发生了什么；早上 8 点应用开着、又有新东西时，还会收到一条系统通知。详见[等你和交付](./the-one-app/needs-you)和[周报](./the-one-app/weekly)。

## 没有黑箱

多 Agent 的工作，只有看得见才值得信任。在 The One 里，**全景**让你一眼看到所有事项的工作组和 Agent 此刻在做什么，点一个工作组就进到它的**剧场**。在事项的剧场里，你可以看这个事项的工作组怎么干活，读其中每个 Agent 的消息、工具调用和上下文，并逐块审阅每一处改动。Agent 不会每一步都停下来请你批准；它做的每件事都记在**行动记录**里，被它改动或删除的文件可以放回。
